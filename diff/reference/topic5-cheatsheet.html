BVPs & classification

Linear 2nd-order ODE + two BCs at different points. Dirichlet fixes $y$, Neumann fixes $y'$, Robin a mix. Solutions = particular + homogeneous BVP solutions $\Rightarrow$ 0, 1 or ∞ solutions. Homogeneous BVP has a nonzero solution $\Rightarrow$ 0 or ∞.

PDE: order = highest derivative; linear if $u$ and derivatives appear linearly with coefficients in independent variables only; homogeneous if every term contains $u$. $Au_{xx}+Bu_{xy}+Cu_{yy}$: $B^2-4AC\lt0$ elliptic (Laplace), $=0$ parabolic (heat), $\gt0$ hyperbolic (wave).

Words → conditions

"held at / quenched in ice"$u=T_0$ / $u=0$
"end insulated", "reflecting"$u_x=0$
"insulated except at ends"1D model (not a BC)
"heat flux $q$ in at $x=0$"$u_x(0,t)=-q$ (Fourier's law)
"released from rest"$u_t(x,0)=0$
"struck from equilibrium with velocity $g$"$u(x,0)=0,\ u_t(x,0)=g$
"pinned / fixed" vs "free" end$u=0$ vs $u_x=0$
disc/drum centre$u$ bounded at $r=0$

Three cases (write all three)

Lecture convention: $\frac{\dot T}{\alpha T}=\frac{X''}{X}=\lambda$ ("LHS only $t$, RHS only $x$ ⇒ constant"). $T\not\equiv0$ ⇒ BCs on $X$.

  • $\lambda=k^2\gt0$: $X=A\cosh kx+B\sinh kx$ ⇒ trivial ($\sinh kL,\cosh kL\ne0$).
  • $\lambda=0$: $X=Ax+B$ ⇒ trivial, except Neumann–Neumann: $X_0=1$.
  • $\lambda=-k^2\lt0$: $X=A\cos kx+B\sin kx$ ⇒ "non-trivial ⇒ $B\ne0$ ⇒ $\sin kL=0$" ⇒ $k_n$. State range of $n$.

Booklet/tutes/Paul use $X''+\lambda X=0$: signs flip. Polar $\Theta''+\lambda\Theta=0$ (2022 paper).

N–N$\cos k_nx$$\frac{n\pi}L$$\ge0$

Hook: BC at $x=0$ picks the function (D→sin, N→cos); same type both ends → $n\pi/L$, mixed → odd multiples of $\pi/2L$.

Heat: 5 steps (lect. 22)

  1. Separate: $\dot T-\alpha\lambda T=0$, $X''-\lambda X=0$
  2. BCs ⇒ three cases ⇒ $\lambda_n=-k_n^2$, $X_n$
  3. $T_n=e^{-\alpha k_n^2t}$ (N–N: $T_0=1$)
  4. Superpose $u=\sum C_ne^{-\alpha k_n^2t}X_n$ (N–N: $\frac{a_0}2+\dots$)
  5. IC: match if $f$ is a finite trig sum (double-angle / product-to-sum first), else $C_n=\frac2L\int_0^L fX_n\,dx$

N–N: $u\to\frac{a_0}2=$ mean of IC. Sketch: start at $f$, end at $u_S$; high modes die first; every $t\gt0$ curve obeys the BCs (pinned value, or flat slope at an insulated end).

Inhomogeneous BCs / source (most examined)

$u=u_S(x)+u_T(x,t)$. $u_S$: $u_t=0$ ⇒ $\alpha u_S''=-q(x)$, impose the inhomogeneous BCs (constant source → parabola, linear → cubic; divide by $\alpha$, mind the sign). $u_T$: same PDE without source, same BC types with RHS $0$, IC $g=f-u_S$.
  • Transient IC is often $u_S$ + one eigenfunction ⇒ match, no integral.
  • $t\to\infty$: $u\to u_S$; point value: substitute $x$.
  • N–N with equal slopes $b$: $u_S=bx+d$, $d$ free; $n=0$ mode absorbs it; limit has mean = mean of $f$. Unequal fluxes, no source: no steady state.

Laplace's equation

Rule: the variable with homogeneous BCs at both ends gets the eigenproblem; the nonzero side is used last for coefficients.

  • Rectangle: partner $\cosh/\sinh(ky)$; $\lambda=0$: $A+By$. Kill side $y=b$ with $\sinh k(b-y)$ (Neumann there: $\cosh k(b-y)$). Two adjacent nonzero sides: split $u=v+w$.
  • Polar: $\Theta''+\lambda\Theta=0$, $r^2R''+rR'-\lambda R=0$ (Euler): $R=Ar^k+Br^{-k}$, $k=0$: $A+B\ln r$.
  • Disc: periodic $\theta$ ⇒ $n$; bounded ⇒ drop $r^{-n},\ln r$: $u=\frac{a_0}2+\sum r^n(a_n\cos n\theta+b_n\sin n\theta)$; $a^na_n$ = FS coeffs of $f$.
  • Wedge $0\le\theta\le\beta$: $k_n$ from the table with $L=\beta$. Annulus: keep both $r^{\pm k}$; $(r/a)^k-(a/r)^k$ vanishes at $r=a$.

Wave equation

$\ddot T-c^2\lambda T=0$; D–D: $u=\sum(a_n\cos\omega_nt+b_n\sin\omega_nt)\sin k_nx$, $\omega_n=ck_n$.

$a_n=\frac2L\int_0^Lf\sin k_nx$, $\quad b_n=\frac{2}{L\,\omega_n}\int_0^Lg\sin k_nx$ (don't forget $\omega_n$).
  • Normal mode = one term; harmonics $\omega_n=n\omega_1$; period $2L/c$.
  • Plucked at $\ell$: mode $n$ missing iff $n\ell\in\mathbb Z$ (pluck point is a node).
  • Rectangle drum: $\omega_{m,n}^2=c^2\pi^2\big(\frac{m^2}{L_x^2}+\frac{n^2}{L_y^2}\big)$ (dispersion relation); square ⇒ $(m,n),(n,m)$ degenerate.

Radial (disc heat / drum)

$R''+\frac1rR'+k^2R=0$ with $\lambda=-k^2$ (only non-trivial case: decay for heat, oscillation for drum). $s=kr$ ⇒ $S''+\frac1sS'+S=0$, Bessel order 0. $Y_0$ log-singular ⇒ dropped (bounded). $J_0(k_na)=0$: $k_na\approx2.405,\ 5.520,\ 8.654$.

$u=\sum C_ne^{-\alpha k_n^2t}J_0(k_nr)$, $C_n=\frac{2}{a^2J_1^2(k_na)}\int_0^afJ_0(k_nr)\,r\,dr$ (weight $r$). Drum: $\omega_n=ck_n$, not integer multiples.

Heat vs wave (1–2 sentences)

Heat (parabolic): $e^{-\alpha k^2t}$ smooths jumps/kinks instantly, $u\to u_S$. Wave (hyperbolic): no decay; kinks/jumps travel at speed $c$, reflect at ends, repeat with period $2L/c$; no steady state.

Genuine solution (lect. 25)

  1. Domain $D=\{0\le x\le L,\ t\ge T\gt0\}$
  2. Bound $|u_n|,|\partial_xu_n|,|\partial_x^2u_n|,|\partial_tu_n|\le Mn^pe^{-\alpha k_n^2T}$
  3. $\sum n^pe^{-cn^2T}$ converges (ratio test) ⇒ M-test ⇒ uniform ⇒ term-by-term OK ⇒ genuine for $t\gt0$

Fails at $t=0$ if IC jumps or mismatches BCs (Gibbs: continuous terms, discontinuous sum). Wave: no decay factor ⇒ needs $\sum n^2|a_n|\lt\infty$; plucked string is only weak.

Exam checklist

  1. Translate words → PDE, BCs, ICs
  2. Inhomogeneous BC/source? Find $u_S$ first, then $u_T$ BCs + IC
  3. Separate with the constant named; write all three cases
  4. Eigenvalues + range of $n$; time/partner ODE per eigenvalue
  5. Superpose; coefficients by matching or half-range integral
  6. Check BCs and IC on the final answer; limit $t\to\infty$; sketch
