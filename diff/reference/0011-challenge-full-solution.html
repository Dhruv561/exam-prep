The challenge, written out as an exam answer

Everything inside the red rule is what goes on your paper. The grey notes explain the reasoning, and you don't write them. Printing this page hides the notes.

Consider $\;3t\,y'' + y' - y = 0,\quad t > 0$.

(a) Substitute $y = \sum_{n\ge0} c_nt^n$. Show that this gives only one linearly independent power-series solution, and write it, with $c_0 = 1$, in sum form with an explicit formula for $c_n$. [5]
(b) Find its radius of convergence. [2]
(c) Let $y_2$ be a second, linearly independent solution. Use Abel's identity to find $\operatorname{wr}[y_1, y_2]$, and explain why $y_2$ can't be a power series about $t = 0$. [3]
(d) Show that $y_2 = t^{a}\sum_{j\ge0}d_jt^j$ with $d_0 = 1$ is consistent with (c). Find $a$, $d_1$ and $d_2$ by substituting the first terms of $y_1$ into the Wronskian equation. [5]

(a) 1 · Substitute

With $y = \sum_{n=0}^\infty c_nt^n$: $\;y' = \sum_{n=0}^\infty n\,c_nt^{n-1}$, $\;y'' = \sum_{n=0}^\infty n(n-1)\,c_nt^{n-2}$. Substituting:

$$\sum_{n=0}^\infty 3n(n-1)\,c_nt^{n-1} + \sum_{n=0}^\infty n\,c_nt^{n-1} - \sum_{n=0}^\infty c_nt^n = 0$$ $$\sum_{n=0}^\infty n(3n-2)\,c_nt^{n-1} - \sum_{n=0}^\infty c_nt^n = 0.$$

Combine the $y''$ and $y'$ sums first: $3n(n-1) + n = n(3n-2)$. That one line makes the rest short.

(a) 2 · Match powers, recurrence

The $n = 0$ term of the first sum is $0$. Letting $m = n - 1$ in the first sum and $m = n$ in the second:

$$\sum_{m=0}^\infty\big[(m+1)(3m+1)\,c_{m+1} - c_m\big]\,t^m = 0.$$

Equating coefficients of $t^m$ to zero:

$$c_{m+1} = \frac{c_m}{(m+1)(3m+1)}, \qquad m \ge 0.$$

So every $c_n$ is determined by $c_0$. There is only one arbitrary constant, so the method gives only one linearly independent power-series solution.

Say explicitly where the lowest power went (here: it's automatically zero). That sentence plus "only $c_0$ is arbitrary" is the "show" mark.

(a) 3 · Closed form

Iterating,

$$c_n = \frac{c_0}{(1\cdot1)(2\cdot4)(3\cdot7)\cdots\big(n(3n-2)\big)} = \frac{c_0}{n!\,\prod_{k=1}^n(3k-2)}.$$

Taking $c_0 = 1$:

$$\boxed{\,y_1(t) = \sum_{n=0}^\infty \frac{t^n}{n!\,\prod_{k=1}^n(3k-2)} = 1 + t + \frac{t^2}{8} + \frac{t^3}{168} + \cdots\,}$$

Listing the first terms lets the marker check your formula quickly: $c_1 = 1$, $c_2 = 1/(2\cdot4)$, $c_3 = 1/(6\cdot28)$.

(b) · Radius of convergence

$$R = \lim_{n\to\infty}\left|\frac{c_n}{c_{n+1}}\right| = \lim_{n\to\infty}(n+1)(3n+1) = \infty.$$

The series converges for all $t\in\mathbb R$.

The recurrence gives $c_n/c_{n+1}$ directly, so there's no factorial cancelling to do.

(c) · Abel's identity

In standard form, $\;y'' + \dfrac{1}{3t}\,y' - \dfrac{1}{3t}\,y = 0$, so $f_1(t) = \dfrac{1}{3t}$. By Abel's identity,

$$\operatorname{wr}[y_1,y_2](t) = C\,e^{-\int \frac{1}{3t}\,dt} = C\,t^{-1/3},$$

with $C \neq 0$ since $y_1, y_2$ are linearly independent.

If $y_2$ were a power series about $0$ with positive radius, then $y_1y_2' - y_1'y_2$ would also be a power series, and hence bounded as $t \to 0^+$. But $|C\,t^{-1/3}| \to \infty$ as $t\to0^+$. So $y_2$ is not a power series about $t = 0$.

Name Abel's identity and give the reason $C \ne 0$. The contradiction argument is short but it's the whole of the "explain" mark.

(d) 1 · Set up the Wronskian equation

Let $y_2 = t^a(1 + d_1t + d_2t^2 + \cdots)$. Then

$$y_2' = t^{a-1}\big(a + (a+1)d_1t + (a+2)d_2t^2 + \cdots\big),$$

and from (a), $y_1 = 1 + t + \tfrac18t^2 + \cdots$, $\;y_1' = 1 + \tfrac14t + \cdots$. So

$$y_1y_2' - y_1'y_2 = t^{a-1}\Big[\big(1 + t + \tfrac18t^2\big)\big(a + (a+1)d_1t + (a+2)d_2t^2\big) - \big(t + \tfrac14t^2\big)\big(1 + d_1t\big) + O(t^3)\Big],$$

and this must equal $C\,t^{-1/3}$.

Write $y_1'y_2 = t^{a-1}\cdot t\,y_1'(1 + d_1t + \dots)$. That extra $t$ is where most people lose the $d$'s.

(d) 2 · Match powers

$t^{a-1}$: $\;a\,t^{a-1} = C\,t^{-1/3}$, so $a = \tfrac23$ and $C = \tfrac23$.

Since the Wronskian is exactly $C\,t^{-1/3}$, the coefficients of all higher powers vanish:

$t^{a}$: $\;(a+1)d_1 + a - 1 = 0 \;\Rightarrow\; \tfrac53d_1 = \tfrac13 \;\Rightarrow\; d_1 = \tfrac15.$

$t^{a+1}$: $\;(a+2)d_2 + (a+1)d_1 + \tfrac a8 - d_1 - \tfrac14 = 0$

$$\tfrac83d_2 + \tfrac13 + \tfrac1{12} - \tfrac15 - \tfrac14 = 0 \;\Rightarrow\; \tfrac83d_2 = \tfrac1{30} \;\Rightarrow\; d_2 = \tfrac1{80}.$$

Hence

$$\boxed{\,a = \tfrac23,\quad d_1 = \tfrac15,\quad d_2 = \tfrac1{80},\qquad y_2 = t^{2/3}\Big(1 + \frac t5 + \frac{t^2}{80} + \cdots\Big).\,}$$

Since $a = \tfrac23$ is not a non-negative integer, $y_2$ is not a power series, which is consistent with (c).

Margin check by the generalised series: indicial $\lambda(3\lambda - 2) = 0$ gives $\lambda = \tfrac23$, and $d_{j+1}(j+1)(3j+5) = d_j$ gives $d_1 = \tfrac15$, $d_2 = \tfrac1{80}$. Only write this if you have time to spare.
