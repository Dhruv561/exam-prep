Standard series · Lesson 8

To build a new series: substitute (and carry the condition along: $|2t|<1 \Rightarrow R = \tfrac12$), multiply by $t^k$, or differentiate/integrate term by term. These leave $R$ unchanged; after integrating, fix the constant.

Series = $f$? Find a first-order IVP $f$ satisfies, show the series solves it, then quote uniqueness. Warning: $e^{-1/t^2}$ has Maclaurin series $0$.

Radius of convergence · Lesson 8

$$R = \lim_{n\to\infty}\left|\frac{c_n}{c_{n+1}}\right| \qquad \text{converges for } |t-a|<R,\ \text{diverges for } |t-a|>R$$
  • Note the order: if you flip it you get $1/R$. Endpoints need another test.
  • Gap series ($t^{2k}$): either put $x = t^2$, find $R_x$, then $R = \sqrt{R_x}$, or take the ratio of successive non-zero terms with $t$ kept in.
  • Useful: $(n+1)! = (n+1)\,n!$, $\ (2n+2)! = (2n+2)(2n+1)(2n)!$, $\ (1+\tfrac1n)^n \to e$.

The 5-step method · Lesson 9

$$y = \sum_{n\ge0}c_nt^n,\qquad y' = \sum_{n\ge1}nc_nt^{n-1},\qquad y''=\sum_{n\ge2}n(n-1)c_nt^{n-2}$$
  1. Substitute. Multiply each coefficient into its own sum
  2. Shift every sum to $t^m$. For $t^{n+k}$, put $n = m-k$ everywhere (index and factors); the start moves up by $k$
  3. Extract the low-index terms so all sums start at the same $m$. These give conditions ($c_1=0$, $c_2 = 0$, …)
  4. Recurrence: the coefficient of each $t^m$ is $0$
  5. Count free constants: 2 for second order ($c_0,c_1$), or only 1 if the equation is singular at 0

Polynomial coefficients · Lesson 10

$$(a+\alpha t^2)y'' + bty' + cy = 0:\qquad c_{m+2} = -\frac{\alpha m(m-1) + bm + c}{a(m+2)(m+1)}\,c_m$$
  • Terminating: if the numerator is $0$ at an integer $k\ge0$, the chain with $k$'s parity is a polynomial of degree $k$. For a parameter value giving a polynomial, set the numerator to $0$ at $m=k$.
  • Radius: at least the distance from $0$ to the nearest complex root of the $y''$ coefficient ($1+t^2 \Rightarrow 1$). For this family, $R = \sqrt{|a/\alpha|}$ for a non-terminating chain. Polynomials have $R=\infty$.
  • Step 3 (Airy): when the other terms give $t^{n+1}$, $c_2 = 0$ is forced and $c_{m+3}$ links to $c_m$.
  • Three-term (leading coefficient like $1-t$): tabulate the coefficients for $(c_0,c_1) = (1,0)$ and $(0,1)$; "first $k$ non-zero terms" means skip the zeros.
  • Existence interval (a separate question): divide by $P$, use only real roots, and take the open interval containing $t_0$. It can lie outside $(-R,R)$.

Singular at 0 · Lesson 11

If the $y''$ coefficient vanishes at $0$ ($p\,t\,y'' + q\,y' + \dots$): only $c_0$ is free, so there is one power-series solution $y_1$. Always check the lowest power, e.g. $b\,c_1 = 0$.

$$\operatorname{wr} = Ce^{-\int f_1} = C\,t^{-q/p},\qquad y_2 = y_1\int\frac{\operatorname{wr}}{y_1^2}\,dt$$

Finding $a, d_1, d_2$: substitute $y_2 = t^a(1+d_1t+d_2t^2)$ and the first terms of $y_1$ into $y_1y_2' - y_1'y_2 = C\,t^{-q/p}$. The lowest power gives $a$; set every higher power to $0$. Indicial equation for a $t^\lambda$ trial: $\lambda(p\lambda - p + q) = 0$.

Why $y_2$ isn't a power series: if it were, the Wronskian would be bounded at $0$, but $C\,t^{-q/p}$ is not.

Uniform convergence & genuine solutions · Lesson 12

  • Uniform on $D$: $\max_{t\in D}|W_N - W| \to 0$. Always state $D$. Example: $t^N$ is not uniform on $[0,1]$, but it is uniform on $[0,b]$, $b<1$.
  • A uniform limit of continuous functions is continuous. So a discontinuous limit means not uniform.
Weierstrass write-up: (1) name $w_n(t)$ and $D$; (2) $|w_n(t)|\le a_n$ for all $t\in D$, where $a_n$ has no $t$ in it; (3) $\sum a_n$ converges (geometric, $p$-series, or ratio test); (4) so $\sum w_n$ converges uniformly on $D$.

Use $|\sin|,|\cos|\le1$, $|t|\le b$ on $[-b,b]$. If $\sum a_n$ diverges, the test is inconclusive (it doesn't show non-uniform convergence).

The short-answer trio (for a series with radius $R$):
  1. Radius by the ratio test (successive non-zero terms)
  2. Converges uniformly on every closed $[-b,b]$ with $0<b<R$ (every $b>0$ if $R=\infty$), and not necessarily on $(-R,R)$ or $\mathbb R$
  3. Genuine: $R>0$, so the series and its derivatives up to the order of the ODE (same radius) converge uniformly on each $[-b,b]$. Term-by-term differentiation is valid there, so it is a genuine solution on $(-R,R)$. If $R=0$, it is formal only
