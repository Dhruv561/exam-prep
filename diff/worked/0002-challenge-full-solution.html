Lesson 2 · Exam-level challenge · Full written solution

The challenge, written out as an exam answer

Everything inside the red rule is what goes on your paper. The grey notes explain the reasoning, and you don't write them. Printing this page hides the notes.

Solve $\;t\,y'' - (t+2)\,y' + 2y = t(t-1)\,e^{t},\quad y(1) = 5,\;\; y'(1) = 4 + e,\quad t>0.$

Also state the general complementary solution, and the interval on which your answer is valid.

Write thisDon't write this

1 · A complementary solution

Try $v = e^{t}$, so $v' = v'' = e^{t}$. Substituting into the homogeneous equation:

$$t\,e^{t} - (t+2)\,e^{t} + 2e^{t} = (t - t - 2 + 2)\,e^{t} = 0.$$

So $v = e^{t}$ is a complementary solution.

You found $e^t$ with the test $P+Q+R=0$. That test is scratch work. On the paper, substitute and show you get 0.

2 · Standard form and interval

Dividing by $t$ (valid since $t > 0$):

$$y'' - \frac{t+2}{t}\,y' + \frac{2}{t}\,y = (t-1)\,e^{t}.$$

The coefficients $-\dfrac{t+2}{t}$, $\dfrac{2}{t}$ and $(t-1)e^{t}$ are continuous except at $t = 0$. The initial point $t_0 = 1$ lies in $(0, \infty)$, so by the existence and uniqueness theorem the IVP has a unique solution on $(0,\infty)$.

Name the theorem and say why each function is continuous. That sentence is usually worth its own mark.

3 · Reduce the order

Let $y = u(t)\,e^{t}$. Then

$$\begin{aligned} y' &= (u' + u)\,e^{t}, \\ y'' &= (u'' + 2u' + u)\,e^{t}. \end{aligned}$$

Substituting into the ODE and dividing through by $e^{t} \neq 0$:

$$t\,(u'' + 2u' + u) - (t+2)(u' + u) + 2u = t(t-1)$$ $$t\,u'' + (2t - t - 2)\,u' + (t - t - 2 + 2)\,u = t(t-1)$$ $$t\,u'' + (t-2)\,u' = t(t-1).$$

Let $w = u'$ and divide by $t$:

$$w' + \Big(1 - \frac{2}{t}\Big)\,w = t - 1.$$

Show the line where the $u$ coefficient collapses to $0$. It's the evidence that $v$ really solves the homogeneous equation, and markers look for it. You could plug into the memorised formula $w' + (2v'/v + f_1)w = g/v$ instead, and it gives the same line: $2 + (-1 - 2/t) = 1 - 2/t$. But if the question says "derive" or "use reduction of order", the substitution above is the safe version.

4 · Integrating factor

$$I(t) = \exp\!\Big(\int \Big(1 - \frac{2}{t}\Big)\,dt\Big) = \exp\big(t - 2\ln t\big) = \frac{e^{t}}{t^{2}} \qquad (t > 0).$$

Multiplying the $w$-equation by $I$:

$$\Big(\frac{e^{t}}{t^{2}}\,w\Big)' = \frac{(t-1)\,e^{t}}{t^{2}}.$$

$\ln t$ rather than $\ln|t|$ because $t > 0$. Write the $(t>0)$ so the marker sees you noticed. You can drop the constant of integration inside the exponential.

5 · First integration

Since $\dfrac{d}{dt}\Big(\dfrac{e^{t}}{t}\Big) = \dfrac{t\,e^{t} - e^{t}}{t^{2}} = \dfrac{(t-1)\,e^{t}}{t^{2}}$, integrating gives

$$\frac{e^{t}}{t^{2}}\,w = \frac{e^{t}}{t} + C_1,$$ $$w = u' = t + C_1\,t^{2}e^{-t}.$$

Write the quotient-rule line. Without it, "$= e^t/t$" looks like a guess. Keep $C_1$ here. It becomes your second complementary solution.

6 · Second integration

By parts twice:

$$\begin{aligned} \int t^{2}e^{-t}\,dt &= -t^{2}e^{-t} + \int 2t\,e^{-t}\,dt \\ &= -t^{2}e^{-t} - 2t\,e^{-t} + \int 2e^{-t}\,dt \\ &= -(t^{2} + 2t + 2)\,e^{-t}. \end{aligned}$$

So

$$u = \frac{t^{2}}{2} - C_1\,(t^{2} + 2t + 2)\,e^{-t} + C_2.$$

7 · General solution

$$y = u\,e^{t} = \frac12\,t^{2}e^{t} - C_1\,(t^{2} + 2t + 2) + C_2\,e^{t}.$$

Writing $A = -C_1$ and $B = C_2$:

$$y = \underbrace{A\,(t^{2} + 2t + 2) + B\,e^{t}}_{y_c} \;+\; \underbrace{\tfrac12\,t^{2}e^{t}}_{y_p}.$$

The general complementary solution is $y_c = A\,(t^{2}+2t+2) + B\,e^{t}$, with $A, B$ arbitrary constants. These two solutions are linearly independent on $(0,\infty)$ because their Wronskian is non-zero there:

$$W = \begin{vmatrix} t^{2}+2t+2 & e^{t} \\ 2t+2 & e^{t} \end{vmatrix} = (t^{2}+2t+2)\,e^{t} - (2t+2)\,e^{t} = t^{2}e^{t} \neq 0 \;\text{ for } t > 0.$$

The question asks you to "state the general complementary solution", so label $y_c$ explicitly. Without the Wronskian line you haven't shown that $y_c$ is the general solution, only that it's a sum of two solutions. It takes one line, so include it.

8 · Initial conditions

Differentiating:

$$y' = \Big(t + \tfrac12\,t^{2}\Big)\,e^{t} + A\,(2t + 2) + B\,e^{t}.$$

Then

$$\begin{aligned} y(1) &= \tfrac{e}{2} + 5A + Be = 5, &\quad&(1)\\ y'(1) &= \tfrac{3e}{2} + 4A + Be = 4 + e. &&(2) \end{aligned}$$

$(1) - (2)$: $\;-e + A = 1 - e$, so $A = 1$.

Substituting into $(1)$: $\;\tfrac e2 + 5 + Be = 5$, so $B = -\tfrac12$.

Number the equations so you can say "(1) − (2)" instead of rewriting both.

9 · Answer

$$\boxed{\,y = \tfrac12\,(t^{2} - 1)\,e^{t} + t^{2} + 2t + 2, \qquad t \in (0, \infty).\,}$$

10 · Check (on paper if time allows)

ICs: $\;y(1) = 0 + 5 = 5$ ✓. With $y' = t\,e^{t} + \tfrac12(t^{2}-1)\,e^{t} + 2t + 2$, $\;y'(1) = e + 0 + 4 = 4 + e$ ✓.

Particular solution: $y_p = \tfrac12 t^{2}e^{t}$, $\;y_p' = \big(t + \tfrac12t^{2}\big)e^{t}$, $\;y_p'' = \big(1 + 2t + \tfrac12t^{2}\big)e^{t}$.

$$\begin{aligned} t\,y_p'' - (t+2)\,y_p' + 2y_p &= \Big[\,t + 2t^{2} + \tfrac12 t^{3} - \big(t^{2} + \tfrac12 t^{3} + 2t + t^{2}\big) + t^{2}\Big]\,e^{t} \\ &= (t^{2} - t)\,e^{t} = t(t-1)\,e^{t} \;✓ \end{aligned}$$

The IC check takes about 20 seconds and catches most arithmetic slips. Do the $y_p$ check only if you have time to spare.
