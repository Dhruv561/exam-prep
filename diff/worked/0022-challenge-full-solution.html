$f(x)=\sin(\pi x)$ for $0<x<1$, $f(x)=0$ for $1\le x<2$, with $f(-x)=-f(x)$ and $f(x+4)=f(x)$.

(a) Even, odd or neither? Which coefficients are zero, and why? [2]
(b) Sketch $f$ for $-6<x<6$. [2]
(c) Compute all non-zero Fourier coefficients. [5]
(d) Write the Fourier series using only the non-zero terms. [1]
(e) If instead $f(-x)=f(x)$: the integral for the non-zero coefficients, and which $n$ is special. [2]

(a) · Parity

$f(-x)=-f(x)$, so $f$ is odd. Period $4=2L$, so $L=2$.

$f(x)\cos\frac{n\pi x}2$ is odd × even $=$ odd, so $a_n=\frac12\int_{-2}^{2}f\cos\frac{n\pi x}2\,dx=0$ for all $n\ge0$. Only $b_n$ can be non-zero.

Naming $L=2$ here saves an error later: the trig argument is $\frac{n\pi x}{2}$, not $n\pi x$.

(b) · Sketch

On $(0,1)$: arch $\sin\pi x$ rising to $1$ at $x=\frac12$. On $(1,2)$: zero. On $(-2,0)$: rotate by $180^\circ$, a downward arch on $(-1,0)$ with minimum $-1$ at $x=-\frac12$, zero on $(-2,-1)$. Repeat with period $4$.

On paper: label $x=\pm1,\pm2,\dots,\pm6$ and heights $\pm1$. The sketch is continuous (no jumps), since $f(0^+)=0$ and $f(2^-)=0$. Set the slider to $0$ to see only the sketch; slide it up to watch the series match it.

(c) · Coefficients

Odd, so $$b_n=\frac2L\int_0^L f(x)\sin\frac{n\pi x}{2}\,dx=\int_0^1\sin(\pi x)\sin\frac{n\pi x}2\,dx,$$ since $f=0$ on $(1,2)$. Product-to-sum: $$\sin(\pi x)\sin\frac{n\pi x}2=\frac12\Big[\cos\big((1-\tfrac n2)\pi x\big)-\cos\big((1+\tfrac n2)\pi x\big)\Big].$$

$n=2$ (the frequencies are equal, $1-\frac n2=0$): $$b_2=\int_0^1\sin^2(\pi x)\,dx=\int_0^1\frac{1-\cos2\pi x}2\,dx=\frac12.$$

$n\ne2$: $$b_n=\frac12\left[\frac{\sin\big((1-\frac n2)\pi\big)}{(1-\frac n2)\pi}-\frac{\sin\big((1+\frac n2)\pi\big)}{(1+\frac n2)\pi}\right].$$ With $\sin(\pi-\frac{n\pi}2)=\sin\frac{n\pi}2$ and $\sin(\pi+\frac{n\pi}2)=-\sin\frac{n\pi}2$: $$b_n=\frac{\sin\frac{n\pi}2}{2\pi}\left[\frac{1}{1-\frac n2}+\frac{1}{1+\frac n2}\right]=\frac{\sin\frac{n\pi}2}{2\pi}\cdot\frac{2}{1-\frac{n^2}4}=\frac{4\sin\frac{n\pi}2}{\pi(4-n^2)}.$$

Even $n\ne2$: $\sin\frac{n\pi}2=0$, so $b_n=0$. Odd $n=2m-1$: $\sin\frac{(2m-1)\pi}2=(-1)^{m+1}$, so $$\boxed{b_2=\tfrac12,\qquad b_{2m-1}=\frac{4(-1)^{m+1}}{\pi\big(4-(2m-1)^2\big)},\quad m=1,2,\dots}$$ All other coefficients are $0$.

Do the special $n$ first, before you forget. The general formula at $n=2$ is $\frac{4\cdot0}{0}$: undefined, not zero, which is why $b_2$ survives while $b_4,b_6,\dots$ vanish. Sanity: $\frac12\sin(\pi x)$ alone already looks like $f$ on $(0,1)$. First few: $b_1=\frac4{3\pi}$, $b_3=\frac4{5\pi}$, $b_5=-\frac4{21\pi}$. Each step is a single product-to-sum; no integration by parts.

(d) · The series

$$f(x)=\frac12\sin(\pi x)+\frac4\pi\sum_{m=1}^\infty\frac{(-1)^{m+1}}{4-(2m-1)^2}\sin\frac{(2m-1)\pi x}2.$$

The $n=2$ term is $b_2\sin\frac{2\pi x}2=\frac12\sin\pi x$. Numerical check: at $x=1$ every term should sum to $f(1)=0$, and it does ($\sum\frac{1}{4-(2m-1)^2}$ telescopes to $0$). Equality holds everywhere here because the extension is continuous (Lesson 23).

(e) · Even version

Then $f$ is even, $b_n=0$, and $$a_n=\frac2L\int_0^L f\cos\frac{n\pi x}2\,dx=\int_0^1\sin(\pi x)\cos\frac{n\pi x}2\,dx.$$ Product-to-sum gives $\frac12[\sin((1-\frac n2)\pi x)+\sin((1+\frac n2)\pi x)]$; the first term's antiderivative has $1-\frac n2$ in the denominator, so $n=2$ needs separate treatment.

(If you did evaluate: $a_2=\int_0^1\tfrac12\sin2\pi x\,dx=0$ and $a_n=\frac{4(1+\cos\frac{n\pi}2)}{\pi(4-n^2)}$ otherwise, $a_0=\frac2\pi$. Not asked.)
