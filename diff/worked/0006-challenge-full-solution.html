Lesson 6 · Challenge · Full written solution

Diagonalisation with resonant forcing

Everything inside the red rule is what goes on your paper. The grey notes are commentary and you don't write them.

$\;x' = -x + 2y + 2e^{t},\;\; y' = 2x - y,\;\; x(0) = 1,\; y(0) = 0.$

(a) Solve the IVP by diagonalisation. (b) Compute $e^{At}$. (c) Describe $\mathbf y(t)$ as $t\to\infty$.

(a) · Solve the IVP

1 · Vector form

$\mathbf y = (x, y)^T$, so $\mathbf y' = A\mathbf y + \mathbf b$ with $$A = \begin{pmatrix}-1&2\\2&-1\end{pmatrix},\qquad \mathbf b = \begin{pmatrix}2e^{t}\\0\end{pmatrix},\qquad \mathbf y(0) = \begin{pmatrix}1\\0\end{pmatrix}.$$

The forcing $2e^t$ sits in the $x'$ equation, so it is the first entry of $\mathbf b$. Writing $(0, 2e^t)$ is the easiest slip to make here, and it changes the answer.

2 · Eigenvalues and eigenvectors

$\det(A - \lambda I) = (-1-\lambda)^2 - 4 = \lambda^2 + 2\lambda - 3 = (\lambda - 1)(\lambda + 3)$, so $\lambda = 1,\,-3$.

$\lambda = 1$: $(A - I)\mathbf v = \begin{pmatrix}-2&2\\2&-2\end{pmatrix}\mathbf v = \mathbf 0$ gives $\mathbf v_1 = (1,1)^T$.

$\lambda = -3$: $(A + 3I)\mathbf v = \begin{pmatrix}2&2\\2&2\end{pmatrix}\mathbf v = \mathbf 0$ gives $\mathbf v_2 = (1,-1)^T$.

$$S = \begin{pmatrix}1&1\\1&-1\end{pmatrix},\quad D = \begin{pmatrix}1&0\\0&-3\end{pmatrix},\quad \det S = -2,\quad S^{-1} = \frac12\begin{pmatrix}1&1\\1&-1\end{pmatrix}.$$

Shortcut: $\operatorname{tr}A = -2$ and $\det A = 1 - 4 = -3$, so $\lambda^2 + 2\lambda - 3 = 0$. A symmetric $\begin{pmatrix}a&b\\b&a\end{pmatrix}$ always has eigenvectors $(1,\pm1)$.

3 · Decouple

Put $\mathbf z = S^{-1}\mathbf y$. Since $A = SDS^{-1}$, multiplying $\mathbf y' = A\mathbf y + \mathbf b$ by $S^{-1}$ gives $$\mathbf z' = D\mathbf z + S^{-1}\mathbf b.$$ $$S^{-1}\mathbf b = \frac12\begin{pmatrix}1&1\\1&-1\end{pmatrix}\begin{pmatrix}2e^t\\0\end{pmatrix} = \begin{pmatrix}e^t\\e^t\end{pmatrix},\qquad \mathbf z(0) = S^{-1}\begin{pmatrix}1\\0\end{pmatrix} = \begin{pmatrix}\tfrac12\\\tfrac12\end{pmatrix}.$$ So $$z_1' = z_1 + e^t,\qquad z_2' = -3z_2 + e^t.$$

This is the step your page was missing. You don't expand $S^{-1}\mathbf y'$ or $DS^{-1}\mathbf y$ in terms of $x, y$. Name $\mathbf z = S^{-1}\mathbf y$ and the system splits into two scalar ODEs.

4 · Solve $z_1$ (resonant)

$z_1' - z_1 = e^t$. Integrating factor $e^{-t}$: $(e^{-t}z_1)' = e^{-t}(z_1' - z_1) = 1$, so $e^{-t}z_1 = t + C_1$ and $$z_1 = (t + C_1)e^t.$$ $z_1(0) = \tfrac12$ gives $C_1 = \tfrac12$.

The forcing $e^t$ has the same exponent as the homogeneous solution $e^{t}$ ($\lambda_1 = 1$). That is resonance, and it is why a $t$ appears. A guess of $ae^t$ would give $0 = 1$.

5 · Solve $z_2$

$z_2' + 3z_2 = e^t$. Integrating factor $e^{3t}$: $(e^{3t}z_2)' = e^{4t}$, so $e^{3t}z_2 = \tfrac14e^{4t} + C_2$ and $$z_2 = \tfrac14e^t + C_2e^{-3t}.$$ $z_2(0) = \tfrac12$ gives $\tfrac14 + C_2 = \tfrac12$, so $C_2 = \tfrac14$.

6 · Recouple

$\mathbf y = S\mathbf z$, that is, $x = z_1 + z_2$ and $y = z_1 - z_2$, with $z_1 = (t + \tfrac12)e^t$ and $z_2 = \tfrac14e^t + \tfrac14e^{-3t}$: $$\boxed{x = \big(t + \tfrac34\big)e^{t} + \tfrac14e^{-3t},\qquad y = \big(t + \tfrac14\big)e^{t} - \tfrac14e^{-3t}}$$

7 · Check

$x(0) = \tfrac34 + \tfrac14 = 1$ ✓ and $y(0) = \tfrac14 - \tfrac14 = 0$ ✓.

$x' = \big(t + \tfrac74\big)e^t - \tfrac34e^{-3t}$, and $-x + 2y + 2e^t = \big(-t - \tfrac34 + 2t + \tfrac12 + 2\big)e^t + \big(-\tfrac14 - \tfrac12\big)e^{-3t} = \big(t + \tfrac74\big)e^t - \tfrac34e^{-3t}$ ✓.

$y' = \big(t + \tfrac54\big)e^t + \tfrac34e^{-3t}$, and $2x - y = \big(2t + \tfrac32 - t - \tfrac14\big)e^t + \big(\tfrac12 + \tfrac14\big)e^{-3t} = \big(t + \tfrac54\big)e^t + \tfrac34e^{-3t}$ ✓.

(b) · The matrix exponential

$A$ is diagonalisable, so $e^{At} = Se^{Dt}S^{-1}$ with $e^{Dt} = \operatorname{diag}(e^{t}, e^{-3t})$: $$Se^{Dt} = \begin{pmatrix}e^{t}&e^{-3t}\\e^{t}&-e^{-3t}\end{pmatrix},$$ $$e^{At} = \frac12\begin{pmatrix}e^{t}&e^{-3t}\\e^{t}&-e^{-3t}\end{pmatrix}\begin{pmatrix}1&1\\1&-1\end{pmatrix} = \boxed{\frac12\begin{pmatrix}e^{t}+e^{-3t}&e^{t}-e^{-3t}\\e^{t}-e^{-3t}&e^{t}+e^{-3t}\end{pmatrix}}$$

Check: at $t=0$ this is $I$ ✓. Column 1 differentiated at $0$ is $\tfrac12(1-3,\;1+3) = (-1, 2)$, which is column 1 of $A$ ✓.

The homogeneous part of the answer to (a) is $e^{At}\mathbf y(0)$, which is just column 1 here: $\tfrac12\big(e^t + e^{-3t},\; e^t - e^{-3t}\big)$.

(c) · Long-term behaviour

As $t\to\infty$, $e^{-3t}\to0$ and $te^{t}$ dominates $e^{t}$, so $$\mathbf y(t) \sim t\,e^{t}\begin{pmatrix}1\\1\end{pmatrix}.$$ Growth rate: $te^{t}$ (faster than any pure exponential $e^{\lambda t}$ with $\lambda \le 1$). Direction: along the $\lambda = 1$ eigenvector $(1,1)$, since $x/y = \dfrac{(t+\frac34)e^t + \dots}{(t+\frac14)e^t - \dots} \to 1$.

The extra factor of $t$ is the signature of resonance. Without it, the growth would be plain $e^{t}$.
