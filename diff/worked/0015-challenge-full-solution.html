The challenge, written out as an exam answer

Everything inside the red rule is what goes on your paper. The grey notes explain the reasoning, and you don't write them. Printing this page hides the notes.

$y''+3y'+2y=f(t),\;\; y(0)=0,\; y'(0)=1$, with $f(t)=t$ for $0\le t<2$ and $f(t)=2$ for $t\ge2$.

(a) Write $f$ using one Heaviside function and find $F(s)$. [2]
(b) Find $Y(s)$, and decompose every part into partial fractions. [4]
(c) Find $y(t)$ with a Heaviside, then as an explicit piecewise function. [3]
(d) Show $y,y',y''$ are continuous at $t=2$, say which derivative first jumps and by how much, and find $\lim_{t\to\infty}y$. [3]

(a) · Heaviside form and $F(s)$

At $t=2$ the function changes from $t$ to $2$, a change of $2-t=-(t-2)$. So $$f(t)=t-(t-2)\,H_2(t).$$ The second term is already a function of $t-2$, so the t-shift applies directly: $$F(s)=\frac1{s^2}-\frac{e^{-2s}}{s^2}=\frac{1-e^{-2s}}{s^2}.$$

Lucky case: the change $-(t-2)$ is already shifted. Had it been "2" to "$t^2$", you would use $h(u)=(u+2)^2$. Check: for $t\ge2$, $t-(t-2)=2$ ✓.

(b) · Transform the ODE

Using $\mathcal L\{y''\}=s^2Y-sy(0)-y'(0)=s^2Y-1$ and $\mathcal L\{y'\}=sY$: $$(s^2+3s+2)Y-1=\frac{1-e^{-2s}}{s^2}\;\Rightarrow\; Y=\frac1{(s+1)(s+2)}+\frac{1-e^{-2s}}{s^2(s+1)(s+2)}.$$ Partial fractions: $$\frac1{(s+1)(s+2)}=\frac1{s+1}-\frac1{s+2}.$$ $$\frac1{s^2(s+1)(s+2)}=\frac As+\frac B{s^2}+\frac C{s+1}+\frac D{s+2}.$$ Cover-up: $B=\dfrac1{1\cdot2}=\dfrac12$, $\;C=\dfrac1{(-1)^2(1)}=1$, $\;D=\dfrac1{(-2)^2(-1)}=-\dfrac14$. The left side is $O(1/s^4)$, so the $1/s$ coefficients sum to zero: $A+C+D=0$, hence $A=-\dfrac34$. $$\frac1{s^2(s+1)(s+2)}=-\frac3{4s}+\frac1{2s^2}+\frac1{s+1}-\frac1{4(s+2)}.$$

Alternative for $A$: differentiate $\frac1{(s+1)(s+2)}$ at $s=0$: $-\frac{2s+3}{(s+1)^2(s+2)^2}\big|_0=-\frac34$. Quick check at $s=1$: LHS $\frac1{1\cdot2\cdot3}=\frac16$; RHS $-\frac34+\frac12+\frac12-\frac1{12}=\frac16$ ✓.

(c) · Invert

Let $h(t)=\mathcal L^{-1}\!\left\{\dfrac1{s^2(s+1)(s+2)}\right\}=-\dfrac34+\dfrac t2+e^{-t}-\dfrac14e^{-2t}$. Then $$y(t)=\underbrace{e^{-t}-e^{-2t}}_{\text{from }\frac1{(s+1)(s+2)}}+h(t)-h(t-2)\,H_2(t).$$ For $0\le t<2$: $$y=e^{-t}-e^{-2t}+h(t)=-\frac34+\frac t2+2e^{-t}-\frac54e^{-2t}.$$ For $t\ge2$, using $h(t)-h(t-2)=1+e^{-t}-\tfrac14e^{-2t}-e^{2-t}+\tfrac14e^{4-2t}$: $$y=1+(2-e^2)\,e^{-t}+\frac{e^4-5}{4}\,e^{-2t}.$$

Check first piece: $y(0)=-\frac34+2-\frac54=0$ ✓; $y'=\frac12-2e^{-t}+\frac52e^{-2t}$, $y'(0)=1$ ✓. For $t\ge2$ the $t/2$ and $-\frac34$ cancel because $h(t)$ and $h(t-2)$ share the same constant; the leftover $+1$ comes from $\frac t2-\frac{t-2}2$.

(d) · Continuity, first jump, long run

Only the term $-h(t-2)H_2(t)$ changes at $t=2$, so look at the start-up values of $h$: $h(0)=-\tfrac34+1-\tfrac14=0$; $\;h^{(1)}(t)=\tfrac12-e^{-t}+\tfrac12e^{-2t}$ gives $h^{(1)}(0)=0$; $\;h^{(2)}(t)=e^{-t}-e^{-2t}$ gives $h^{(2)}(0)=0$; $\;h^{(3)}(t)=-e^{-t}+2e^{-2t}$ gives $h^{(3)}(0)=1$.

So $y,y',y''$ have no jump at $t=2$, while $y^{(3)}$ jumps by $\boxed{-1}$.

Consistent with the ODE: $y^{(3)}=f'-3y''-2y'$, and $f'$ drops from $1$ to $0$ at $t=2$.

For $t\ge2$, $e^{-t},e^{-2t}\to0$, so $\displaystyle\lim_{t\to\infty}y=\boxed1$. Interpretation: the load is held at $2$, and the mass settles where the spring balances it: $2y=2$.

$f$ is continuous at $2$ (the ramp reaches $2$) but $f'$ is not, so the first jump is one derivative higher than for a jump in $f$ itself. Lecture 13 slide 5: $y^{(n)}$ is continuous wherever $g$ is. No need to evaluate both pieces at $t=2$: the zero start-up values guarantee they match.
