Q1 (d)

$$(t^2+1)\,y' - 2t\,y = t^2+1$$

Standard form and $I$

Divide by $t^2+1$ (never zero, so there are no bad points): $$y' - \frac{2t}{t^2+1}\,y = 1.$$ $\int -\dfrac{2t}{t^2+1}\,dt = -\ln(t^2+1)$, so $$I = e^{-\ln(t^2+1)} = \frac{1}{t^2+1}.$$

Collapse and integrate

$$\Big(\frac{y}{t^2+1}\Big)' = \frac{1}{t^2+1} \quad\Longrightarrow\quad \frac{y}{t^2+1} = \arctan t + C.$$

Answer

$$\boxed{y = (t^2+1)\big(\arctan t + C\big)}, \qquad t\in\mathbb R.$$

Note: the right side became $\frac{1}{t^2+1}$ after multiplying by $I$. Spot $\int\frac{1}{1+t^2} = \arctan t$ instantly; it comes up again in Laplace.

Q1 (e)

$$t\,y' + (t+1)\,y = 3e^{-t}$$

Standard form and $I$

Divide by $t$: $$y' + \Big(1 + \frac1t\Big)y = \frac{3e^{-t}}{t}.$$ $\int\big(1+\frac1t\big)dt = t + \ln t$, so $$I = e^{t+\ln t} = e^t\cdot e^{\ln t} = t\,e^{t}.$$ Split the exponent: $e^{a+b} = e^a e^b$. (For $t<0$ you'd get $|t|e^t$, but a constant sign doesn't matter in $I$.)

Collapse and integrate

$$(t e^t y)' = t e^t\cdot\frac{3e^{-t}}{t} = 3 \quad\Longrightarrow\quad t e^t y = 3t + C.$$ Everything cancels. That's the sign you chose $I$ right.

Answer

$$\boxed{y = 3e^{-t} + \frac{C\,e^{-t}}{t}}, \qquad t>0 \text{ or } t<0.$$ In Lesson 2's terms: $y_c = Ce^{-t}/t$, $\;y_p = 3e^{-t}$.

Q1 (f)

$$t\,y' + 2y = e^{t} + \log t$$

Standard form and $I$

$\log t$ forces $t>0$. Divide by $t$: $$y' + \frac2t\,y = \frac{e^t + \ln t}{t}, \qquad I = e^{2\ln t} = t^2.$$

Collapse

$$(t^2 y)' = t^2\cdot\frac{e^t + \ln t}{t} = t\,e^t + t\ln t.$$

The two integrals (by parts)

First: $u = t$, $dv = e^t\,dt$: $$\int t e^t\,dt = t e^t - \int e^t\,dt = (t-1)e^t.$$

Second: $u = \ln t$ (the log is always $u$), $dv = t\,dt$: $$\int t\ln t\,dt = \frac{t^2}{2}\ln t - \int \frac{t^2}{2}\cdot\frac1t\,dt = \frac{t^2}{2}\ln t - \frac{t^2}{4}.$$

So $t^2 y = (t-1)e^t + \tfrac{t^2}{2}\ln t - \tfrac{t^2}{4} + C$.

Answer

Divide by $t^2$, including the $C$: $$\boxed{y = \frac{(t-1)e^t}{t^2} + \frac{\ln t}{2} - \frac14 + \frac{C}{t^2}}, \qquad t>0.$$

Q2 (b)

$$y' + t\,y = t^3, \qquad y(0) = 3$$

Interval first

Already in standard form. $f = t$ and $g = t^3$ are continuous everywhere, so there are no bad points: valid on $\mathbb R$.

$I$ and collapse

$I = e^{\int t\,dt} = e^{t^2/2}$, so $$\big(e^{t^2/2}y\big)' = t^3 e^{t^2/2}.$$

The integral (substitute, then by parts)

Let $u = \tfrac{t^2}{2}$, so $du = t\,dt$ and $t^2 = 2u$. Then $t^3\,dt = t^2\cdot t\,dt = 2u\,du$: $$\int t^3 e^{t^2/2}\,dt = \int 2u\,e^u\,du = 2(u-1)e^u = (t^2-2)\,e^{t^2/2}.$$ Trick: split $t^3 = t^2\cdot t$ so that one $t$ goes with $dt$ to make $du$.

General solution, IC, answer

$e^{t^2/2}y = (t^2-2)e^{t^2/2} + C \;\Rightarrow\; y = t^2 - 2 + Ce^{-t^2/2}$.
$y(0) = -2 + C = 3 \;\Rightarrow\; C = 5$: $$\boxed{y = t^2 - 2 + 5e^{-t^2/2}}, \qquad t\in\mathbb R.$$

Q2 (c)

$$y' + \frac{4y}{t+2} = 3, \qquad y(0) = -5$$

Interval first

The only bad point is $t = -2$. Since $t_0 = 0 > -2$, the interval is $(-2,\infty)$.

$I$ and collapse

$I = e^{4\ln(t+2)} = (t+2)^4$, so $$\big((t+2)^4 y\big)' = 3(t+2)^4 \quad\Longrightarrow\quad (t+2)^4 y = \tfrac35(t+2)^5 + C.$$

General solution, IC, answer

$y = \tfrac35(t+2) + C(t+2)^{-4}$.
$y(0) = \tfrac65 + \tfrac{C}{16} = -5 \;\Rightarrow\; \tfrac{C}{16} = -\tfrac{31}{5} \;\Rightarrow\; C = -\tfrac{496}{5}$: $$\boxed{y = \frac{3(t+2)}{5} - \frac{496}{5(t+2)^4}}, \qquad t\in(-2,\infty).$$ Ugly constants are normal. Don't panic if $C$ isn't a nice number. Check $y(0)$ again instead.

Q2 (f)

$$y' + \frac{2y}{t} = \frac{1}{t^2}, \qquad y(t_0) = y_0$$

Interval first (the point of this question)

The only bad point is $t = 0$, which splits the line into two pieces. Which one you get depends on $t_0$:

  • If $t_0 > 0$: valid on $(0,\infty)$.
  • If $t_0 < 0$: valid on $(-\infty,0)$.
  • If $t_0 = 0$: the theorem guarantees nothing. In fact you can't even impose $y(0) = y_0$, because the solutions below aren't defined at $0$.
$I$ and collapse

$I = e^{2\ln|t|} = t^2$ (fine for both signs of $t$). Then $$(t^2 y)' = 1 \quad\Longrightarrow\quad t^2 y = t + C \quad\Longrightarrow\quad y = \frac1t + \frac{C}{t^2}.$$

Apply the symbolic IC, answer

$y_0 = \dfrac{1}{t_0} + \dfrac{C}{t_0^2} \;\Rightarrow\; C = y_0t_0^2 - t_0$: $$\boxed{y = \frac1t + \frac{y_0t_0^2 - t_0}{t^2}}$$ on $(0,\infty)$ if $t_0>0$, or on $(-\infty,0)$ if $t_0<0$.

Check: put $t = t_0$: $\;\frac{1}{t_0} + y_0 - \frac{1}{t_0} = y_0$ ✓

Patterns to take away

  • Everything cancels after multiplying by $I$ (Q1e, Q2c, Q2f). This happens a lot and is a good sign your $I$ is right.
  • $e^{a+\ln t} = t\,e^{a}$: split the exponent before simplifying.
  • By parts with a log: the log is always $u$.
  • $t^3e^{t^2/2}$: split off one $t$ for the substitution.
  • Symbolic $t_0$: the answer is a case split on the sign of $t_0$.
