Lesson 7 · Exam-level challenge · Full written solution

The challenge, written out as an exam answer

Everything inside the red rule is what goes on your paper. The grey notes explain the reasoning, and you don't write them. Printing this page hides the notes.

Consider $\;t^2y'' - t(t+2)\,y' + (t+2)\,y = 2t^3e^{t},\quad t>0$.

(a) Show that $v = t$ is a complementary solution.
(b) Use reduction of order to find the general solution. Identify $y_c$ and $y_p$, and prove the complementary solutions are linearly independent.
(c) Solve the IVP with $y(1) = 0,\; y'(1) = 2e$, and state the interval of validity.

Write thisDon't write this

(a) · $v = t$ is a complementary solution

With $v = t$: $\;v' = 1$, $\;v'' = 0$. Substituting into the homogeneous equation:

$$t^2\cdot 0 - t(t+2)\cdot 1 + (t+2)\cdot t = -t(t+2) + t(t+2) = 0.$$

So $v = t$ is a complementary solution.

The test $Q + tR = 0$ is how you'd spot it, but "show" means substitute and get $0$ on the page.

(b) 1 · Standard form

Dividing by $t^2$ (valid since $t>0$):

$$y'' - \frac{t+2}{t}\,y' + \frac{t+2}{t^2}\,y = 2t\,e^{t},$$

so $\;f_1(t) = -\dfrac{t+2}{t} = -1 - \dfrac2t\;$ and $\;g(t) = 2t\,e^{t}$.

$g = 2te^t$, not $2t^3e^t$. Getting this wrong ruins every line after it. Splitting $f_1$ into $-1 - 2/t$ now makes the next integral one line.

(b) 2 · Reduce the order

Let $y = u(t)\,t$. Then $y' = u't + u$ and $y'' = u''t + 2u'$. Substituting into the original ODE:

$$t^2(u''t + 2u') - t(t+2)(u't + u) + (t+2)\,u\,t = 2t^3e^{t}$$ $$t^3u'' + \big(2t^2 - t^2(t+2)\big)u' + \big(-t(t+2) + t(t+2)\big)u = 2t^3e^{t}$$ $$t^3u'' - t^3u' = 2t^3e^{t}.$$

Dividing by $t^3$ and letting $w = u'$:

$$w' - w = 2e^{t}.$$

Show the line where the $u$ coefficient collapses to $0$. It proves $v$ works and markers look for it. The formula route gives the same thing: $I = v^2e^{\int f_1} = t^2\cdot e^{-t}/t^2 = e^{-t}$ and $Ig/v = 2$. If the question says "use reduction of order", the substitution above is the safe version. The formula is fine as a check.

(b) 3 · Integrating factor and first integration

Integrating factor $I = e^{\int -1\,dt} = e^{-t}$:

$$(e^{-t}w)' = 2 \quad\Longrightarrow\quad e^{-t}w = 2t + C_1 \quad\Longrightarrow\quad w = (2t + C_1)\,e^{t}.$$

Keep $C_1$. It becomes your second complementary solution.

(b) 4 · Second integration

By parts, $\int t\,e^{t}\,dt = t\,e^{t} - \int e^{t}\,dt = (t-1)\,e^{t}$, so

$$u = \int w\,dt = 2(t-1)\,e^{t} + C_1e^{t} + C_2.$$

(b) 5 · General solution, $y_c$ and $y_p$

$$y = u\,t = 2t(t-1)\,e^{t} + C_1\,t\,e^{t} + C_2\,t = 2t^2e^{t} + (C_1 - 2)\,t\,e^{t} + C_2\,t.$$

Writing $A = C_1 - 2$ and $B = C_2$:

$$y = \underbrace{A\,t\,e^{t} + B\,t}_{y_c} \;+\; \underbrace{2t^2e^{t}}_{y_p},$$

with $A, B$ arbitrary constants.

The $-2te^t$ from $2t(t-1)e^t$ is a complementary solution, so it's absorbed into $A$. Leaving $y_p = 2t(t-1)e^t$ isn't wrong, just untidy. Show the renaming line so the marker can follow it.

(b) 6 · Linear independence

With $y_1 = t\,e^{t}$, $y_1' = (1+t)\,e^{t}$, and $y_2 = t$, $y_2' = 1$:

$$\operatorname{wr}[y_1, y_2](t) = \begin{vmatrix} t\,e^{t} & t \\ (1+t)\,e^{t} & 1 \end{vmatrix} = t\,e^{t} - t(1+t)\,e^{t} = -t^2e^{t}.$$

Since $\operatorname{wr} = -t^2e^{t} \neq 0$ for $t>0$, $\;t\,e^{t}$ and $t$ are linearly independent solutions on $(0,\infty)$. So $y_c = A\,t\,e^{t} + B\,t$ is the general complementary solution.

The sign depends on the order you list them in: the lesson used $[t,\,te^t]$ and got $+t^2e^t$. Either is fine. What matters is "$\neq 0$, so independent", written out. Abel check in the margin: $\operatorname{wr} = C\,e^{-\int f_1} = C\,e^{t + 2\ln t} = C\,t^2e^t$ ✓, with $C = -1$ here.

(c) 1 · Interval of validity

In standard form, the coefficients $-\dfrac{t+2}{t}$, $\;\dfrac{t+2}{t^2}$ and $2t\,e^{t}$ are continuous except at $t = 0$. The initial point $t_0 = 1$ lies in $(0,\infty)$, so by the existence and uniqueness theorem the IVP has a unique solution on $(0,\infty)$.

Name the theorem and say which functions are continuous. That sentence is usually worth its own mark.

(c) 2 · Initial conditions

Differentiating the general solution:

$$y' = 2(t^2 + 2t)\,e^{t} + A(1+t)\,e^{t} + B.$$

Then

$$\begin{aligned} y(1) &= 2e + Ae + B = 0, &\quad&(1)\\ y'(1) &= 6e + 2Ae + B = 2e. &&(2) \end{aligned}$$

$(2) - (1)$: $\;4e + Ae = 2e$, so $A = -2$.

Substituting into $(1)$: $\;2e - 2e + B = 0$, so $B = 0$.

Product rule on $2t^2e^t$: $(4t + 2t^2)e^t$. Number the equations so you can write "(2) − (1)" instead of rewriting both.

(c) 3 · Answer

$$\boxed{\,y = 2t^2e^{t} - 2t\,e^{t} = 2t(t-1)\,e^{t}, \qquad t\in(0,\infty).\,}$$

Check (on paper if time allows)

ICs: $\;y(1) = 2\cdot1\cdot0\cdot e = 0$ ✓. With $y' = 2(2t-1)\,e^{t} + 2t(t-1)\,e^{t} = 2(t^2 + t - 1)\,e^{t}$, $\;y'(1) = 2e$ ✓.

Particular solution: $y_p = 2t^2e^t$, $\;y_p' = 2(t^2 + 2t)\,e^t$, $\;y_p'' = 2(t^2 + 4t + 2)\,e^t$.

$$\begin{aligned} t^2y_p'' - t(t+2)\,y_p' + (t+2)\,y_p &= 2e^t\Big[t^4 + 4t^3 + 2t^2 - t^2(t+2)^2 + t^3 + 2t^2\Big] \\ &= 2e^t\Big[t^4 + 5t^3 + 4t^2 - (t^4 + 4t^3 + 4t^2)\Big] \\ &= 2t^3e^{t} \;✓ \end{aligned}$$

The IC check takes about 20 seconds and catches most arithmetic slips. Only do the $y_p$ check if you have time to spare.
