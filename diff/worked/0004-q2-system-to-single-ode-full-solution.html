Quiz Q2: turning a system into one ODE for $x$

The quiz lets you jump straight to the answer with the trace/determinant shortcut. An exam usually says "derive" or "show", so you need the elimination written out. Everything inside the red rule is what goes on your paper. The grey notes explain the reasoning, and you don't write them. Printing this page hides the notes.

Consider the system $\;x' = 3x - y,\quad y' = 4x - 2y.$

(a) Show that $x(t)$ satisfies a single second-order linear ODE, and find it.

(b) Given $x(0) = 1$ and $y(0) = 0$, find the initial conditions for that ODE, then solve for $x(t)$ and $y(t)$.

Part (b) isn't in the quiz. It's added because exams usually attach ICs, and getting $x'(0)$ and recovering $y$ are where marks are lost.

0 · The idea

The two equations are linked: $x'$ depends on $y$, and $y'$ depends on $x$. The trick is that the first equation can be rearranged to give $y$ in terms of $x$ and $x'$:

$$x' = 3x - y \quad\Longrightarrow\quad y = 3x - x'.$$

So $y$ isn't really a separate unknown. Once you know $x$, you know $y$. Every time a $y$ or a $y'$ appears, you can swap it for something involving only $x$. Differentiating is what lets you bring in the second equation.

1 · Differentiate the first equation

Differentiating $x' = 3x - y$ with respect to $t$:

$$x'' = 3x' - y'. \tag{1}$$

Why differentiate? The answer has to be second order, so you need an $x''$. Differentiating also produces a $y'$, which is exactly what the second equation tells you.

2 · Substitute the second equation for $y'$

Using $y' = 4x - 2y$ in (1):

$$x'' = 3x' - (4x - 2y) = 3x' - 4x + 2y. \tag{2}$$

Keep the brackets until you've distributed the minus sign. Writing $3x' - 4x - 2y$ is the most common slip at this step.

3 · Eliminate $y$ using the first equation

From $x' = 3x - y$ we have $y = 3x - x'$. Substituting into (2):

$$\begin{aligned} x'' &= 3x' - 4x + 2(3x - x') \\ &= 3x' - 4x + 6x - 2x' \\ &= x' + 2x. \end{aligned}$$

Hence

$$\boxed{\,x'' - x' - 2x = 0.\,}$$

Now there's no $y$ left, so you're done. Gather the $x'$ terms ($3x' - 2x' = x'$) and the $x$ terms ($-4x + 6x = 2x$) separately.

4 · Check with trace and determinant (scratch work)

$A = \begin{pmatrix}3 & -1\\ 4 & -2\end{pmatrix}$, $\;\operatorname{tr}A = 3 + (-2) = 1$, $\;\det A = (3)(-2) - (-1)(4) = -6 + 4 = -2$.

$$x'' - (\operatorname{tr}A)\,x' + (\det A)\,x = x'' - x' - 2x \;✓$$

Do this in the margin. If it doesn't match, there's a sign slip in steps 2 or 3. In $\det A = ad - bc$, $b = -1$ and $c = 4$, so $-bc = +4$.

5 · Initial conditions for the single ODE

We need $x(0)$ and $x'(0)$. We have $x(0) = 1$, and from the first equation of the system,

$$x'(0) = 3x(0) - y(0) = 3(1) - 0 = 3.$$

A second-order ODE needs $x(0)$ and $x'(0)$, but the question gives you $x(0)$ and $y(0)$. The system equation for $x'$ converts one into the other. Don't write $x'(0) = 0$ by copying $y(0)$.

6 · Solve for $x(t)$

Trying $x = e^{\lambda t}$: $\;\lambda^2 - \lambda - 2 = (\lambda - 2)(\lambda + 1) = 0$, so $\lambda = 2, -1$ and

$$x = C_1e^{2t} + C_2e^{-t}, \qquad x' = 2C_1e^{2t} - C_2e^{-t}.$$

Applying the ICs:

$$x(0) = C_1 + C_2 = 1, \qquad x'(0) = 2C_1 - C_2 = 3.$$

Adding these: $3C_1 = 4$, so $C_1 = \tfrac43$ and $C_2 = -\tfrac13$. Therefore

$$x(t) = \tfrac13\big(4e^{2t} - e^{-t}\big).$$

7 · Recover $y(t)$

From $y = 3x - x'$:

$$\begin{aligned} y &= \big(4e^{2t} - e^{-t}\big) - \tfrac13\big(8e^{2t} + e^{-t}\big) \\ &= \tfrac13\big(12e^{2t} - 3e^{-t} - 8e^{2t} - e^{-t}\big) \\ &= \tfrac43\big(e^{2t} - e^{-t}\big). \end{aligned}$$ $$\boxed{\,x(t) = \tfrac13\big(4e^{2t} - e^{-t}\big), \qquad y(t) = \tfrac43\big(e^{2t} - e^{-t}\big).\,}$$

Use the same rearrangement as in step 3, not a second ODE for $y$. Solving a separate ODE for $y$ would bring in two new constants that you'd then have to match up. Here $y$ comes out with no new constants.

8 · Verify

$x(0) = \tfrac13(4 - 1) = 1$ ✓ and $y(0) = \tfrac43(1 - 1) = 0$ ✓.

$y' = \tfrac43\big(2e^{2t} + e^{-t}\big)$ and $4x - 2y = \tfrac13\big(16e^{2t} - 4e^{-t}\big) - \tfrac83\big(e^{2t} - e^{-t}\big) = \tfrac13\big(8e^{2t} + 4e^{-t}\big)$ ✓.

You only need to check the second equation. The first one, $x' = 3x - y$, holds automatically because that's how you built $y$.

Why the shortcut always works

Do the same steps for a general system $x' = ax + by,\; y' = cx + dy$ with $b \neq 0$:

  1. Differentiate: $x'' = ax' + by'$.
  2. Substitute $y'$: $x'' = ax' + b(cx + dy) = ax' + bcx + d\,(by)$.
  3. Eliminate using $by = x' - ax$: $x'' = ax' + bcx + d(x' - ax) = (a + d)x' - (ad - bc)x$.
  4. So $x'' - (a + d)x' + (ad - bc)x = 0$, that is, $x'' - (\operatorname{tr}A)x' + (\det A)x = 0$.

Notice that step 3 substitutes for $by$ as a whole, so you never divide by $b$. If $b = 0$, the first equation is just $x' = ax$ and doesn't involve $y$ at all, so solve it directly.
