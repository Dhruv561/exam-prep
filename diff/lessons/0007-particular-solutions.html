Lesson 7 · Topic 1: Linear ODEs & IVPs · Targeted

Particular solutions: what to substitute, and when

The goal: look at any inhomogeneous linear ODE and know straight away which of two methods to use. One is a machine that always works. The other is a fast shortcut for nice equations. Then run the method without second-guessing.

Why this matters for 5 Nov: almost every Topic 1 question ends with "find the general solution", and the marks for $y_p$ are where most people stall. Lessons 2 and 3 taught the machine. This lesson is about choosing it confidently, plus a shortcut you can use to check it.

0 · Warm-up from Lessons 2–3

W1. For $\;t\,y'' + 2y' = 6t\;$ ($t>0$), the $g$ you use in reduction of order is…

Divide by $t$ first: $y'' + \tfrac2t y' = 6$. Using $g$ from before dividing is the most common way $y_p$ comes out wrong.

W2. You know $v = t^2$ and, from Abel, $\operatorname{wr} = t^3$. The reduction-of-order factor $I = v^2e^{\int f_1}$ is…

$e^{\int f_1} = 1/\operatorname{wr}$ (Abel with $C = 1$), so $I = v^2/\operatorname{wr} = t^4/t^3 = t$. If you already have the Wronskian, $I$ costs no integral.

1 · The decision: which method?

There are only two ways to get $y_p$ for a single second-order ODE in this course. You never have to guess, because the machine always works. Guessing is just faster when the equation is nice.

  1. First order? Use an integrating factor (Lesson 1). $y_p$ is the $\int Ig$ part.
  2. Does the question say "reduction of order", or give you $v$? Use the machine (§2). Do what you're told.
  3. Constant coefficients or Euler, and the forcing is built from $e^{kt}$, polynomials, $\sin$/$\cos$ (or $t^k$ and $\ln t$ for Euler)? Use the shortcut (§3): predict the shape of $y_p$, substitute it, and match coefficients.
  4. Anything else (coefficients that depend on $t$, or forcing like $1/t$ or $\tan t$)? Use the machine. Find $v$ with the Lesson 2 tests first.
  5. A system $\mathbf y' = A\mathbf y + \mathbf b$? Diagonalise (Lesson 6). That's the course's official method for constant-coefficient inhomogeneous problems (Lecture 6, summary slide).

"I never know what to substitute" has a fixed answer for each method. In the machine you always substitute $y = u\,v$. In the shortcut, a table (§3) tells you the shape.

2 · The machine: reduction of order

Five steps, the same every time. You need one complementary solution $v$.

  1. Standard form. Divide by the $y''$ coefficient. Read off $f_1$ and $g$, after dividing.
  2. $I = v^2e^{\int f_1}$. (Or $I = v^2/\operatorname{wr}$ if you already have the Wronskian.)
  3. $(Iw)' = \dfrac{Ig}{v}$. Integrate, and add $C_1$.
  4. $w = \dfrac{1}{I}(\dots)$, then $u = \displaystyle\int w\,dt$. Add $C_2$.
  5. $y = uv$. The terms with no constant are $y_p$. The terms with $C_1$ and $C_2$ are $y_c$.

You never decide what $y_p$ looks like. It's whatever is left without a $C$. The only skill involved is doing the two integrals.

Pick the right $v$
If you know both complementary solutions, use the one that matches the forcing as $v$. Then $g/v$ simplifies, and the integrals usually avoid by-parts. Example A shows both choices.

Example A: constant coefficients, resonant forcing

$$y'' - 4y' + 3y = 2e^{3t}$$

Complementary solutions

$\lambda^2 - 4\lambda + 3 = (\lambda-1)(\lambda-3)$, so $y_c = C_1e^{t} + C_2e^{3t}$. The forcing $e^{3t}$ matches one of them, so take $v = e^{3t}$.

Steps 1–3

Already in standard form: $f_1 = -4$, $g = 2e^{3t}$. $$I = e^{6t}\cdot e^{-4t} = e^{2t}, \qquad \frac{Ig}{v} = \frac{e^{2t}\cdot 2e^{3t}}{e^{3t}} = 2e^{2t}.$$ $$(e^{2t}w)' = 2e^{2t} \;\Rightarrow\; e^{2t}w = e^{2t} + C_1 \;\Rightarrow\; w = 1 + C_1e^{-2t}.$$

Steps 4–5

$u = t - \tfrac{C_1}{2}e^{-2t} + C_2$, so $$y = uv = \underbrace{t\,e^{3t}}_{y_p} \;-\; \tfrac{C_1}{2}e^{t} + C_2e^{3t}.$$ There were no by-parts integrals at all. With $v = e^{t}$ instead, you'd get $Ig/v = 2$, then $w = (2t + C_1)e^{2t}$, and $\int 2t\,e^{2t}$ needs by-parts. That still works, but it's slower.

Example B: Euler, resonant forcing

$$t^2y'' - 2t\,y' + 2y = 2t^2, \qquad t>0$$

Complementary solutions

Indicial: $n(n-1) - 2n + 2 = (n-1)(n-2)$, so $y_c = C_1t + C_2t^2$. The forcing is $t^2$, so take $v = t^2$.

The machine

Standard form: $f_1 = -2/t$, $\;g = 2$ (not $2t^2$!). $$I = t^4\cdot t^{-2} = t^2, \qquad \frac{Ig}{v} = \frac{t^2\cdot 2}{t^2} = 2.$$ $$(t^2w)' = 2 \;\Rightarrow\; w = \frac2t + \frac{C_1}{t^2} \;\Rightarrow\; u = 2\ln t - \frac{C_1}{t} + C_2.$$ $$y = uv = \underbrace{2t^2\ln t}_{y_p} - C_1t + C_2t^2.$$

Example C: variable coefficients (machine only)

$$t\,y'' - (2t+1)\,y' + (t+1)\,y = t^2e^{t}, \qquad t>0$$

The coefficients depend on $t$ and it isn't Euler, so the shortcut table doesn't apply. This is the case where people freeze, and the machine doesn't care.

Find $v$

$P + Q + R = t - (2t+1) + (t+1) = 0$, so $v = e^{t}$.

Steps 1–3

Divide by $t$: $f_1 = -2 - \tfrac1t$, $\;g = t\,e^{t}$. $$e^{\int f_1} = e^{-2t - \ln t} = \frac{e^{-2t}}{t}, \qquad I = e^{2t}\cdot\frac{e^{-2t}}{t} = \frac1t, \qquad \frac{Ig}{v} = \frac{1}{t}\cdot\frac{t\,e^{t}}{e^{t}} = 1.$$ $$\Big(\frac wt\Big)' = 1 \;\Rightarrow\; w = t^2 + C_1t.$$

Steps 4–5

$u = \tfrac{t^3}{3} + \tfrac{C_1}{2}t^2 + C_2$, so $$y = \underbrace{\tfrac13\,t^3e^{t}}_{y_p} + A\,t^2e^{t} + B\,e^{t}.$$ That gives $y_c$ for free as well: $t^2e^t$ is the second complementary solution.

3 · The shortcut: predict the shape

When the coefficients are constant, every derivative of $e^{kt}$, $t^m$, $\sin$ or $\cos$ stays in the same family. So $y_p$ must be built from the same pieces as the forcing. Write the shape with unknown constants, substitute, and match coefficients.

Constant coefficients (roots $\lambda$ of the characteristic equation):

Forcing $g$Try
$e^{kt}$$A\,e^{kt}$
Polynomial of degree $m$A full polynomial of degree $m$: $A_mt^m + \dots + A_0$
$\cos\omega t$ or $\sin\omega t$$A\cos\omega t + B\sin\omega t$ (always both)
Products, like $t\,e^{kt}$Product of the shapes: $(At + B)\,e^{kt}$

Resonance rule: if the forcing's exponent ($k$, or $0$ for a polynomial, or $\pm i\omega$ for trig) is a root of multiplicity $s$, multiply the whole guess by $t^s$.

Euler equations are constant-coefficient in disguise: $t = e^{s}$ turns $t^k$ into $e^{ks}$ and $\ln t$ into $s$. So:

Forcing $g$Try
$t^k$$A\,t^k$
$\ln t$ or a constant$A\ln t + B$, or just $A$

Resonance rule: if $k$ is a root of the indicial equation of multiplicity $s$, multiply by $(\ln t)^s$.

Two ways the shortcut goes wrong
(1) Missing resonance. Trying $Ae^{3t}$ in Example A gives $A(9 - 12 + 3)e^{3t} = 0 \ne 2e^{3t}$. If the left side vanishes, you've hit resonance, so multiply by $t$.
(2) Half a trig guess. $\cos t$ forcing still needs $A\cos t + B\sin t$, unless there's no $y'$ term. Derivatives swap $\sin$ and $\cos$.
Check Example A with the shortcut

$k = 3$ is a single root, so try $y = A\,t\,e^{3t}$: $\;y' = A(1 + 3t)e^{3t}$, $\;y'' = A(6 + 9t)e^{3t}$. $$A\big[(6+9t) - 4(1+3t) + 3t\big]e^{3t} = 2A\,e^{3t} = 2e^{3t} \;\Rightarrow\; A = 1 \;✓$$ The $t$ terms cancel. They always do when your resonance factor is right.

Check Example B with the shortcut

$k = 2$ is a single root of $(n-1)(n-2)$, so try $y = A\,t^2\ln t$. Then $y' = A(2t\ln t + t)$ and $y'' = A(2\ln t + 3)$. $$A\,t^2\big[(2\ln t + 3) - (4\ln t + 2) + 2\ln t\big] = A\,t^2 = 2t^2 \;\Rightarrow\; A = 2 \;✓$$

In an exam: if the question doesn't name a method, the shortcut is a fully valid way to find $y_p$ for constant-coefficient or Euler equations. If it says "use reduction of order", use the machine, and then use the shortcut in the margin as a check.

4 · Reading off $y_p$

$y_p$ isn't unique. Any particular solution plus any complementary solution is another particular solution (Lesson 2, §1). So:

  • If the machine gives you $y_p = 2t(t-1)e^{t} = 2t^2e^{t} - 2t\,e^{t}$ and $t\,e^{t}$ is in $y_c$, you can drop the $-2t\,e^t$. It gets absorbed into a constant.
  • Different methods, or different choices of $v$, can give $y_p$'s that look different but differ only by a $y_c$. Both are right.

5 · Practice

Paper first, then click.

1. The shape of $y_p$ for $\;y'' + y' - 6y = 5e^{2t}$ is…

$\lambda^2 + \lambda - 6 = (\lambda-2)(\lambda+3)$. $k = 2$ is a single root, so multiply by $t$ once. Substituting gives $A\big[(4+4t) + (1+2t) - 6t\big] = 5A = 5$, so $y_p = t\,e^{2t}$.

2. The shape of $y_p$ for $\;y'' + 4y = 8\cos 2t$ is…

The roots are $\pm 2i$, which match the forcing's $\pm i\omega = \pm 2i$, so multiply by $t$. Option (a) misses the resonance: it substitutes to $0$. Option (c) drops the $\sin$ half. Working it out gives $y_p = 2t\sin 2t$.

3. A particular solution of $\;t^2y'' - t\,y' + y = t,\;\; t>0$ is…

Indicial: $n^2 - 2n + 1 = (n-1)^2$, a double root at $n = 1$, and the forcing is $t^1$. So try $A\,t(\ln t)^2$, which substitutes to $2A\,t = t$ and gives $A = \tfrac12$. Options (a) and (b) are both complementary solutions: they give $0$.

4. For $\;t^2y'' - 3t\,y' + 3y = t^4\;$ with $v = t$, the right side $Ig/v$ of $(Iw)' = Ig/v$ is…

$f_1 = -3/t$ and $g = t^2$ after dividing. $I = t^2\cdot t^{-3} = 1/t$, so $Ig/v = \tfrac1t\cdot t^2/t = 1$. Option (a) comes from using $g = t^4$. Then $w = t^2 + C_1t$, so $u = t^3/3 + \dots$ and $y_p = t^4/3$. Check with the shortcut: $4$ isn't an indicial root ($n = 1, 3$), and $A\,t^4$ gives $(12 - 12 + 3)A = 1$ ✓.

5. For $\;y'' - 2y' - 3y = 4e^{-t}$, which $v$ keeps the machine free of by-parts integrals?

$v = e^{-t}$ matches the forcing. $I = e^{-2t}e^{-2t} = e^{-4t}$ and $Ig/v = 4e^{-4t}$, so $Iw = -e^{-4t} + C_1$, $w = -1 + C_1e^{4t}$, and $y_p = -t\,e^{-t}$. With $v = e^{3t}$ you get $w = (4t + C_1)e^{-4t}$, which needs by-parts.

6. The general solution of some ODE is $\;y = t\,e^{t} + C_1e^{-t} + C_2e^{t}$. Which is not a valid particular solution?

(b) and (c) are $t\,e^t$ plus a complementary solution, so they're also particular solutions. $t$ isn't in $y_c$, so (d) doesn't solve the ODE.

7. A particular solution of $\;t^2y'' - 2y = 6,\;\; t>0$ is…

A constant is $t^0$. The indicial equation $n^2 - n - 2 = (n-2)(n+1)$ doesn't have $0$ as a root, so try $y = A$: $\;-2A = 6$, so $A = -3$. Thirty seconds, with no reduction of order needed.

6 · Exam-level challenge

This chains finding $v$, the machine, Abel, independence and initial conditions. Fully on paper, then open one step at a time.

Consider $\;t^2y'' - t(t+2)\,y' + (t+2)\,y = 2t^3e^{t},\quad t>0$.

(a) Show that $v = t$ is a complementary solution.
(b) Use reduction of order to find the general solution. Identify $y_c$ and $y_p$, and prove the complementary solutions are linearly independent.
(c) Solve the IVP with $y(1) = 0,\; y'(1) = 2e$, and state the interval of validity.

(a) Check $v = t$

$v' = 1$, $v'' = 0$: $\;t^2\cdot 0 - t(t+2)\cdot 1 + (t+2)\,t = 0$ ✓. (The quick test is $Q + tR = 0$.)

(b) Step 1: standard form and $I$

Divide by $t^2$: $\;f_1 = -\dfrac{t+2}{t} = -1 - \dfrac2t$, $\;g = 2t\,e^{t}$. $$e^{\int f_1} = e^{-t - 2\ln t} = \frac{e^{-t}}{t^2}, \qquad I = t^2\cdot\frac{e^{-t}}{t^2} = e^{-t}, \qquad \frac{Ig}{v} = \frac{e^{-t}\cdot 2t\,e^{t}}{t} = 2.$$

(b) Step 2: integrate twice

$(e^{-t}w)' = 2 \Rightarrow e^{-t}w = 2t + C_1 \Rightarrow w = (2t + C_1)\,e^{t}.$
$u = 2(t-1)e^{t} + C_1e^{t} + C_2$, using $\int t\,e^t\,dt = (t-1)e^t$. $$y = uv = 2t(t-1)e^{t} + C_1\,t\,e^{t} + C_2\,t.$$

(b) Step 3: read off $y_c$ and $y_p$

$2t(t-1)e^t = 2t^2e^t - 2t\,e^t$, and $t\,e^t$ is in $y_c$, so absorb it into the constant: $$y = \underbrace{2t^2e^{t}}_{y_p} + \underbrace{A\,t\,e^{t} + B\,t}_{y_c}.$$ Independence: $\operatorname{wr}[t,\,t\,e^t] = t\,(1+t)e^t - 1\cdot t\,e^t = t^2e^{t} \ne 0$ for $t>0$ ✓.
Abel check: $\operatorname{wr} = C\,e^{-\int f_1} = C\,e^{t + 2\ln t} = C\,t^2e^t$ ✓. And $I = v^2/\operatorname{wr} = t^2/(t^2e^t) = e^{-t}$ ✓.

(c) Initial conditions and interval

$y' = 2(t^2 + 2t)e^{t} + A(1+t)e^{t} + B$. $$\begin{aligned} y(1) &= 2e + Ae + B = 0, &(1)\\ y'(1) &= 6e + 2Ae + B = 2e. &(2)\end{aligned}$$ $(2) - (1)$: $4e + Ae = 2e$, so $A = -2$. Then $(1)$ gives $B = 0$. $$\boxed{y = 2t(t-1)\,e^{t}}, \qquad t\in(0,\infty).$$ The only bad point after dividing by $t^2$ is $t = 0$, and $t_0 = 1 > 0$.

7 · Before you close this tab

Retrieval: write the five-step machine, the decision list and the resonance rule from memory, then check

Machine: standard form ($g$ after dividing) → $I = v^2e^{\int f_1}$ → $(Iw)' = Ig/v$, $+C_1$ → $u = \int w$, $+C_2$ → $y = uv$, and the constant-free part is $y_p$.

Decide: told to, or variable coefficients → machine. Constant-coefficient or Euler with nice forcing → shortcut. System → diagonalise.

Resonance: exponent is an $s$-fold root → multiply by $t^s$ (or $(\ln t)^s$ for Euler).
