Lesson 2 · Topic 1: Linear ODEs & IVPs

Reduction of order: from one solution to all of them

The goal: given a second-order linear ODE and one complementary solution (or a hint to find one), produce the full general solution, apply the initial conditions, and check it.

Why this matters for 5 Nov: a reduction-of-order question shows up on nearly every past paper, often worth 10+ marks across its parts. Lecture 2 calls finding the first solution "usually the difficult task", and exam questions make you do that part too.

0 · Warm-up from Lesson 1

Retrieval first. Answer from memory: you'll use both skills again below.

W1. The integrating factor for $\;t\,y' + 3y = \sin t\;$ ($t>0$) is…

Standard form first: $y' + \tfrac{3}{t}y = \tfrac{\sin t}{t}$, so $I = e^{3\ln t} = t^3$. $e^{3t}$ is the skipped-standard-form mistake.

W2. Largest interval with a guaranteed unique solution: $\;(t^2-9)\,y'' + y' + \dfrac{y}{t} = 0,\;\; y(1)=0,\; y'(1)=1$.

Divide by $t^2-9$. The bad points are $t=\pm3$ (from the division) and $t=0$ (from $y/t$). The interval containing $t_0=1$ is $(0,3)$.

1 · General = complementary + particular

Write a linear ODE as $Ty = g$, where $T = \frac{d^2}{dt^2} + f_1(t)\frac{d}{dt} + f_0(t)$ is a linear operator, just like a matrix in $A\mathbf v = \mathbf w$ (Lecture 2, slides 2–5). The recipe is the same as in linear algebra:

  • Complementary solutions $y_c$ solve $Ty_c = 0$. They form a vector space, the solution space. For a 2nd-order ODE it is 2-dimensional, so $y_c = C_1 y_1 + C_2 y_2$ with $y_1, y_2$ linearly independent (Lecture 3, slide 3).
  • A particular solution $y_p$ is any one solution of $Ty_p = g$.
  • General solution: $y = y_c + y_p$. Two constants for a 2nd-order ODE, so you need two initial conditions.

You've seen this already: in Lesson 1, Q7, $y = t - 1 + Ce^{-t}$ is $y_p = t-1$ plus $y_c = Ce^{-t}$.

Why is "any one" particular solution enough? (Try it first: it's a past-paper short answer.)

Let $y$ be any solution and $y_p$ a fixed particular one. Then $T(y - y_p) = Ty - Ty_p = g - g = 0$ because $T$ is linear. So $y - y_p$ is a complementary solution, which means $y = y_c + y_p$. Different choices of $y_p$ differ by a complementary solution, which just gets absorbed into $C_1, C_2$.

2 · The method

Suppose you know one non-zero complementary solution $v(t)$. Look for the general solution in the form $y = u(t)\,v(t)$ (Lecture 2, slides 10–12; Paul's Notes: Reduction of Order).

  1. Standard form. Divide by the coefficient of $y''$: $\;y'' + f_1 y' + f_0 y = g$. (Same trap as Lesson 1.)
  2. Substitute $y = uv$. Because $Tv = 0$, every $u$-term (without a derivative) cancels. With $w = u'$ you get a first-order linear ODE: $$w' + \Big(\frac{2v'}{v} + f_1\Big)w = \frac{g}{v}.$$
  3. Integrating factor (Lesson 1 again): $$I = v^2\, e^{\int f_1\,dt}, \qquad (I w)' = \frac{I g}{v}.$$
  4. Integrate twice. Get $w$ (constant $C_1$), then $u = \int w\,dt$ (constant $C_2$), then $y = uv$. Apply ICs, then check.

Memorise one line: $\;I = v^2 e^{\int f_1}$, $\;(Iw)' = Ig/v$, $\;y = v\displaystyle\int\!\frac{1}{I}\Big(\int \frac{Ig}{v}\,dt\Big)dt.$

If you blank in the exam, you can always rebuild it: substitute $y=uv$, use $y' = u'v+uv'$ and $y'' = u''v + 2u'v' + uv''$, and watch the $u$-terms vanish.

Three ways to lose marks
(1) Using $f_1$ before dividing by the $y''$ coefficient.
(2) Dropping $C_1$ inside the first integral. That constant is your second complementary solution.
(3) Forgetting the last multiply by $v$: $u$ is not the answer, $uv$ is.

3 · Finding $v$ when it isn't given

For $P(t)\,y'' + Q(t)\,y' + R(t)\,y = 0$, try these in order. Each test takes ten seconds.

TrialWorks when
$y = e^{t}$$P + Q + R = 0$
$y = e^{-t}$$P - Q + R = 0$
$y = e^{at}$$a^2P + aQ + R = 0$ for every $t$: group by powers of $t$ and make each bracket vanish
$y = t$$Q + tR = 0$
$y = t^n$Every term has the same power of $t$ (e.g. $t^2y'', ty', y$). That's an Euler equation, Lesson 3
$y = (t+a)^b$The question tells you to: substitute and match coefficients

If the question says "show that $v$ is a complementary solution", substitute it and show you get 0. That's easy marks, so write it out.

Worked example

Solve $\;(t+1)\,y'' - (t+2)\,y' + y = (t+1)^2 e^{t},\quad y(0)=1,\; y'(0)=0$.

Find $v$. $P+Q+R = (t+1) - (t+2) + 1 = 0$, so $v = e^{t}$.

1. Standard form. $f_1 = -\dfrac{t+2}{t+1} = -1 - \dfrac{1}{t+1}$, $\;g = (t+1)e^t$. The only bad point is $t=-1$, so the solution lives on $(-1,\infty)$.

2–3. $\int f_1 = -t - \ln(t+1)$, so $I = e^{2t}\cdot\dfrac{e^{-t}}{t+1} = \dfrac{e^{t}}{t+1}$. And $\dfrac{Ig}{v} = \dfrac{e^t}{t+1}\cdot(t+1) = e^t$.

4. $(Iw)' = e^t \Rightarrow Iw = e^t + C_1 \Rightarrow w = (t+1) + C_1(t+1)e^{-t}$.
$u = \int w\,dt = \tfrac{t^2}{2} + t - C_1(t+2)e^{-t} + C_2$, using $\int (t+1)e^{-t}dt = -(t+2)e^{-t}$.
$y = uv = \big(\tfrac{t^2}{2}+t\big)e^t \;-\; C_1(t+2) \;+\; C_2 e^t$.

Read it off: $y_c = A(t+2) + Be^t$ and $y_p = \big(\tfrac{t^2}{2}+t\big)e^t$. (Rename $-C_1 = A$, $C_2 = B$.)

ICs. $y(0) = 2A + B = 1$ and $y'(0) = 1 + A + B = 0$, so $A = 2$, $B = -3$: $$\boxed{y = \big(\tfrac{t^2}{2} + t - 3\big)e^{t} + 2t + 4}$$

Check $y_c$: $y = t+2$ gives $0 - (t+2) + (t+2) = 0$ ✓

4 · Practice

Paper first, then click.

1. $y_1 = t^2$ and $y_2 = 3t^2$ both solve a 2nd-order linear homogeneous ODE. Is $C_1t^2 + 3C_2t^2$ its general solution?

$y_2 = 3y_1$, so $C_1t^2 + 3C_2t^2 = (C_1+3C_2)t^2$ is really one constant. The solution space is 2D, so you need two linearly independent solutions. There's no $y_p$ because the ODE is homogeneous.

2. After substituting $y = uv$, which coefficient no longer appears in the ODE for $w = u'$?

The $u$-terms collect into $u\,Tv = 0$, which takes $f_0$ with it. That's why the result is first order in $w$. $f_1$ survives in $I = v^2e^{\int f_1}$, and $g$ survives as $g/v$.

3. Which is a complementary solution of $\;(1-t)\,y'' + t\,y' - y = 0$?

$P+Q+R = (1-t) + t - 1 = 0$, so $e^t$ works. $Q + tR = t - t = 0$, so $t$ works too. Two independent solutions means you get $y_c = C_1e^t + C_2t$ with no reduction of order needed. Always run every quick test.

4. Trialling $y = e^{at}$ in $\;t\,y'' - (2t+1)\,y' + (t+1)\,y = 0$, which $a$ works?

$a^2t - (2t+1)a + (t+1) = t\,(a-1)^2 + (1-a)$. Both brackets must vanish for every $t$, so $a = 1$. (The quick test agrees: $P+Q+R = 0$.)

5. For $\;t^2y'' + t\,y' - 4y = 0$ with $v = t^2$, the reduction-of-order integrating factor is…

Standard form: $f_1 = 1/t$, so $e^{\int f_1} = t$ and $I = v^2\cdot t = t^5$. Then $(t^5w)' = 0$ gives $w = Ct^{-5}$, $u = -\tfrac{C}{4}t^{-4}$, and $y = uv \propto t^{-2}$. The first option is what you get if you skip standard form and use $f_1 = t$.

6. $v = e^{t}/t$ solves $\;t\,y'' + 2y' - t\,y = 0$. The integrating factor $I$ for the $w$-equation is…

$f_1 = 2/t$, so $e^{\int f_1} = t^2$. Then $I = v^2 t^2 = \dfrac{e^{2t}}{t^2}\cdot t^2 = e^{2t}$. The $t^2$ factors cancel. That kind of tidy cancellation is a sign you're on track.

7. Carry on from Q6. The second, linearly independent complementary solution is…

$g = 0$, so $(e^{2t}w)' = 0 \Rightarrow w = Ce^{-2t} \Rightarrow u = -\tfrac{C}{2}e^{-2t}$. Then $y = uv \propto e^{-2t}\cdot\dfrac{e^t}{t} = \dfrac{e^{-t}}{t}$. If you picked $e^{-t}$, you forgot to multiply $u$ by $v$ and dropped the $1/t$.

5 · Exam-level challenge

No $v$ is given, the forcing isn't simple, and there are ICs to fit. Do it fully on paper, then open one step at a time.

Solve $\;t\,y'' - (t+2)\,y' + 2y = t(t-1)\,e^{t},\quad y(1) = 5,\;\; y'(1) = 4 + e,\quad t>0.$

Also state the general complementary solution, and the interval on which your answer is valid.

Step 1: find $v$

Quick tests: $P+Q+R = t - (t+2) + 2 = 0$, so $v = e^t$. (Check $y = t$: $Q + tR = t - 2 \neq 0$, so that one fails.) The bad point after dividing by $t$ is $t = 0$, and $t_0 = 1$, so the interval is $(0,\infty)$.

Step 2: standard form and $I$

$f_1 = -1 - \dfrac{2}{t}$ and $g = (t-1)e^t$. Then $e^{\int f_1} = e^{-t}t^{-2}$, so $I = e^{2t}\cdot e^{-t}t^{-2} = \dfrac{e^t}{t^2}$, and $$\frac{Ig}{v} = \frac{e^t}{t^2}(t-1) = \frac{(t-1)e^t}{t^2}.$$

Step 3: the first integral (the trick)

Spot that $\dfrac{(t-1)e^t}{t^2} = \Big(\dfrac{e^t}{t}\Big)'$ by the quotient rule. So $Iw = \dfrac{e^t}{t} + C_1$, and $$w = \frac{t^2}{e^t}\Big(\frac{e^t}{t} + C_1\Big) = t + C_1t^2e^{-t}.$$ On an exam, an integrand like this is almost always a derivative of something simple. Try quotient or product rule backwards before reaching for parts.

Step 4: second integral and general solution

$\int t^2 e^{-t}dt = -(t^2+2t+2)e^{-t}$, so $u = \tfrac{t^2}{2} - C_1(t^2+2t+2)e^{-t} + C_2$, and $$y = uv = \tfrac12 t^2 e^t + A\,(t^2+2t+2) + B\,e^t.$$ So $y_c = A(t^2+2t+2) + Be^t$ and $y_p = \tfrac12t^2e^t$. Check $t^2+2t+2$: $2t - (t+2)(2t+2) + 2(t^2+2t+2) = 0$ ✓

Step 5: initial conditions

$y(1) = \tfrac e2 + 5A + Be = 5$ and $y'(1) = \tfrac{3e}{2} + 4A + Be = 4 + e$. Subtracting gives $A - e = 1 - e$, so $A = 1$ and then $B = -\tfrac12$: $$\boxed{y = \tfrac12\,(t^2-1)\,e^t + t^2 + 2t + 2}, \qquad t\in(0,\infty).$$

Once you've checked the steps, compare your script against the full written solution, which shows every line you'd write in the exam.
