Lesson 19 · Topic 5: Binomial trees

American options on a binomial tree

The goal: price an American put on a two- or three-step tree by checking at every node whether to exercise now or keep the option; say which nodes exercise and why; get the early-exercise premium; and know without calculating that an American call on a non-dividend stock is just the European call.

Why this matters for 5 Nov: past finals have a 7-mark "three-period American put: draw the tree with stock price and option value at every node" (u from \(\sigma\), u and d to 4 dp, stock prices to 2 dp), followed by a 3-mark "the option trades at $X: find the arbitrage". Older papers ask for the European and American values on the same tree, and the MCQs ask "American call, no dividends: when do you exercise early?" (never).

Assumes Lesson 16 (one-period tree, \(\Delta\)), Lesson 17 (risk-neutral \(p\)) and Lesson 18 (two-step European trees, working backwards, \(u\) and \(d\) from \(\sigma\)). It reuses the early-exercise reasons from Lesson 15. Notation (Lecture 6): \(u, d\) = up and down factors, \(\Delta t\) = length of one step, \(p = \dfrac{e^{r\Delta t}-d}{u-d}\) = risk-neutral probability of an up move, \(f\) = option value at a node.

1 · One new rule: at each node, take the better of keeping it and cashing it in

A European option can only be used at expiry, so at an earlier node its value is the discounted risk-neutral average of the two values one step later. An American option can be exercised at any node. So its holder, at each node, has two choices:

  • Continuation value (also called the hold value): what the option is worth if you keep it for one more step. Same formula as the European tree, applied to the next step's American values: \(e^{-r\Delta t}\,[\,p f_u + (1-p) f_d\,]\).
  • Exercise value (the intrinsic value at that node): what you get by exercising right now. Put \(K - S\), call \(S - K\) (or 0 if negative).
$$f_{\text{node}} \;=\; \max\Big(\underbrace{e^{-r\Delta t}\,[\,p f_u + (1-p) f_d\,]}_{\text{continuation (hold)}},\;\; \underbrace{K - S_{\text{node}}}_{\text{exercise now (put)}}\Big)$$

That is the whole method. You still start at expiry and work backwards (backward induction: each node's value uses the next step's values, which already include the best decisions from there on). At the final nodes nothing changes: payoff = exercise value, the same as for the European option. A node where exercise wins is an exercise node; there the option's time value is zero.

Because the American holder has every right the European holder has, plus more, American \(\ge\) European at every node. The difference at time 0 is the early-exercise premium: \(P - p_{\text{Euro}}\) for a put. (Lecture 6, slides 5–7; Hull, Binomial Trees chapter, "American options".)

2 · The lecture's two-step put, done as an American

Lecture 6 setup: \(S_0 = 50\), \(K = 52\), \(\Delta t = 1\) year, \(r = 5\%\), \(u = 1.2\), \(d = 0.8\). Node names as in the lecture: A (today), B (up), C (down), D, E, F (expiry). The lecture's Week 5 recap (slide 3) priced the European put at \(4.1923\), with \(f_B = 1.4147\) and \(f_C = 9.4636\).

Predict first: at node C the stock is $40 and the put has strike $52. The European value there is $9.46. Would an American holder keep the put at C?

Reveal

No. Exercising at C pays \(52 - 40 = \$12\), more than the $9.46 the put is worth if kept. Look at C's two children: E ($48) and F ($32). The put finishes in the money on both branches, so keeping it gives you no protection you don't already have. All waiting does is delay receiving \(K\) (lose interest on $52 for a year).

  1. Parameters. \(p = \dfrac{e^{0.05}-0.8}{1.2-0.8} = \dfrac{1.0513-0.8}{0.4} = 0.6282\), discount factor \(e^{-0.05} = 0.9512\).
  2. Expiry (D, E, F). Stock 72, 48, 32. Put payoffs \(0, 4, 20\). Same as the European.
  3. Node B (\(S = 60\)). Hold: \(e^{-0.05}[0.6282(0) + 0.3718(4)] = 1.4147\). Exercise: \(52-60 \lt 0\), so 0. Value \(= \max(1.4147, 0) = 1.4147\). Keep.
  4. Node C (\(S = 40\)). Hold: \(e^{-0.05}[0.6282(4) + 0.3718(20)] = 9.4636\). Exercise: \(52-40 = 12\). Value \(= \max(9.4636, 12) = \mathbf{12}\). Exercise.
  5. Node A (\(S = 50\)). Hold, using the American values at B and C: \(e^{-0.05}[0.6282(1.4147) + 0.3718(12)] = 5.0894\). Exercise: \(52-50 = 2\). Value \(= \max(5.0894, 2) = 5.0894\). Keep.
Result. American put \(= \$5.09\) vs European put \(= \$4.19\). Early-exercise premium \(= 5.09 - 4.19 = \$0.90\). The whole premium comes from one decision: exercise at node C if the stock falls.

The diagram uses unrounded \(p\), so node A shows 5.0896. The lecture slide shows 5.0892 (rounding \(p\) and \(f_B\)). Anything that rounds to 5.09 is fine.

The mark-losing slip
Working out node A from the European value at C (9.4636) and only then comparing with exercise at A gives \(\max(4.1923, 2) = 4.19\), which is just the European price. The exercise check at C has to feed into A. Do the check at every node as you go, and carry the larger number back.

3 · Why early exercise happens at the low nodes

Lesson 15 gave the trade-off for a put: exercising early earns interest on \(K\), and waiting keeps the insurance value (if you keep the put you still gain if the stock falls further, but lose nothing extra if it rebounds). The tree makes both visible at a single node.

A node with one step left

Take a node with \(S = 40\), \(K = 44\), one step of \(\Delta t = 0.25\) left, so exercising pays $4. The next step has \(u = 1 + x\), \(d = 1 - x\). A wider spread \(x\) plays the role of higher volatility. Predict each row before reading the verdict.

Spread, rateChildren (put payoffs)Hold valueVerdict
\(\pm 10\%\), \(r = 4\%\)44 (0), 36 (8)3.56Exercise (4 > 3.56)
\(\pm 10\%\), \(r = 0\)44 (0), 36 (8)4.00Tie: no interest to earn
\(\pm 15\%\), \(r = 4\%\)46 (0), 34 (10)4.62Hold: more insurance value
\(\pm 15\%\), \(r = 12\%\)46 (0), 34 (10)3.87Exercise: interest now beats it
\(\pm 20\%\), \(r = 12\%\)48 (0), 32 (12)4.94Hold: too much insurance to give up

Two things to read from this table.

  • Higher \(r\) pushes towards exercise; higher \(\sigma\) pushes towards holding. Same directions as Lesson 15 and Tutorial 4 Q6, now with numbers.
  • If the put is in the money on both branches, exercise (when \(r>0\)). Then the put is like a promise to swap the share for \(K\) one step later, worth \(Ke^{-r\Delta t} - S\), which is less than \(K - S\). No insurance is left, only lost interest. This is exactly node C of the lecture tree (both children 48 and 32 are below 52).

Why the low nodes? Down there the put is deep in the money: both branches below finish in the money, the insurance value has gone, and \(K - S\) is large, so the interest on it is large. At the high nodes the put is near or out of the money and is mostly insurance, so you keep it.

4 · American call on a non-dividend stock: the tree never exercises

Predict first: same lecture tree, but a call with \(K = 52\). At node B (\(S = 60\)) exercising pays $8. Will the tree exercise there?

Reveal

Hold at B: \(e^{-0.05}[0.6282(72-52) + 0.3718(48-52)^+] = e^{-0.05}(0.6282 \times 20) = 11.95\), well above 8. Keep. At C the call is out of the money. At A: hold \(= 7.14\) vs exercise 0. American call \(= \) European call \(= \$7.14\).

This is Lesson 15's result showing up in the tree: holding a call is worth at least \(S - Ke^{-r\Delta t}\), which is more than \(S - K\), the exercise value, because you pay the strike later. So at every node hold beats exercise, and \(C = c\). On an exam you can say "no dividends, so the American call equals the European call; no node is exercised" and price it as European. Showing the hold-vs-exercise check at one or two nodes is a cheap way to prove it. (Dividends change this; that comes in the dividends lessons.)

Lecture slide 8, both halves
(i) American call, no dividends: never exercise early (exercise gets intrinsic; waiting gets intrinsic + time value). (ii) American put, no dividends: early exercise may be optimal, and at a node where it is, time value = 0.

5 · More steps, same rule

Lecture 6's multi-period example is a 5-step American put: \(S_0 = K = 50\), \(r = 10\%\), \(\sigma = 40\%\), \(T = 5\) months, \(\Delta t = 1\) month. With more steps, \(u\) and \(d\) come from volatility:

$$u = e^{\sigma\sqrt{\Delta t}}, \qquad d = \frac{1}{u}.$$

Here \(u = e^{0.4\sqrt{1/12}} = 1.1224\), \(d = 0.8909\), \(p = 0.5073\). Because \(ud = 1\), the tree recombines onto the same prices (50 appears at \(t = 0, 2, 4\)). The tree exercises at three nodes, all in the bottom-left corner: \(S = 39.69\) at month 4 (hold 9.90 vs exercise 10.31, the lecture's ticked node), \(S = 31.50\) at month 4, and \(S = 35.36\) at month 3. The American put is 4.49; the European would be about 4.32. The boundary between "hold" and "exercise" nodes is the early-exercise boundary: below it, exercise.

Exams use 2 or 3 steps. Three steps is 6 hold-vs-exercise checks (3 at \(t=2\), 2 at \(t=1\), 1 at \(t=0\)).

6 · Exam layout (what earns the marks)

  1. Parameters. \(\Delta t = T/n\). \(u, d\) (given, or \(u = e^{\sigma\sqrt{\Delta t}}\), \(d = 1/u\)) to 4 dp. \(p = (e^{r\Delta t} - d)/(u-d)\) to 4 dp. Write the discount factor \(e^{-r\Delta t}\).
  2. Stock tree, prices to 2 dp. Label nodes (A, B, C, …).
  3. Expiry payoffs at the final nodes.
  4. Work backwards. At every earlier node write three things: hold \(= e^{-r\Delta t}[p f_u + (1-p) f_d]\), exercise \(= K - S\) (put), value \(= \max\). Mark exercise nodes (✓ or "EE").
  5. Draw the final tree with stock price and option value at every node (the 7-mark question literally asks for this).
  6. State the answer to 2 dp, list the nodes where early exercise is optimal, and if asked, give the European value from the same tree (no max) and the premium.
  7. One sentence why: "at C the put is deep in the money on both branches, so interest on \(K\) beats the time value given up."

Calculator tip (Casio FX-82): store \(p\) in memory A and \(e^{-r\Delta t}\) in B. Each node is then \(B(Af_u + (1-A)f_d)\). Keep 4 dp for node values; round only the final answer.

7 · Try it

Set up any tree with up to 4 steps. Things to try: (1) the lecture put, then switch Style to European and watch node C drop from 12 to 9.46. (2) Switch to a call: no node ever highlights. (3) Raise \(r\) and watch more nodes exercise; raise \(u\) (or \(\sigma\)) and watch them stop. (4) Set \(r = 0\): the premium goes to zero.

8 · Concept checks

C1. At an interior node of an American put tree, what is the option value?

The holder picks the better of keeping (continuation) and exercising. (a) is the European rule.

C2. At the final nodes of an American put tree, how does the value compare with the European tree?

At expiry there is no "later", so both options are worth the payoff. Differences only appear at earlier nodes.

C3. At a node of a put tree both next-step stock prices are below \(K\), and \(r \gt 0\). What should the American holder do there?

Both payoffs are \(K - S_{\text{next}}\), linear in the stock, so the hold value is \(e^{-r\Delta t}E^*[K - S_{\text{next}}] = Ke^{-r\Delta t} - S \lt K - S\). No insurance left, only lost interest.

C4. A two-step American put tree has no exercise nodes. What follows?

If the max never picks exercise, every node equals the European calculation, so the early-exercise premium is 0.

C5. Starting from a tree where a down node is just barely an exercise node, which change is most likely to make that node a hold node?

A wider spread is higher volatility: more insurance value from holding. Higher \(r\) and higher \(K\) push towards exercise; (d) mixes a push each way.

C6. An American call on a non-dividend stock is priced on a three-step tree. How many nodes are exercise nodes?

Hold \(\ge S - Ke^{-r\Delta t} \gt S - K\) at every node, so \(C = c\). Lecture 6 slide 8 (i).

C7. At an exercise node of an American put tree, what is the option's time value at that node?

Value = max(hold, \(K - S\)) = \(K - S\) at an exercise node, so time value = value − intrinsic = 0. (The European put there can be worth less than \(K - S\).)

9 · Exam-style questions

Calculator-only, same length as the finals. Keep \(u, d, p\) to 4 dp and node values to 4 dp; answers to 2 dp. Draw the tree on paper first.

Question A (two-step, \(u\) and \(d\) given, about 6 marks)

A non-dividend stock trades at $80. Over each of the next two 6-month periods it will either rise by 25% or fall by 20%. The risk-free rate is 6% p.a. continuously compounded. Consider a 1-year put with strike $84.

A1. What is the risk-neutral probability \(p\) of an up move (4 dp)?

\(u = 1.25\), \(d = 0.80\), \(\Delta t = 0.5\). \(p = \dfrac{e^{0.03} - 0.8}{1.25 - 0.8} = \dfrac{1.0305 - 0.8}{0.45} = 0.5121\).

A2. At the down node after 6 months (\(S = 64\)), what is the put's continuation value?

$
Expiry payoffs: \(S = 125, 80, 51.20\) give \(0, 4, 32.80\). Hold \(= e^{-0.03}[0.5121(4) + 0.4879(32.80)] = 0.9704 \times 18.0509 = 17.52\). Exercising pays \(84 - 64 = 20\), which is more.

A3. What is the value of the American put today?

$
Up node (\(S = 100\)): \(e^{-0.03}[0.5121(0) + 0.4879(4)] = 1.8938\), exercise 0 → keep. Down node: \(\max(17.52, 20) = 20\), exercise. Today: \(e^{-0.03}[0.5121(1.8938) + 0.4879(20)] = 10.41\) vs exercise \(84 - 80 = 4\) → keep. \(P = \$10.41\).

A4. What is the value of the European put with the same terms?

$
Use 17.52 (not 20) at the down node: \(e^{-0.03}[0.5121(1.8938) + 0.4879(17.5174)] = 9.24\).

A5. What is the early-exercise premium?

$
\(10.4104 - 9.2350 = 1.18\) (1.17 if you subtract the rounded 10.41 and 9.24; either is fine).

A6. Same tree, an American call with strike $84. What is it worth?

$
No dividends, so price it as European. Payoffs \(41, 0, 0\). \(f = e^{-0.06}\,p^2(41) = 0.9418 \times 0.2623 \times 41 = 10.13\). Check the up node: hold \(e^{-0.03}(0.5121 \times 41) = 20.37 \gt 100 - 84 = 16\), so keep.

Question B (\(u\) from \(\sigma\): a two-step warm-up, then three steps, about 7 marks)

A non-dividend stock trades at $60 with volatility 30% p.a. The risk-free rate is 2% p.a. continuously compounded. An American put has strike $58 and 6 months to expiry. Use a two-period tree for B1–B3.

B1. What is \(u\) (4 dp)?

\(\Delta t = 0.25\). \(u = e^{0.3\sqrt{0.25}} = e^{0.15} = 1.1618\); \(d = 1/u = 0.8607\); \(p = (e^{0.005} - 0.8607)/(1.1618 - 0.8607) = 0.4793\).

B2. What is the American put worth today?

$
Stock: 80.99, 60.00, 44.45 at expiry; payoffs 0, 0, 13.55. Down node (\(S = 51.64\)): hold \(e^{-0.005}(0.5207 \times 13.5517) = 7.02\) vs exercise \(58 - 51.64 = 6.36\) → keep. Up node: 0. Today: \(e^{-0.005}(0.5207 \times 7.0212) = 3.64\) vs exercise 0. \(P = \$3.64\).

B3. Which conclusion about the put in B2 is correct?

At the down node the middle child (60) is out of the money, so the put still has insurance value, and with \(r = 2\%\) there is little interest to gain. Also, at \(t = 0\) the put is out of the money (\(S = 60 \gt 58\)).
Now a different put for B4–B6. Non-dividend stock $45, \(\sigma = 20\%\), \(r = 8\%\), American put, \(K = \$48\), 9 months, three-period tree (the model answer in section 6; cover it first).

B4. What is \(p\) (4 dp)?

\(u = e^{0.1} = 1.1052\), \(d = 0.9048\), \(p = (e^{0.02} - 0.9048)/0.2004 = 0.5759\).

B5. What is the American put worth today?

$
See the table in section 6. Exercise at \(S = 36.84\) (\(t=2\)) and \(S = 40.72\) (\(t=1\)); today \(0.9802[0.5759(1.2588) + 0.4241(7.2840)] = 3.74\).

B6. At which nodes is early exercise optimal in B5?

\(t=1\) down: \(\max(6.35, 7.28)\); \(t=2\) down-down: \(\max(10.21, 11.16)\). The middle node at \(t=2\) (\(S = 45\)) is in the money but hold (3.03) beats exercise (3.00); today hold 3.74 beats 3.00. So (c) is wrong.

Question C (deep in the money, about 4 marks)

A non-dividend stock trades at $30. Each 6-month period it rises 10% or falls 10%. \(r = 10\%\) p.a. continuously compounded. A 1-year American put has strike $40. Two-period tree.

C-1. What is the American put worth today?

$
\(p = (e^{0.05} - 0.9)/0.2 = 0.7564\). Expiry: 36.30, 29.70, 24.30 → 3.70, 10.30, 15.70. Up node (33): hold 5.05 vs 7 → exercise. Down node (27): hold 11.05 vs 13 → exercise. Today: hold \(e^{-0.05}[0.7564(7) + 0.2436(13)] = 8.05\) vs \(40 - 30 = 10\) → exercise now. \(P = \$10.00\).

C-2. What should the holder of the put in C-1 do today, and what is the European put worth?

European: \(e^{-0.10}[p^2(3.70) + 2p(1-p)(10.30) + (1-p)^2(15.70)] = 6.19\), below its intrinsic value of 10 (a European put can trade below \(K - S\); Lesson 15). The premium is 3.81.

Question D (mispricing, about 3 marks)

Back to Question A: your tree says the American put is worth $10.41. Use the American values at the first-step nodes (\(f_u = 1.8938\) at \(S = 100\), \(f_d = 20\) at \(S = 64\)).

D1. What is the put's delta \(\Delta = \dfrac{f_u - f_d}{S_u - S_d}\) at \(t = 0\) (3 dp)?

\(\Delta = (1.8938 - 20)/(100 - 64) = -18.1062/36 = -0.503\). A long put is hedged by buying 0.503 shares.

D2. The put is quoted at $9.50. Which strategy locks in a riskless profit?

Cheap → buy it. Hedge a long put (\(\Delta \lt 0\)) with a long stock position, financed by borrowing. Rebalance at the next node and exercise where the tree says (at \(S = 64\)). The profit in today's money is \(10.41 - 9.50 = \$0.91\).

D3. Instead the put is quoted at $3.50 with the stock at $80. What riskless profit is available right now, per put?

$
That is below the intrinsic value \(84 - 80 = 4\). Buy the put and a share for \(83.50\), exercise immediately, receive \(84\): profit \(\$0.50\). No tree needed.

10 · Rule of thumb

American on a tree = European tree + "max(hold, exercise)" at every node, carried backwards. For puts, exercise shows up at the low nodes, especially where both branches below finish in the money; more of it with higher \(r\), less with wider \(u\)–\(d\) (higher \(\sigma\)), none at \(r = 0\). For calls on non-dividend stocks it never shows up, so \(C = c\). Report: value, exercise nodes, and (if asked) European value and premium.
