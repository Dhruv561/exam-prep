Lesson 25 · Topic 7: Black-Scholes-Merton

BSM is the binomial tree with infinitely many steps

The goal: see that the tree of Topics 5–6 and the BSM formula are one model at two resolutions. Know how fast and in what pattern the tree value approaches BSM, read the Tutorial 7 convergence questions, say when the tree beats the formula (American options), and write the 2-mark "link between binomial and BSM" answer.

Why this matters for 5 Nov: the binomial question in past finals ends with a short "link between the binomial model and BSM" part (about 2 marks), and Lecture 7 slide 32 and Tutorial 7 (Q5, Q6) are built around it. Expect a 1- or 2-step tree value next to a BSM value, then "which is larger?", "what happens as steps increase?" and "why would you still use the tree?".

Assumes Lesson 18 (\(u = e^{\sigma\sqrt{\Delta t}}\), \(d = 1/u\), \(p\), roll-back), Lesson 19 (early exercise) and Lesson 24 (\(d_1\), \(d_2\), \(N(\cdot)\), the call and put formulas). Notation: \(N\) (capital, no argument) in this lesson is the number of steps when it appears as \(N=20\) etc.; \(N(x)\) with brackets is the standard normal cumulative probability. \(\Delta t = T/N\) is one step in years.

1 · One model, two resolutions

Predict first: a tree with 1 step has two possible end prices. A stock really has a whole range. What should happen to the tree's option value as you add steps: jump around, drift one way, or settle? And settle at what?

It settles (with a zig-zag on the way, section 4) at the BSM price. Nothing else in the tree changes: same \(S_0\), \(K\), \(r\), \(\sigma\), \(T\). Only the step length \(\Delta t\) shrinks.

The tree (CRR, from Lesson 18).

\[u = e^{\sigma\sqrt{\Delta t}},\qquad d = \frac1u,\qquad p = \frac{e^{r\Delta t}-d}{u-d},\qquad f = e^{-r\Delta t}\big[\,p f_u + (1-p) f_d\,\big]\]

The limit. Let \(N\to\infty\), so \(\Delta t\to0\). The European tree value converges to the BSM value \(c = S_0N(d_1) - Ke^{-rT}N(d_2)\) (and likewise for the put).

Why they must agree. Three links, each already in your notes:

  1. The same spread. Each step moves \(\ln S\) by \(+\sigma\sqrt{\Delta t}\) or \(-\sigma\sqrt{\Delta t}\), so after \(N\) steps the variance of \(\ln S_T\) is about \(N\sigma^2\Delta t = \sigma^2 T\). That is exactly the BSM assumption that \(\ln S_T\) is normal with standard deviation \(\sigma\sqrt T\) (Lesson 22). Adding up many small \(\pm\) moves gives a bell curve in \(\ln S\); that is why \(u\) is built from \(\sigma\sqrt{\Delta t}\).
  2. The same pricing logic. In the tree you hold \(\Delta\) shares against the option so the portfolio is riskless for one step, so it must earn \(r\) (no arbitrage). BSM does the same "riskless portfolio earns \(r\)" argument over an instant (Lecture 7 slides 13–14). Hence both can be priced as an expected payoff discounted at \(r\), with the stock growing at \(r\), not at its real-world return.
  3. Rebalancing frequency. The tree's hedge ratio \(\Delta\) is reset at each of \(N\) dates; BSM resets it continuously (that is the "short period of time" on slide 15). More steps = closer to continuous rebalancing.
"The tree is a different model"
No. The tree has no extra assumption over BSM; it is BSM with the stock allowed only a coarse set of prices. Its risk-neutral probability \(p\) is not a real-world probability and has nothing to do with the stock's expected return \(\mu\) (Lesson 17); \(\mu\) also never appears in the BSM formula.

4 · How the tree converges: the odd/even sawtooth

The pattern. For an at-the-money European option the values do not creep up to BSM from one side; they alternate: odd \(N\) too high, even \(N\) too low, with both gaps shrinking. Doubling \(N\) roughly halves the gap: even \(N=10, 20, 40, 80\) give errors −0.0527, −0.0266, −0.0133, −0.0067 (odd \(N = 11, 21, 41, 81\): +0.0425, +0.0222, +0.0113, +0.0057). So error \(\approx\) constant\(/N\), and to buy one more correct decimal you need ten times the steps.

Why it zig-zags (intuition). The payoff has a kink at \(K\). With \(d=1/u\), an even number of steps has a terminal node at exactly \(S_0\), so for an ATM option a node sits right on the kink. With an odd number of steps there is no such node: the nearest nodes straddle \(K\). Where the kink sits relative to the nodes decides whether the coarse payoff overstates or understates the true curve, so the error flips sign with parity. (This explains the pattern; the exam never asks for the proof. Away from the money the zig-zag is still there, e.g. WPL \(N = 5,6,7,8\): 6.07, 5.96, 6.06, 6.02, but it is less regular.) A handy consequence: averaging the values for \(N\) and \(N+1\) cancels much of the zig-zag; for the Tutorial 7 option \(N=10, 11\) averages to 2.7072 against BSM 2.7123.

Why a shorter \(\Delta t\) helps (exam wording: "as \(\Delta t\to0\)"):

  • the \(N+1\) end prices become dense, so the lognormal distribution of \(S_T\) and the kinked payoff \(\max(S_T-K,0)\) are captured more finely;
  • each step's move \(\pm\sigma\sqrt{\Delta t}\) is small, so "only two outcomes per step" is a smaller approximation;
  • the hedge is rebalanced more often, approaching BSM's continuous rebalancing.
Monotone convergence is not guaranteed
Tutorial 7 Q6 (Brent) shows only even \(N\) (2, 4, 8, 16), which do rise steadily. Odd \(N\) would have given values falling toward the answer from above. "More steps always raises the value" is wrong in general; "more steps always gets closer on average" is the right claim.

(c). Both 10 and 20 are even, so the sign matches, and the gap scales like \(1/N\) (Tutorial 7 numbers: −0.0527 then −0.0266). Even \(N\) are not exact; they are just consistently on one side.

5 · Tutorial 7: Q5 and Q6 (Brent), with interpretations

Q5: \(S_0 = K = 10\), \(r = 6\%\), \(\sigma = 40\%\), \(T = 2\), European call

(a) One period. \(\Delta t = 2\): \(u = e^{0.4\sqrt2} = 1.7607\), \(d = 0.5680\), \(e^{0.12} = 1.1275\), \(p = (1.1275 - 0.5680)/(1.7607-0.5680) = 0.4691\). \(S_u = 17.607\), \(f_u = 7.607\); \(S_d=5.68\), \(f_d = 0\). \(c = e^{-0.12}\times0.4691\times7.607 = \mathbf{3.16}\) (Python: 3.1650, so 3.16 or 3.17 depending on how you round \(u\), \(p\); the tute solution gives 3.16).

(b) Ten periods (simulator, \(\Delta t = 0.2\), \(u = 1.1959\)): 2.66 (Python 2.6596 ✓).

BSM (Tute 4a, table method, formula sheet pp. 5-6): \(d_1 = 0.4950 \to 0.49\), \(d_2 = 0.4950 - 0.4\sqrt2 = -0.0707 \to -0.07\), \(N(d_1)=0.6879\), \(N(d_2)=0.4721\), \(c = 10(0.6879) - 10e^{-0.12}(0.4721) = \mathbf{2.69}\). With exact \(N\) and unrounded \(d\) (not the exam method): 2.71. Exact BSM is 2.7123; the tree's true limit is 2.7123, not 2.69.

(c) Interpretation (model answer): one step gives 3.16, ten steps give 2.66, BSM gives about 2.7. As the number of steps rises (the step length \(\Delta t\) falls), the binomial price moves toward the BSM price, so BSM is the limit of the binomial model. Note the solution sheet says "increasing the time step", which is a slip: it is shortening the time step (more steps) that gives convergence. Also notice the ten-step value (2.66) is slightly below both BSM figures, which is the even-\(N\) side of the sawtooth. One could not conclude "the tree always underprices" from one value.

6 · The tree and N(d2) tell the same story

Lecture 7 slide 31 reads the call as "expected payoff given in-the-money, times the chance of being in the money". The tree has the same pieces: at the end there are \(N+1\) nodes, each with a risk-neutral probability from \(p\); add those for nodes with \(S_T \gt K\) and you get the tree's risk-neutral probability of finishing in the money. As \(N\to\infty\) that probability tends to \(N(d_2)\), and the tree's probability-weighted stock payoff tends to the \(S_0 N(d_1)\) part.

WPL: \(N(d_2) = 0.8023\) (tables; unrounded 0.8017). The tree's chance of ending above \(K=25\): 0.8127 at \(N=100\), 0.7990 at \(N=500\), 0.8001 at \(N=1000\): the same zig-zag, settling on the BSM value. So "\(N(d_2)\) is the risk-neutral probability the option is exercised" and "\(p\) is the risk-neutral probability of one up move" are the same idea at two resolutions, and neither is a forecast using the stock's real expected return.

5. For a call, \(N(d_2)\) in the BSM formula is best matched on the tree by:

(b). \(p\) (c) is per step and \(\Delta\) (d) is a hedge ratio (it matches \(N(d_1)\), the call's delta). Nothing in BSM or the tree uses real-world probabilities (a).

7 · When is the tree preferable?

For a plain European option on a non-dividend stock, use the formula: exact, instant, no step error. The tree wins when the formula cannot be used:

  • American options where early exercise can be optimal (American puts; calls on dividend payers): the BSM formula is for European options only. The tree handles it by comparing the held value with exercise value at every node (Lesson 19).
  • Payoffs that are unusual or depend on the path, and trees with changing inputs.
  • Teaching the hedge: the tree shows \(\Delta\) at each node explicitly.

Numbers. Put with \(S_0=50\), \(K=52\), \(r=5\%\), \(\sigma=30\%\), \(T=1\). BSM (European): \(d_1=0.19\), \(d_2=-0.11\), \(p = 52e^{-0.05}(0.5438)-50(0.4247) = \mathbf{5.66}\) by the formula-sheet table (\(N(-x)\) read off the \(x\le0\) table), 5.67 with exact \(N\). Trees: 2-step European 5.42, 2-step American 6.04; at 1000 steps the European tree is 5.66 (converging to BSM) but the American tree is 6.00. The formula has no way to produce the extra 0.33 for the right to exercise early (the American put's early-exercise premium).

A European and American call on a non-dividend stock are equal (never exercise early), so BSM is fine for both. For the same inputs, call: American tree 6.1980 equals the European tree 6.1980, against BSM 6.20.

6. Why would an analyst value an American put with a 100-step tree rather than the BSM put formula?

(a). Trees need \(\sigma\) for \(u\) too (b), BSM uses \(r\) (c), and neither is a bound (d).

8 · The 2-mark exam answer

"Explain the link between the binomial model and the BSM model" (model answer, 2 marks). (1) As the number of steps increases (time step \(\Delta t\to0\)), the binomial price for a European option converges to the BSM price, i.e. BSM is the limit of the binomial model with \(u=e^{\sigma\sqrt{\Delta t}}\), \(d=1/u\). (2) Both rest on the same no-arbitrage argument: a riskless hedge of stock and option earns the risk-free rate, so valuation is risk-neutral, and the stock's real expected return does not matter. The difference is that the binomial rebalances at discrete dates and BSM continuously; the tree can also value American options.

Marking points to hit: more steps / shorter \(\Delta t\), converges to BSM, same no-arbitrage / risk-neutral logic. Add "European" or you may lose the mark.

Question A (9 marks): one step against BSM

A non-dividend-paying stock trades at $60. A 6-month European call has strike $50. The risk-free rate is 5% p.a. continuously compounded and the volatility is 20% p.a.

A(a). (2 marks) Using a one-step binomial tree with \(u=e^{\sigma\sqrt{\Delta t}}\), \(d=1/u\), find the risk-neutral probability of an up move (4 dp).

\(\Delta t = 0.5\): \(u = e^{0.1414} = 1.1519\), \(d = 0.8681\), \(e^{0.025}=1.0253\). \(p = (1.0253-0.8681)/(1.1519-0.8681) = 0.1572/0.2838 = 0.5539\). (Using \(e^{0.05}\) gives 0.6405.)

A(b). (3 marks) Value the call with the one-step tree.

$
\(S_u = 69.11\), \(f_u = 19.11\); \(S_d = 52.09\), \(f_d = 2.09\) (both nodes are in the money). \(c = e^{-0.025}[0.5539(19.1146)+0.4461(2.0874)] = 0.9753\times11.5196 = 11.23\).

A(c). (2 marks) Value the call with BSM (tables, \(d\) to 2 dp).

$
\(d_1 = [\ln(60/50)+(0.05+0.02)(0.5)]/(0.2\sqrt{0.5}) = 0.2178/0.1414 = 1.54\); \(d_2 = 1.5367-0.1414 = 1.3953 \to 1.40\). \(N(1.54)=0.9382\), \(N(1.40)=0.9192\). \(c = 60(0.9382) - 50e^{-0.025}(0.9192) = 56.292 - 44.826 = 11.47\). Exact \(N\), unrounded \(d\): 11.48 (not the exam method).

A(d). (2 marks) Which statement about the one-step value 11.23 and the BSM value is correct?

(c). With both end nodes above \(K\), the tree payoff is just \(S_T - K\), worth \(S_0 - Ke^{-rT} = 11.23\) exactly. It cannot see the chance of finishing below \(K\) (where the call pays 0), so it undervalues the option. More steps add that chance: 2-step 11.42, 3-step 11.54, 20-step 11.47, 1000-step 11.48. Note the 3-step overshoots: the sawtooth. (a) is false in general (WPL one-step was lower, Tutorial 7 higher); (d) invents a validity rule.

A(e) (1 mark, no answer box): "What happens to the tree value of the put as \(N\) increases?" The one-step put is worth $0.00 (both end nodes above 50, the put pays nothing) while BSM gives about $0.23: the tree value rises and converges to BSM (2-step 0.18, 4-step 0.23, 50-step 0.24).
