Setup (fresh data; about 12 marks). The numbers of insurance claims \(X_1,\dots,X_8\) filed by eight small businesses are modelled as a two-component Poisson mixture: \(Z_i\sim\text{Categorical}(\pi_1,1-\pi_1)\), \(X_i\mid Z_i=k\sim\text{Poisson}(\lambda_k)\). An analyst uses the tute week 7 code:

EM.iter <- function(X, w.curr, lambda_curr) {
  prob.x.z = compute.prob.x.z(X, w.curr, lambda_curr)$prob.x.z
  P_ik = prob.x.z / rowSums(prob.x.z)
  w.new = colSums(P_ik)/sum(P_ik)
  lambda_new = colSums(P_ik*X)/colSums(P_ik)
  return(list(w.new=w.new, lambda_new=lambda_new))
}
compute.prob.x.z <- function(X, w.curr, lambda_curr) {
  L = matrix(NA, nrow=length(X), ncol= length(w.curr))
  for(k in seq_len(ncol(L))) {
    L[, k] = dpois(X, lambda_curr[k])*w.curr[k]
  }
  return(list(prob.x.z=L))
}

(a) · What the objects are [2]

$$\begin{aligned} \texttt{prob.x.z}[i,k]&=P(X_i=x_i,Z_i=k\mid\theta^0)\\ &=w_k^0\frac{(\lambda_k^0)^{x_i}e^{-\lambda_k^0}}{x_i!}\\[6pt] \texttt{P\_ik}[i,k]&=P(Z_i=k\mid X_i=x_i,\theta^0)\\ &=\frac{w_k^0(\lambda_k^0)^{x_i}e^{-\lambda_k^0}/x_i!}{\sum_{j=1}^2w_j^0(\lambda_j^0)^{x_i}e^{-\lambda_j^0}/x_i!} \end{aligned}$$

The joint, and the responsibility, at the current values.

(b) · Row 4 [3]

\(x_4=2\), so \(x_4!=2\):

$$\begin{aligned} \texttt{prob.x.z}[4,1]&=0.6\times\frac{1^2e^{-1}}2\\ &=0.6(0.183940)\\ &=0.1104\\ \texttt{prob.x.z}[4,2]&=0.4\times\frac{6^2e^{-6}}2\\ &=0.4(18)(0.002479)\\ &=0.0178\\ \texttt{P\_ik}[4,1]&=\frac{0.1104}{0.1104+0.0178}\\ &=\frac{0.1104}{0.1282}\\ &=0.86 \end{aligned}$$

\(0.86\gt0.5\): assign observation 4 to component 1

(c) · First M-step [3]

Column 1 of P_ik:

$$\begin{aligned} \sum_i\gamma_{i1}&=0.9955+0.9738+0.9738+0.8608\\ &\quad+0.1466+0.0047+0.0001+0.0000\\ &=3.9553\\ \texttt{w.new}[1]&=\frac{3.9553}8\\ &=0.49 \end{aligned}$$

Weighted sum of the counts:

$$\begin{aligned} \sum_i\gamma_{i1}x_i&=0.9955(0)+0.9738(1)+0.9738(1)+0.8608(2)\\ &\quad+0.1466(4)+0.0047(6)+0.0001(8)+0.0000(9)\\ &=4.2846\\ \texttt{lambda\_new}[1]&=\frac{4.2846}{3.9553}\\ &=1.08 \end{aligned}$$

w.new[1] \(=0.49\), lambda_new[1] \(=1.08\)

sum(P_ik) \(=n=8\), since each row sums to 1.

(d) · Incomplete log-likelihood [2]

$$\begin{aligned} \ell(\theta^0)&=\sum_{i=1}^8\log\Big(\sum_k\texttt{prob.x.z}[i,k]\Big)\\ &=\log0.2217+\log0.2267+\log0.2267+\log0.1282\\ &\quad+\log0.0627+\log0.0646+\log0.0413+\log0.0275\\ &=-18.82 \end{aligned}$$

EM never decreases the incomplete log-likelihood.

\(\ell(\theta^0)=-18.82\), and after one iteration \(\ell\ge-18.82\)

(e) · Which run [2]

Report EM1 (\(\hat w_1=0.50\), \(\hat\lambda=(1.09,\ 6.63)\)): it has the highest final \(\ell\), \(-18.50\) against EM3's \(-22.87\).

EM2 is the same fit with labels switched (\(w\), \(\lambda\) swapped, same \(\ell\)).

EM3 started with \(\lambda_1^0=\lambda_2^0=4\), so every row of P_ik equals \((0.6,\ 0.4)\) and both rates become \(\bar x=3.875\): it is stuck at a stationary point, so discard it.
