Question 1

Setup (fresh; 10 marks, about 23 minutes, FX-82, 2 d.p.).

The random variable \(X\) has density \(f(x)\propto\tilde f(x)=x^2(2-x)\) for \(0<x<2\), and \(f(x)=0\) otherwise. You have access only to a generator of independent \(U(0,1)\) random numbers.

  1. Give a rejection sampling algorithm for \(X\) using the \(U(0,2)\) density as proposal. Find the smallest \(M\) for which it is valid, showing your calculus. [3]
  2. Find the probability that a single candidate is accepted. Show your work. [2]
  3. A student proposes instead \(g(x)=x/2\) on \((0,2)\). Explain how to simulate from \(g\) using one uniform, find the smallest \(M\) for this \(g\), and state the acceptance step. [3]
  4. Which of the two samplers is more efficient? Give the expected number of candidates per accepted draw for each. [2]

Write thisDon't write this

(a) · Algorithm with uniform proposal [3]

\(g(x)=\frac12\) on \((0,2)\), so \(\tilde f/g=2\tilde f\). Maximise \(\tilde f(x)=2x^2-x^3\):

$$\begin{aligned} \tilde f'(x)&=4x-3x^2\\ &=x(4-3x)=0\\ x^*&=\tfrac43\quad(x=0\text{ is a minimum})\\ \tilde f''\big(\tfrac43\big)&=4-8\lt0\quad\Rightarrow\text{ maximum}\\ \tilde f\big(\tfrac43\big)&=\tfrac{16}9\cdot\tfrac23\\ &=\tfrac{32}{27} \end{aligned}$$

So:

$$\begin{aligned} M&=\sup_x\frac{\tilde f(x)}{g(x)}\\ &=2\times\frac{32}{27}\\ &=\frac{64}{27}\\ &=2.37 \end{aligned}$$

Acceptance ratio:

$$\begin{aligned} \frac{\tilde f(x)}{Mg(x)}&=\frac{x^2(2-x)}{(64/27)(1/2)}\\ &=\frac{27x^2(2-x)}{32} \end{aligned}$$

Algorithm:

  1. Draw \(U_1,U_2\sim U(0,1)\) independently and set \(X=2U_1\).
  2. If \(U_2\le\dfrac{27X^2(2-X)}{32}\), return \(X\).
  3. Otherwise go back to step 1.

(b) · Acceptance probability [2]

\(\tilde f\) is not normalised, so find \(Z\):

$$\begin{aligned} Z&=\int_0^2(2x^2-x^3)\,dx\\ &=\Big[\frac{2x^3}3-\frac{x^4}4\Big]_0^2\\ &=\frac{16}3-4\\ &=\frac43\\ P(\text{accept})&=\frac ZM\\ &=\frac{4/3}{64/27}\\ &=\frac43\cdot\frac{27}{64}\\ &=\frac9{16}\\ &=0.56 \end{aligned}$$

\(P(\text{accept})=0.56\)

(c) · Proposal \(g(x)=x/2\) [3]

Inversion. The cdf is \(G(x)=x^2/4\):

$$\begin{aligned} u&=\frac{x^2}4\\ x&=2\sqrt u \end{aligned}$$

So \(X=2\sqrt{U_1}\). Smallest \(M\):

$$\begin{aligned} r(x)=\frac{\tilde f(x)}{g(x)}&=\frac{x^2(2-x)}{x/2}\\ &=4x-2x^2\\ r'(x)&=4-4x=0\quad\Rightarrow x^*=1\\ M&=r(1)\\ &=2 \end{aligned}$$

Acceptance ratio:

$$\begin{aligned} \frac{\tilde f(x)}{Mg(x)}&=\frac{2x(2-x)}2\\ &=x(2-x) \end{aligned}$$

Draw \(U_1,U_2\sim U(0,1)\), set \(X=2\sqrt{U_1}\), accept if \(U_2\le X(2-X)\), else repeat. \(M=2\)

(d) · Efficiency [2]

Expected candidates per accepted draw is \(M/Z\):

$$\begin{aligned} \text{(a)}:\quad&\frac{64/27}{4/3}=\frac{16}9=1.78\\ \text{(c)}:\quad&\frac2{4/3}=\frac32=1.50 \end{aligned}$$

Sampler (c) is more efficient: \(g\) rises from 0 like \(\tilde f\), so \(\tilde f/g\) is flatter and \(M\) smaller

Calculus with a max check · \(M=64/27\) · algorithm in steps · \(Z/M\), not \(1/M\) · \(2\sqrt U\) · \(M=2\) · \(M/Z\) for both.

Question 2

Setup (fresh; 10 marks, about 23 minutes, FX-82, 2 d.p.).

A random number \(X\) is generated as follows. (1) Generate \(U\) and \(V\) independently from \(U(0,1)\). (2) If \(UV<\tfrac12\), deliver \(X=U\); otherwise go to (1).

  1. Show that a single pass delivers a value with probability \(\tfrac12(1+\log2)\). [2]
  2. Find the cdf and the pdf of \(X\). [4]
  3. Let \(T\) be the number of passes needed to deliver one value. State the distribution of \(T\) and evaluate \(E[T]\). [2]
  4. The algorithm is changed to deliver \(Y=U^2\) instead. Find \(P(Y\le0.25)\). [2]

Write thisDon't write this

(a) · Delivery probability [2]

Given \(U=u\) we need \(V\lt\frac1{2u}\). That bound is at least 1 when \(u\le\frac12\):

$$\begin{aligned} P\big(V\lt\tfrac1{2u}\big)&=\begin{cases}1&0\lt u\le\tfrac12\\[2pt]\dfrac1{2u}&\tfrac12\lt u\lt1\end{cases} \end{aligned}$$

Integrate over \(u\):

$$\begin{aligned} A=P(\text{deliver})&=\int_0^{1/2}1\,du+\int_{1/2}^1\frac1{2u}\,du\\ &=\frac12+\frac12\big[\log u\big]_{1/2}^1\\ &=\frac12+\frac12\log2\\ &=\frac12(1+\log2) \end{aligned}$$

(b) · cdf and pdf [4]

\(X\) is \(U\) conditional on delivery:

$$\begin{aligned} F(x)&=\frac{P(U\le x,\ UV\lt\frac12)}{A} \end{aligned}$$

For \(0\lt x\le\frac12\):

$$\begin{aligned} F(x)&=\frac1A\int_0^x1\,du\\ &=\frac xA\\ &=\frac{2x}{1+\log2} \end{aligned}$$

For \(\frac12\lt x\lt1\):

$$\begin{aligned} F(x)&=\frac1A\Big(\frac12+\int_{1/2}^x\frac1{2u}\,du\Big)\\ &=\frac1A\Big(\frac12+\frac12\log(2x)\Big)\\ &=\frac{1+\log(2x)}{1+\log2} \end{aligned}$$

Differentiate each piece:

\(f(x)=\dfrac2{1+\log2}\) on \(0\lt x\le\frac12\); \(f(x)=\dfrac1{(1+\log2)\,x}\) on \(\frac12\lt x\lt1\)

Check: \(F(1)=1\), and both pieces give \(F(\frac12)=1/(1+\log2)=0.59\).

(c) · Number of passes [2]

Passes are independent, each succeeding with probability \(A\):

$$\begin{aligned} T&\sim\text{Geometric}(A)\text{ on }\{1,2,\dots\}\\ E[T]&=\frac1A\\ &=\frac2{1+\log2}\\ &=1.18 \end{aligned}$$

\(E[T]=1.18\)

(d) · \(Y=U^2\) [2]

\(U\gt0\), so \(\{Y\le0.25\}=\{U\le0.5\}\), with the same acceptance rule:

$$\begin{aligned} P(Y\le0.25)&=F(0.5)\\ &=\frac1{1+\log2}\\ &=0.59 \end{aligned}$$

\(P(Y\le0.25)=0.59\)
