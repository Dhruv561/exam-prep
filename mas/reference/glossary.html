Glossary

Every lesson uses these terms in exactly this sense. New terms get added with each lesson.

TermMeaningLesson
Likelihood \(L(\theta)\)The joint density/pmf of the observed data, read as a function of \(\theta\)1
Log-likelihood \(\ell(\theta)\)\(\log L(\theta)=\sum_i \log f(x_i;\theta)\) for independent data1
Score\(\ell'(\theta)\). The MLE solves score \(=0\)1
MLE \(\hat\theta\)The value of \(\theta\) that maximises \(\ell\)1
Observed information \(J(\theta)\)\(-\ell''(\theta)\) (minus the Hessian for vector \(\theta\)). Depends on the data1
Fisher information \(\mathcal I(\theta)\)\(\mathbb E\,J(\theta;X)\), for the whole sample. Doesn't depend on the data1
Asymptotic normality\(\hat\theta\approx N(\theta^*,\mathcal I(\theta^*)^{-1})\) for large \(n\)1
Consistency\(\hat\theta\to\theta^*\) in probability as \(n\to\infty\)1
EfficiencyAsymptotically unbiased, with the smallest possible variance \(\mathcal I^{-1}\)1
Wald CI\(\hat\theta\pm z_\alpha\sqrt{\mathcal I(\hat\theta)^{-1}}\) (or with \(J\) in place of \(\mathcal I\))1
InvarianceThe MLE of \(g(\theta)\) is \(g(\hat\theta)\)1
Logit\(\eta=\log\frac{p}{1-p}\), with inverse \(p=\frac{e^\eta}{1+e^\eta}\)1
Linear predictor \(\eta\)\(x^T\beta=\beta_0+\beta_1x_1+\dots\), linked to the mean by \(g(\cdot)=\eta\)1
Link function \(g\)Maps the mean (here \(p\in(0,1)\)) onto the real line: \(g(p_i)=\eta_i\). Binomial choices: logit \(\log\frac{p}{1-p}\), probit \(\Phi^{-1}(p)\), complementary log-log \(\log(-\log(1-p))\)2
Odds / odds ratioOdds \(=p/(1-p)\). In a logit model, raising \(x_j\) by \(\Delta\) multiplies the odds by \(e^{\beta_j\Delta}\) (the odds ratio). Logit link only2
Covariance matrix \(V\) of \(\hat\beta\)\(V=\mathcal I(\hat\beta)^{-1}\), R's vcov(model). SEs are \(\sqrt{V_{jj}}\); \(\operatorname{Var}(t^T\hat\beta)=t^TVt\) needs the covariances2
Saturated modelOne free parameter per observation (\(\tilde p_i=y_i/m_i\)); fits the data exactly, so it has the largest possible log-likelihood \(\ell_{\text{sat}}\)3
Deviance \(D\)\(2(\ell_{\text{sat}}-\ell(\hat\beta))\) on \(n-p\) df. "Scaled deviance" \(D/\phi\) is the same number for binomial/Poisson (\(\phi=1\))3
Residual / null deviance\(D\) of your model (df \(n-p\)) / of the intercept-only model (df \(n-1\)). So \(n=\) null df \(+1\), \(p=n-\) residual df3
Nested modelsA is nested in B if A is B with some parameters constrained (usually set to 0)3
Likelihood ratio test (LRT)For nested A ⊂ B: \(D_A-D_B=-2(\ell_A-\ell_B)\approx\chi^2_s\), \(s\) = extra parameters in B3
Wald test\(z=\hat\beta_j/\text{se}(\hat\beta_j)\approx N(0,1)\) under \(H_0:\beta_j=0\) (R's z value); \(z^2\approx\) LR3
Deviance goodness-of-fit testModel adequate ⇒ \(D\approx\chi^2_{n-p}\), only if \(m_ip_i, m_i(1-p_i)\gtrsim5\); never for 0/1 data3
AIC\(2p-2\ell(\hat\beta)\); smaller is better; models needn't be nested. \(\ell=p-\text{AIC}/2\)3
Pearson \(X^2\), dispersion \(\hat\phi\)\(X^2=\sum(y_i-\hat\mu_i)^2/v(\hat\mu_i)\); \(\hat\phi=X^2/(n-p)\). \(\hat\phi\gg1\) signals overdispersion (SEs too small)3
Likelihood-ratio confidence region\(\{\theta: 2\ell(\hat\theta)-2\ell(\theta)\le\chi^2_k(0.95)\}\), \(k=\dim\theta\): the \(\theta_0\) not rejected by the LRT of \(H_0:\theta=\theta_0\)4
Case-control (retrospective) studyCases and controls sampled separately. In a logit model only the intercept shifts (by \(\log\pi_1/\pi_0\)), so odds ratios stay valid but fitted \(p\) are not population risks4
Sparse dataMany groups with \(m_i\hat p_i\) or \(m_i(1-\hat p_i)<5\): the deviance fit test is invalid, but LRTs between nested models still work4
Exponential family\(f(y;\theta,\phi)=\exp\big[\frac{y\theta-b(\theta)}{a(\phi)}+c(y,\phi)\big]\); the support must not depend on \(\theta\); course uses \(a(\phi)=\phi\)5
Canonical parameter \(\theta\)The function of the parameters that multiplies \(y\) in \(\log f\). \(\mathbb EY=b'(\theta)\)5
Dispersion parameter \(\phi\)Scale parameter in \(a(\phi)\): \(\sigma^2\) (normal), \(1/\nu\) (gamma), 1 (Poisson, binomial). \(\operatorname{Var}Y=a(\phi)b''(\theta)\)5
Variance function \(v(\mu)\)\(b''\) written as a function of \(\mu\): \(v=b''\circ(b')^{-1}\), so \(\operatorname{Var}Y=a(\phi)v(\mu)\). Not the variance unless \(\phi=1\)5
Canonical link\(g=(b')^{-1}\), so \(g(\mu)=\theta=x^T\beta\). Makes \(X^Ty\) sufficient for \(\beta\); score \(X^T(y-\mu)/a(\phi)\). IWLS weights become \(W_{ii}=v(\mu_i)\) and \(J=\mathcal I\), so Newton–Raphson = Fisher scoring5, 6
GLMIndependent \(Y_i\) from one exponential family + linear predictor \(\eta_i=x_i^T\beta\) + monotone differentiable link \(g(\mu_i)=\eta_i\); \(\phi\) is not modelled6
Working response \(z_i\)\(z_i=\eta_i+(y_i-\mu_i)g'(\mu_i)\), a linearisation of \(g(y_i)\); the response of each IWLS weighted fit6
IWLS weights \(W_{ii}\)\(1/\big(g'(\mu_i)^2v(\mu_i)\big)\), the inverse variance of \(z_i\) up to \(a(\phi)\). Poisson-log: \(\mu_i\); Gamma-log: 16
IWLSStart \(\hat\mu^0=y\); repeat \(\hat\beta=(X^TWX)^{-1}X^TWz\) and update \(\mu,z,W\) until \(\hat\beta\) settles. Equals Fisher scoring for any GLM; R's "Fisher Scoring iterations"6
Fisher scoringNewton–Raphson with the observed information \(J\) replaced by the Fisher information \(\mathcal I\); same as NR for a canonical link6
Log link (multiplicative effect)\(\log\mu=\eta\): raising \(x_j\) by \(\Delta\) multiplies the mean (or rate) by \(e^{\beta_j\Delta}\); CI by exponentiating the endpoints7
Rate model / offset\(\log\lambda_i=\log t_i+x_i^T\beta\) for counts over exposure \(t_i\); R's offset(log(t)) fixes that coefficient at 1 (not estimated, not in \(p\)), so \(e^{\beta_j}\) are rate ratios7
Gamma GLMPositive skewed response with \(v(\mu)=\mu^2\), \(\operatorname{Var}Y=\phi\mu^2\) (CV \(=\sqrt\phi\)); canonical link \(1/\mu\) (R default), log link for multiplicative effects7
F test (\(\phi\) estimated)Nested A ⊂ B: \(F=\frac{(D_A-D_B)/s}{\hat\phi_B}\approx F_{s,n-p_B}\), with \(\hat\phi_B=X^2_B/(n-p_B)\) from the bigger model; R's anova(A, B, test="F")7
Pearson / deviance residual\(r_P=(y_i-\hat\mu_i)/\sqrt{v(\hat\mu_i)}\), \(\sum r_P^2=X^2\); \(r_D=\operatorname{sign}(y_i-\hat\mu_i)\sqrt{d_i}\), \(\sum r_D^2=D\) (R's default residuals(m))8
Leverage \(h_{ii}\)Diagonal of the IWLS hat matrix; \(\sum h_{ii}=p\). Potential to move the fit; rule of thumb flags \(h_{ii}>2p/n\). R's hatvalues(m)8
Standardised residual\(r_{SP}, r_{SD}\): \(r_P\) or \(r_D\) divided by \(\sqrt{(1-h_{ii})\hat\phi}\)8
Jack-knife residualApprox. standardised change when \(y_i\) is left out: \(\operatorname{sign}\cdot\sqrt{r_D^2+h\,r_P^2/(1-h)}\) (\(\phi=1\)); R's rstudent(m). Large ⇒ outlier8
Cook's distance \(C_i\)Influence: how far \(\hat\beta\) moves when \(y_i\) is dropped. \(C_i\approx r_P^2h_{ii}/[p\hat\phi(1-h_{ii})^2]\); needs leverage and a residual8
Known dispersion (averaged counts)If \(Y\) is the mean of \(k\) iid Poisson\((\mu)\) counts, it is an exponential family with \(\theta=\log\mu\), \(b=e^\theta\), \(\phi=1/k\) known, \(\operatorname{Var}Y=\mu/k\). Estimates unchanged, SEs scale by \(\sqrt{\phi}\)9
Prior weightsKnown per-observation weights \(w_i\) with \(a_i(\phi)=\phi/w_i\) (Faraway). R fits binomial proportions \(y_i/m_i\) with \(m_i\) as prior weights, hence \(V(\mu)=\mu(1-\mu)\)9
OverdispersionActual \(\operatorname{Var}Y_i\) exceeds the model's (Poisson \(\mu\), binomial \(mp(1-p)\)), from dependent trials or a \(p\)/rate that varies between units (unobserved heterogeneity). Signs: \(D\gg n-p\), tiny fit-test p-value, \(\hat\phi\gg1\). Ignoring it: \(\hat\beta\) fine, SEs and p-values too small10
Quasi-score \(u_i\)\(u_i=(Y_i-\mu_i)/(\phi v(\mu_i))\); needs only the mean and variance; \(\mathbb Eu_i=0\), \(-\mathbb E\,\partial u_i/\partial\mu_i=\mathbb Eu_i^2=1/(\phi v)\)11
Quasi log-likelihood \(Q\)\(Q_i=\int_{y_i}^{\mu_i}\frac{y_i-t}{\phi v(t)}dt\le0\), \(Q=\sum Q_i\). Slides often drop terms free of \(\mu\) ("up to a constant"); use the definite integral for numbers11
(Scaled) quasidevianceScaled: \(D_Q/\phi=-2\sum Q_i\) (saturated \(Q=0\)). Quasideviance: \(D_Q=-2\sum\int_{y_i}^{\mu_i}\frac{y_i-t}{v(t)}dt\); equals the Poisson/binomial deviance for \(v=\mu\) / \(\mu(m-\mu)/m\)11
Quasi-Poisson / quasi-binomial\(\operatorname{Var}Y=\phi\mu\) / \(\phi\,mp(1-p)\), \(\phi\) free (\(\hat\phi=X^2/(n-p)\)). Same \(\hat\beta\) and deviance as Poisson/binomial; SE \(\times\sqrt{\hat\phi}\); t value; AIC: NA; compare models with F. R: family=quasi(link=, variance=) for other \(v\)12
Efficiency (quasi vs MLE)Quasi estimators are consistent and asymptotically normal but usually have larger variance than the MLE when the true distribution is known11
Latent label \(Z_i\)Unobserved component label, \(Z_i\sim\text{Categorical}(\pi_1,\dots,\pi_K)\); mixing weights \(\pi_k\) sum to 114
Complete-data log-likelihood\(\log P(X,Z\mid\theta)=\sum_i\sum_k I(Z_i=k)[\log\pi_k+\log f_k(x_i)]\): the log-likelihood if the labels were observed. Lecture calls it the "complete log-likelihood"14, 17
Responsibility \(\gamma_{ik}\)\(P(Z_i=k\mid X,\theta^0)=\pi_kf_k(x_i)/\sum_j\pi_jf_j(x_i)\) (Bayes' rule), also called the posterior component probability; \(\sum_k\gamma_{ik}=1\); 1 for an observation whose label is known14, 16
Q-function \(Q(\theta,\theta^0)\)\(E_{Z\mid X,\theta^0}[\log P(X,Z\mid\theta)]=\sum_i\sum_k\gamma_{ik}[\log\pi_k+\log f_k(x_i;\theta)]\), the expected complete log-likelihood. \(\theta^0\) (numbers) fixes the weights \(\gamma_{ik}=P(Z_i=k\mid X_i,\theta^0)\); \(\theta\) is the free argument. Derive: indicators → log → linearity → \(E[I(Z_i=k)]=P(Z_i=k\mid X_i,\theta^0)\) → expand \(\log f\). Not the quasi-likelihood \(Q\) (Lesson 11)14, 17
Adam's / Eve's law\(\mathbb EX=\mathbb E[\mathbb E(X\mid Z)]\); \(\operatorname{Var}X=\mathbb E[\operatorname{Var}(X\mid Z)]+\operatorname{Var}[\mathbb E(X\mid Z)]\) (within + between)14
Conditional independenceData iid given the parameters; marginally dependent through the shared parameter14
Monte Carlo estimate\(\frac1N\sum_j g(X_j)\approx\mathbb Eg(X)\); rejection sampling accepts with probability \(1/k\)14
KernelA density with its normalising constant removed; matching it names the distribution and its parameters15
Full conditional\(p(\theta_j\mid\text{data},\text{all other parameters})\propto\) the joint read as a function of \(\theta_j\) alone15
Conjugate priorA prior whose posterior is in the same family, e.g. Gamma for a Poisson rate15
Precision \(\tau\)\(1/\sigma^2\). Normal–Normal: posterior precision = prior precision + \(n\tau\)15
Completing the square\(\exp(-\tfrac A2\mu^2+B\mu)\propto N(B/A,\,1/A)\)15
Marginal likelihood (evidence) \(p(x)\)\(\int p(x\mid\theta)p(\theta)\,d\theta\); free of \(\theta\), so it cancels in ∝ and in MH ratios15
Mixture component \(f_k\)The distribution of \(X_i\) given \(Z_i=k\), e.g. \(N(\mu_k,\sigma_k^2)\) (GMM) or Poisson\((\lambda_k)\)16
Mixing proportion \(\pi_k\)\(P(Z_i=k)\), also "mixture weight"; \(\pi_k>0\), \(\sum_k\pi_k=1\). The prior in the responsibility formula16
Latent variableA variable in the model that is never observed, here the label \(Z_i\). Generative story: draw \(Z_i\sim\text{Categorical}(\pi)\), then \(X_i\mid Z_i=k\sim f_k\)16
Mixture density\(P(X_i=x_i)=\sum_k\pi_kf_k(x_i)\) (total probability). Not the density of \(\sum_k\pi_kX_k\), which is a linear combination16
Complete / incomplete dataComplete \(=(X,Z)\), labels included; incomplete (observed) \(=X\) only. Observed-data (incomplete) log-likelihood \(\ell(\theta)=\sum_i\log\sum_k\pi_kf_k(x_i)\): log of a sum, so no closed-form MLE. R: sum(log(rowSums(M)))16
Classification rule (mixture)Assign \(x_i\) to cluster 1 if \(P(Z_i=1\mid x_i)>0.5\) (\(K=2\)), i.e. \(\pi_1f_1(x_i)>\pi_2f_2(x_i)\); for \(K\ge3\), the largest \(\gamma_{ik}\)16
EM algorithmExpectation–maximisation: find the MLE in a latent-variable model by iterating E-step and M-step from a start \(\theta^0\), setting \(\theta^0\leftarrow\hat\theta\) each time17
E-stepUsing the current \(\theta^0\), compute the posterior \(P(Z\mid X,\theta^0)\); for a mixture, every responsibility \(\gamma_{ik}\). This turns the complete log-likelihood into \(Q(\theta,\theta^0)\). R: P_ik = prob.x.z / rowSums(prob.x.z)17
M-step\(\hat\theta=\arg\max_\theta Q(\theta,\theta^0)\) with the \(\gamma_{ik}\) held fixed; gives weighted versions of the complete-data MLEs (e.g. \(\hat\pi_k=\frac1n\sum_i\gamma_{ik}\), \(\hat\mu_k=\sum_i\gamma_{ik}x_i/\sum_i\gamma_{ik}\))17, 18
Ascent (monotonicity) property\(\ell(\hat\theta)\ge\ell(\theta^0)\) every iteration: \(\ell(\theta)\ge Q(\theta,\theta^0)+C\) (Jensen, \(C=-\sum_Zq\log q\)), equality at \(\theta^0\) (Bayes), and the M-step raises \(Q\). A decreasing log_liks trace means a bug17
Stopping rule (EM)Stop when the incomplete log-likelihood changes by less than \(\epsilon\) (or after a maximum number of iterations). R: while((delta.ll > epsilon) & (n.iter <= max.iter))17
Local maximum / multiple startsEM climbs to a stationary point near its start, not necessarily the global maximum. Run from several initial values; keep the run with the highest final incomplete log-likelihood. Identical starting components (\(\lambda_1^0=\lambda_2^0\)) never separate17
Label switchingTwo EM runs giving the same fit with component labels swapped (\(\pi_1\leftrightarrow1-\pi_1\), parameters swapped); same \(\ell\), equally good17
Effective count \(N_k\)\(N_k=\sum_i\gamma_{ik}\), the expected number of points in component \(k\); denominator of the weighted mean and variance; \(\hat\pi_k=N_k/n\). R: colSums(P_ik)18
Weighted variance update\(\hat\sigma_k^2=\sum_i\gamma_{ik}(x_i-\hat\mu_k)^2/N_k\): differentiate w.r.t. \(\sigma^2\), plug in the new \(\hat\mu_k\). Shared variance: \(\hat\sigma^2=\frac1n\sum_i\sum_k\gamma_{ik}(x_i-\hat\mu_k)^2\)18
Lagrange multiplier (mixing proportions)Maximise \(\sum_kN_k\log\pi_k+\eta(1-\sum_k\pi_k)\): \(N_k/\pi_k=\eta\), \(\eta=n\), so \(\hat\pi_k=N_k/n\). For \(K=2\) just use \(\pi,1-\pi\)18, 19
Known-component observationNo \(Z_i\) in the model: contributes \(\log f_k(x_i)\) with weight 1 and no \(\log\pi\) term; enters \(\hat\mu_k,\hat\sigma_k^2\) but not \(\hat\pi\)17, 19
Observed label\(Z_i=k\) recorded: contributes \(\log\pi_k+\log f_k(x_i)\), so it counts in \(\hat\pi\)'s numerator and denominator19
Tied parameter (EM)Parameter shared by several components (common \(\sigma^2\), \(N(\mu,\sigma^2)/N(\mu,9\sigma^2)\), \(\text{Pois}(\lambda)/\text{Pois}(3\lambda)\)); its M-step derivative sums terms from every component18, 19
Zero-inflated PoissonMixture of a point mass at 0 (prob \(\pi\)) and Poisson(\(\lambda\)); \(\gamma_{i1}=\pi^0/(\pi^0+(1-\pi^0)e^{-\lambda^0})\) for zeros, 0 otherwise; \(\hat\lambda=\sum x_i/(n-\sum\gamma_{i1})\)19
prob.x.zLecturer's \(n\times K\) matrix: entry \([i,k]=\pi_kf_k(x_i)=P(X_i=x_i,Z_i=k)\); rowSums give \(P(X_i=x_i)\); sum(log(rowSums(.))) is \(\ell\)20
P_ikprob.x.z / rowSums(prob.x.z): the responsibilities \(\gamma_{ik}\); each row sums to 120
delta.ll, epsilon, max.iterGain in incomplete \(\ell\) per iteration; loop stops when gain \(\le\) epsilon or after max.iter iterations; length(log_liks) = iterations + 1. Hitting max.iter ≠ converged20
Stuck startEqual initial component parameters make \(\gamma_{ik}=\pi_k^0\) for all \(i\), so every component collapses to \(\bar x\): a stationary point, not the MLE17, 20
Poisson mixture with exposure\(X_i\mid Z_i=k\sim\text{Poisson}(t_i\lambda_k)\), \(t_i\) known. E-step: \(t_i^{x_i}/x_i!\) cancels but \(e^{-t_i\lambda_k^0}\) stays; M-step \(\hat\lambda_k=\sum_i\gamma_{ik}x_i/\sum_i\gamma_{ik}t_i\) (weighted count over weighted exposure)21
Prior \(p(\theta)\), posterior \(p(\theta\mid x)\)Prior: belief about \(\theta\) before the data; posterior \(p(\theta\mid x)=p(x\mid\theta)p(\theta)/p(x)\propto\) likelihood \(\times\) prior. Everything Bayesian (mean, interval, prediction) comes from it22
Hyperparameters \(m_0,\kappa_0,a,b\)The constants in the prior. Posterior parameters carry subscript \(n\): \(m_n,\kappa_n,a_n,b_n\). \(\kappa_0\) = prior precision of a mean (slides: \(\kappa_0=n_0\tau\), \(n_0\) = implicit prior sample size)22
Normal–Normal posterior\(x_i\sim N(\mu,1/\tau)\), \(\mu\sim N(m_0,1/\kappa_0)\): \(\mu\mid x\sim N\big(\frac{\kappa_0m_0+n\tau\bar x}{\kappa_0+n\tau},\frac1{\kappa_0+n\tau}\big)\); precisions add22
Shrinkage (posterior mean as weighted average)\(E[\theta\mid x]=w\,(\text{prior mean})+(1-w)\,\text{MLE}\), \(w=\kappa_0/(\kappa_0+n\tau)\) (Normal), \(b/(b+n)\) (Poisson–Gamma); \(w\to0\) as \(n\to\infty\)22
Credible intervalInterval with posterior probability 0.95 of containing \(\theta\) (central: 2.5% and 97.5% posterior quantiles; Normal posterior: mean \(\pm1.96\) sd). Not a confidence interval22
Posterior predictive \(p(\tilde x\mid x)\)\(\int p(\tilde x\mid\theta)p(\theta\mid x)d\theta\). Normal: \(N(m_n,\ 1/\kappa_n+1/\tau)\). Simulate: draw \(\theta^{(t)}\) from the posterior, then \(\tilde x^{(t)}\) from \(p(\tilde x\mid\theta^{(t)})\)22
Normal–Gamma joint prior\(\mu\mid\tau\sim N(m_0,1/(\kappa_0\tau))\), \(\tau\sim\text{Gamma}(a,b)\): posterior \(\mu\mid\tau,x\sim N(m_n,1/((n+\kappa_0)\tau))\), \(\tau\mid x\sim\text{Gamma}(a+n/2,\ b+S/2+\frac{n\kappa_0(\bar x-m_0)^2}{2(n+\kappa_0)})\)22
Vague / informative / improper priorVague: proper but nearly flat (\(N(0,10^6)\), Gamma(0.001, 0.001)). Informative: changes the posterior. Improper: \(\int p=\infty\) (\(p(\mu)\propto1\), \(p(\tau)\propto1/\tau\)); check the posterior kernel is a valid distribution (e.g. Poisson with \(p(\lambda)\propto1/\lambda\) needs \(\sum y_i>0\))22
BUGS dnorm(mean, prec)Second argument is a precision: dnorm(10, 0.01) is \(N(10,100)\)22
Monte Carlo (MC) standard error\(\text{sd}(g)/\sqrt N\) for \(N\) independent posterior draws, or \(\sqrt{\hat p(1-\hat p)/N}\) for a probability. It is the error of the estimate, not the posterior sd. For MCMC draws use \(s/\sqrt{\text{ESS}}\) instead (block means: \(S/\sqrt Q\))23, 26
Inverse-CDF method\(U\sim U(0,1)\Rightarrow F^{-1}(U)\) has cdf \(F\); solve \(u=F(x)\). Exponential(rate \(\lambda\)): \(x=-\ln(1-u)/\lambda\)23
Discrete inversion (while loop)Increase \(x\) while \(F(x)<u\); then \(P(X=x)=p(x)\)23
Rejection samplingDraw \(X\sim g\), \(U\sim U(0,1)\); accept if \(U\le\tilde f(X)/(M\,g(X))\). Needs only the unnormalised target \(\tilde f\)23
Envelope constant \(M\)Smallest valid \(M=\sup\tilde f/g\) (calculus). Acceptance probability \(Z/M\), \(Z=\int\tilde f\) (\(1/M\) if normalised); mean attempts per draw \(M/Z\)23
Prior as proposal\(g=p(\theta)\) gives \(M=\max_\theta p(x\mid\theta)\); accept if \(U\le p(x\mid\theta)/p(x\mid\hat\theta)\)23
Composition samplingDraw \(\theta\sim p(\theta\mid x)\), then \(\tilde x\sim p(\tilde x\mid\theta)\); the \(\tilde x\) alone follow the predictive23
Metropolis–Hastings (MH)Propose \(\theta^*\sim q(\cdot\mid\theta^c)\); accept with probability \(\alpha\), else repeat \(\theta^c\). The target is needed only up to a constant24
Target \(\pi\)Unnormalised density to sample; for a posterior \(\pi(\theta)=p(x\mid\theta)p(\theta)\)24
Proposal \(q(\theta^*\mid\theta^c)\)Density of landing on \(\theta^*\) when starting from \(\theta^c\)24
Acceptance probability \(\alpha\)\(\min\big\{1,\frac{\pi(\theta^*)\,q(\theta^c\mid\theta^*)}{\pi(\theta^c)\,q(\theta^*\mid\theta^c)}\big\}\); ledger: likelihood, priors, proposal ratio24
Proposal ratio\(q(\theta^c\mid\theta^*)/q(\theta^*\mid\theta^c)\), reverse over forward; equals 1 for a symmetric proposal. The reverse density uses the new value as its starting point24
Symmetric (random-walk) proposale.g. \(N(\theta^c,s^2)\): \(q\) cancels and \(\alpha=\min\{1,\pi(\theta^*)/\pi(\theta^c)\}\)24
Independence samplerProposal \(g\) ignores \(\theta^c\): \(\alpha=\min\{1,w(\theta^*)/w(\theta^c)\}\), \(w=\pi/g\)24
Log-scale random walk\(\log\tau^*\sim N(\log\tau^c,s^2)\) keeps \(\tau^*>0\); symmetric in \(\log\tau\) but the proposal ratio is \(\tau^*/\tau^c\)24
Burn-inInitial draws discarded because they still depend on the starting value. Choose it where traces of several chains from overdispersed starts overlap and \(\hat R<1.05\)24, 26
Acceptance rateFraction of proposals accepted (mean(diff(x) != 0)). Too high = tiny steps, too low = huge steps; about 0.2–0.5 is typical for a random walk24
Effective sample size (ESS)Number of independent draws the chain is worth: \(n/(1+2\sum_i\rho_i)\approx n(1-\hat\rho_1)/(1+\hat\rho_1)\)24, 26
Gibbs samplingCycle through the full conditionals \(p(\theta_j\mid\theta_{-j},x)\) using the newest values; MH with \(\alpha=1\), so no proposal and no accept/reject25
Full conditionalOne parameter given all others and the data: write the joint, keep factors containing the parameter, recognise the kernel, name it with parameters25
Gibbs schemeInitial values; for \(t=1,\dots,T\) draw each parameter from its conditional; discard burn-in; average \(g\) over the kept draws25
Hierarchical priorParameters whose prior depends on another parameter with its own prior, e.g. \(\theta_j\mid\mu,\tau_\theta\sim N(\mu,1/\tau_\theta)\), \(\mu\sim N(m_0,1/\kappa_0)\). The conditional of \(\mu\) involves only the \(\theta_j\) and \(\tau_\theta\), not the data; the \(\theta_j\) are shrunk toward \(\mu\)28
Changepoint modelRate \(\lambda_1\) up to an unknown year \(M\), then \(\lambda_2\): Gamma conditionals for the \(\lambda\)s, discrete conditional \(P(M=m)\propto(\lambda_1/\lambda_2)^{c_m}e^{(\lambda_2-\lambda_1)m}\)25
Discrete full conditionalEvaluate the unnormalised weight at every value and divide by the total; R: sample(1:n, 1, prob = w)25
rnorm and rgamma argumentsrnorm(1, mean, sd) takes the sd (use sqrt(v)); rgamma(1, shape, rate); an Inverse-Gamma draw is 1/rgamma(1, a, b)25
Trace plot\(\theta^{(t)}\) against \(t\). Stationary: hairy caterpillar, no trend, constant spread26
Overdispersed startsInitial values more spread out than the posterior, so several chains can reveal non-convergence26
Gelman–Rubin (BGR) \(\hat R\)\(B/W\): sd of the pooled draws over the mean within-chain sd, on the post-burn-in window (the slide version); \(<1.05\) supports convergence. It cannot detect regions no chain reached26
Autocorrelation (lag \(k\))\(\text{corr}(\theta^{(t)},\theta^{(t+k)})\); shown by an ACF plot, with a dashed band for independent draws26
ThinningKeep every \(k\)th draw; saves memory but never increases the ESS26
MixingHow fast the chain explores the target; slow mixing = wandering trace, slowly decaying ACF, small ESS26
KL divergence\(\text{KL}(q\|p)=E_q[\log q(\theta)-\log p(\theta\mid x)]\ge0\); not symmetric. VI minimises \(\text{KL}(q\|\text{posterior})\)27
ELBO\(E_q[\log p(\theta,x)]-E_q[\log q(\theta)]\); \(\log p(x)=\text{ELBO}+\text{KL}\), so ELBO \(\le\log p(x)\) and maximising it minimises the KL without needing \(p(x)\)27
Variational inference (VI)Approximate the posterior by the nearest member \(q\) of a family \(\mathcal D\) by optimisation; fast, not exact27
Mean-field family\(q(\theta)=\prod_jq_j(\theta_j)\): an assumption about the approximation, not the model27
CAVIUpdate \(q^*_j\propto\exp\{E_{-j}[\log p(\theta,x)]\}\) holding the other factors fixed; the ELBO never decreases; local optimum only27
\(E_\mu[(c-\mu)^2]\) trick\(=(c-E[\mu])^2+V[\mu]\); gives the rate of \(q^*_\tau\) in Normal–Gamma CAVI (and \(q^*_{\sigma^2}\) for an Inverse-Gamma)27
VI vs MCMCVI: fast and deterministic but underestimates posterior variance (bivariate Normal: \(\sigma^2(1-\rho^2)\)). MCMC: slow, exact in the limit27
