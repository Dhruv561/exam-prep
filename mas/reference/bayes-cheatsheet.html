Notation: Normal\((\text{mean},\text{variance})\); \(\tau=1/\sigma^2\); Gamma\((\text{shape},\text{rate})\); Inverse-Gamma\((\text{shape},\text{scale})\); \(\tau\sim\text{Gamma}(a,b)\iff\sigma^2\sim\text{Inv-Gamma}(a,b)\); \(S_\mu=\sum_i(x_i-\mu)^2\), \(S=\sum_i(x_i-\bar x)^2\); posterior parameters carry subscript \(n\); \(\pi\) is the unnormalised target, \(\theta^c\) current, \(\theta^*\) proposed.

Bayes' rule · L22

$$p(\theta\mid x)=\frac{p(x\mid\theta)p(\theta)}{p(x)}\ \propto\ p(x\mid\theta)\,p(\theta)$$

Drop every factor free of \(\theta\) (\(p(x)\), \(x_i!\), \(\sqrt{2\pi}\), \(b^a/\Gamma(a)\)); keep any factor containing it (\(\tau^{n/2}\), the \(\sqrt{\kappa_0\tau}\) of \(p(\mu\mid\tau)\)). Joint prior \(p(\mu,\tau)=p(\mu\mid\tau)p(\tau)\). Intro Bayes slide 8

Summaries. Mean \(E[\theta\mid x]\); 95% credible interval = central 95% (Normal posterior: mean \(\pm1.96\) sd), \(P(\theta\in I\mid x)=0.95\). Predictive \(p(\tilde x\mid x)=\int p(\tilde x\mid\theta)p(\theta\mid x)d\theta\); Normal: \(N(m_n,\ 1/\kappa_n+1/\tau)\). By simulation: draw \(\theta^{(t)}\), then \(\tilde x^{(t)}\mid\theta^{(t)}\).

Priors · L22

Vague: proper, nearly flat (\(N(0,10^6)\), Gamma\((0.001,0.001)\)). Informative: \(\kappa_0\) or \(b\) comparable to \(n\tau\) or \(n\). Improper: \(\int p=\infty\): \(p(\mu)\propto1\), \(p(\tau)\propto1/\tau\), \(p(\sigma^2)\propto1/\sigma^2\). Check the posterior kernel is a valid distribution:

\(p(\mu)\propto1\Rightarrow N(\bar x,\frac1{n\tau})\) · \(p(\tau)\propto\frac1\tau\Rightarrow\text{Gamma}(\frac n2,\frac S2)\), proper iff \(S>0\) · Poisson \(p(\lambda)\propto\frac1\lambda\Rightarrow\text{Gamma}(\sum y,n)\), proper iff \(\sum y>0\).

BUGS dnorm(mean, precision): dnorm(10, 0.01) is \(N(10,100)\).

Gibbs sampling · L25 · MCMC slides 13–23

  1. Write the joint = likelihood \(\times\) every prior. 2. Treat other parameters as constants; keep each factor containing \(\theta_j\). 3. Recognise the kernel: \(\exp\{\text{quadratic}\}\to\) Normal (complete the square); \(\theta^{s-1}e^{-r\theta}\to\) Gamma; finite set \(\to\) weights, divide by the total. 4. State name and both parameters, in the sheet's parametrisation.

Scheme: initial values; for \(t=1,\dots,T\) draw each parameter from its conditional using the newest values of the others; discard burn-in; average \(g\) over kept draws. It is MH with \(\alpha=1\), so no proposal and no accept/reject.

Metropolis–Hastings · L24 · MCMC slides 4–12

$$\alpha=\min\Big\{1,\ \underbrace{\frac{\pi(\theta^*)}{\pi(\theta^c)}}_{\text{target ratio}}\times\underbrace{\frac{q(\theta^c\mid\theta^*)}{q(\theta^*\mid\theta^c)}}_{\text{proposal: reverse/forward}}\Big\},\qquad\pi=p(x\mid\theta)\,p(\theta)\ \ (\text{posterior kernel})$$

Propose \(\theta^*\sim q(\cdot\mid\theta^c)\); draw \(u\sim U(0,1)\); accept if \(u<\alpha\), else repeat \(\theta^c\). Logs: \(\log\alpha=\min\{0,\ \log\pi^*-\log\pi^c+\log q(\theta^c\mid\theta^*)-\log q(\theta^*\mid\theta^c)\}\), accept if \(\log u<\log\alpha\).

Ledger order (one line per factor, 4 d.p., round once): (i) likelihood ratio, keeping powers like \((\tau^*/\tau^c)^{n/2}\) · (ii) each prior ratio, keeping \(\sqrt{\tau}\) of \(p(\mu\mid\tau)\) · (iii) proposal ratio for each proposed parameter · multiply · \(\min\{1,\cdot\}\).

Proposal ratio. Reverse density starts at \(\theta^*\) and lands on \(\theta^c\): a rate or variance that depended on \(\theta^c\) forward depends on \(\theta^*\) in reverse. Exponential\((\text{rate }1/\tau^c)\): \(q=\frac1{\tau^c}e^{-\tau^*/\tau^c}\); Gamma\((\nu,\nu/\tau^c)\): rate changes too; Normal\((\mu^c,1/\tau^*)\): forward variance \(1/\tau^*\), reverse \(1/\tau^c\).

Tuning. Acceptance too high (0.9) = tiny steps, slow ACF decay; too low (0.05) = huge steps, flat stretches. Aim about 0.2–0.5. Leaving out the proposal ratio gives complete-looking working and loses about 2 marks.

Monte Carlo and rejection · L23

MC: \(E[g(\theta)\mid x]\approx\frac1N\sum g(\theta^{(s)})\); a probability is the mean of indicators. SE \(=\text{sd}(g)/\sqrt N\) or \(\sqrt{\hat p(1-\hat p)/N}\) (independent draws only; not the posterior sd). MC slides 3, 24–28

Inversion: \(U\sim U(0,1)\Rightarrow F^{-1}(U)\sim F\); solve \(u=F(x)\) (Exp(rate \(\lambda\)): \(x=-\ln(1-u)/\lambda\)). Discrete: increase \(x\) while \(F(x)<u\).

Rejection (target \(\tilde f=Zf\), proposal \(g\)): draw \(X\sim g\), \(U\sim U(0,1)\); accept if \(U\le\dfrac{\tilde f(X)}{M\,g(X)}\). Smallest \(M=\sup\tilde f/g\) (differentiate, check max). \(P(\text{accept})=Z/M\) (\(1/M\) if \(f\) is normalised); attempts per draw \(M/Z\). Proposal = prior: \(M=\max_\theta p(x\mid\theta)\), accept if \(U\le p(x\mid\theta)/p(x\mid\hat\theta)\).

Diagnostics · L26 · diagnostics slides 7–14

Trace plot: stationary = hairy caterpillar, no trend, constant spread; burn-in = where chains from overdispersed starts overlap. Wandering trace, slow ACF decay = poor mixing. Informal: traces and ACF. Formal: \(\hat R\).

\(\hat R=B/W\): \(B\) = sd of all pooled draws, \(W\) = mean of within-chain sds, on the post-burn-in window; \(\hat R<1.05\) accepts. It cannot see regions no chain reached, nor autocorrelation.

\(\rho_k\) = lag-\(k\) autocorrelation. \(\text{ESS}=\dfrac{n}{1+2\sum\rho_i}\approx n\dfrac{1-\hat\rho_1}{1+\hat\rho_1}\). MCMC SE \(=s/\sqrt{\text{ESS}}\), not \(s/\sqrt n\); block means: \(S/\sqrt Q\). Thinning saves memory, never raises ESS.

Variational inference and CAVI · L27 · VI slides 8–24

$$q^*_j(\theta_j)\propto\exp\big\{E_{-j}[\log p(\theta,x)]\big\},\qquad q=\prod_jq_j$$ $$\begin{aligned}\text{ELBO}&=E_q[\log p(\theta,x)]-E_q[\log q]\\\log p(x)&=\text{ELBO}+\text{KL}(q\|p)\end{aligned}$$

Maximise ELBO \(\iff\) minimise KL; ELBO \(\le\log p(x)\); never needs \(p(x)\). CAVI never lowers the ELBO; local optimum only.

Recipe: log joint line by line, keep terms with \(\theta_j\), take \(E_{-j}\), expand squares, name. Trick: \(E_\mu[(c-\mu)^2]=(c-E[\mu])^2+V[\mu]\). \(E[\tau]=a^*/b^*\) for Gamma\((a^*,b^*)\).

Joint prior \(\mu\mid\tau\sim N(m_0,\frac1{\kappa_0\tau})\)Independent \(\mu\sim N(m_0,\frac1{\kappa_0})\)
\(q^*_\mu=N(m^*,v^*)\)\(m^*=\frac{\kappa_0m_0+n\bar x}{\kappa_0+n}\), \(v^*=\frac1{(\kappa_0+n)E[\tau]}\)\(m^*=\frac{\kappa_0m_0+E[\tau]n\bar x}{\kappa_0+nE[\tau]}\), \(v^*=\frac1{\kappa_0+nE[\tau]}\)
\(q^*_\tau=\text{Gamma}(a^*,b^*)\)\(a^*=a+\frac{n+1}2\), \(b^*=b+\frac12[\sum(x_i-E\mu)^2+nV\mu]+\frac{\kappa_0}2[(E\mu-m_0)^2+V\mu]\)\(a^*=a+\frac n2\), \(b^*=b+\frac12[\sum(x_i-E\mu)^2+nV\mu]\)

Iterate \(q_\mu\to q_\tau\to\cdots\); \(q^*_{\sigma^2}\) under an Inv-Gamma prior is Inv-Gamma with the same \(b^*\) expression. VI vs MCMC: VI fast and deterministic, but mean-field underestimates variance (bivariate Normal: \(\sigma^2(1-\rho^2)\)); MCMC slow but exact in the limit.
