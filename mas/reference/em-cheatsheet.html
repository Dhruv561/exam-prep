Mixture models and the EM algorithm

Topic 4 on two printed pages. The formula sheet gives only pdfs and means, so every EM formula below is A4 material. EM is a 10–12-mark question: write \(Q(\theta,\theta^0)\), give the E-step, derive the M-step, often with a twist. Each heading links to its lesson. Notation: current values \(\theta^0\), new values \(\hat\theta\), \(\gamma_{ik}:=P(Z_i=k\mid X_i,\theta^0)\), \(N_k=\sum_i\gamma_{ik}\). The lecturer's 2026 notes write \(\theta^{(t)},r_{ik}^{(t)}\) for the same things.

Model and three log-likelihoods · L16, L17

\(Z_i\sim\text{Categorical}(\pi_1,\dots,\pi_K)\), \(X_i\mid Z_i=k\sim f(\cdot\,;\theta_k)\). For \(K=2\), use \(\text{Cat}(\pi,1-\pi)\). Free parameters: \(\pi_1,\dots,\pi_{K-1}\) plus the component parameters. Mixture slides 12–15; EM slides 6–7

E-step: responsibilities · L16

$$\gamma_{ik}=P(Z_i=k\mid X_i,\theta^0)=\frac{\pi_k^0f(x_i;\theta_k^0)}{\sum_{k'}\pi_{k'}^0f(x_i;\theta_{k'}^0)}$$

This is Bayes' rule: joint \(\div\) marginal. \(\sum_k\gamma_{ik}=1\), so \(\sum_{i,k}\gamma_{ik}=n\). Cancel only factors common to every term (\(x_i!\), \(\frac1{\sqrt{2\pi}}\); \(1/\sigma_k\) only if the variances are equal). EM slide 8

Classify: assign \(x_i\) to \(\arg\max_k\gamma_{ik}\). For \(K=2\): component 1 iff \(\gamma_{i1}>0.5\iff\pi_1f_1(x_i)>\pi_2f_2(x_i)\). With equal \(\sigma\), the boundary is at \(\frac{\mu_1+\mu_2}2+\frac{\sigma^2\log(\pi_2/\pi_1)}{\mu_1-\mu_2}\). Report \(\gamma\) itself when asked "how confident".

The EM algorithm · L17

  1. Initialise \(\theta^0\) and evaluate \(\ell(\theta^0)\).
  2. E-step: using \(\theta^0\), compute \(\gamma_{ik}=E_{Z\mid X,\theta^0}[I(Z_i=k)]\) for all \(i,k\). This gives \(Q(\theta,\theta^0)\).
  3. M-step: \(\hat\theta=\arg\max_\theta Q(\theta,\theta^0)\), holding \(\gamma_{ik}\) fixed as numbers.
  4. Evaluate \(\ell(\hat\theta)\). Stop if \(|\ell(\hat\theta)-\ell(\theta^0)|<\varepsilon\) (or after max iterations); else set \(\theta^0\leftarrow\hat\theta\) and go to 2.

Ascent: \(\ell(\hat\theta)\ge Q(\hat\theta,\theta^0)+C\ge Q(\theta^0,\theta^0)+C=\ell(\theta^0)\), with \(C=-\sum_Zq(Z)\log q(Z)\) and \(q=P(Z\mid X,\theta^0)\). By Jensen, equality holds at \(\theta^0\). So \(\ell\) never decreases: a falling \(\ell\) trace means a bug. Local maxima: run from several starts and keep the run with the largest final \(\ell\). Runs with the same \(\ell\) and permuted labels are label switching (the same fit). Equal starts (\(\mu_1^0=\mu_2^0\)) stay stuck: the components never separate. slides 16–17, 22–23

\(Q(\theta,\theta^0)\), general \(K\) · L17 · write these lines in the exam

$$\begin{aligned} P(X,Z\mid\theta)&=\prod_{i=1}^n\prod_{k=1}^K\big[\pi_kf(x_i;\theta_k)\big]^{I(Z_i=k)}\\ \log P(X,Z\mid\theta)&=\sum_{i=1}^n\sum_{k=1}^KI(Z_i=k)\big[\log\pi_k+\log f(x_i;\theta_k)\big]\\ Q(\theta,\theta^0)&=\sum_{i=1}^n\sum_{k=1}^KE_{Z\mid X,\theta^0}[I(Z_i=k)]\big[\log\pi_k+\log f(x_i;\theta_k)\big]\quad\text{(linearity)}\\ &=\sum_{i=1}^n\sum_{k=1}^K\gamma_{ik}\big[\log\pi_k+\log f(x_i;\theta_k)\big]\quad\text{(}E[I]=P\text{)} \end{aligned}$$

Then expand \(\log f\). Normal: \(-\tfrac12\log(2\pi\sigma_k^2)-\tfrac{(x_i-\mu_k)^2}{2\sigma_k^2}\) · Poisson: \(x_i\log\lambda_k-\lambda_k-\log x_i!\) · Exponential: \(\log\lambda_k-\lambda_kx_i\). For \(K=2\), write it out with \(\log\pi\) and \(\log(1-\pi)\). Keep constants such as \(-\log x_i!\) in \(Q\) (or write "+ const"). slides 18–20; tute wk 7 Q2

\(\mu_k\) (only component \(k\) contains \(\mu_k\)):

$$\begin{aligned} \frac{\partial Q}{\partial\mu_k}&=\sum_i\gamma_{ik}\frac{x_i-\mu_k}{\sigma_k^2}=0\\ \sum_i\gamma_{ik}x_i&=\mu_k\sum_i\gamma_{ik}\\ \hat\mu_k&=\frac{\sum_i\gamma_{ik}x_i}{N_k} \end{aligned}$$

\(K=2\) (no Lagrange):

$$\begin{aligned} \frac{\partial Q}{\partial\pi}&=\frac{N_1}{\pi}-\frac{N_2}{1-\pi}=0\\ N_1(1-\pi)&=N_2\pi\\ \hat\pi&=\frac{N_1}{N_1+N_2}=\frac{N_1}{n} \end{aligned}$$

\(\sigma_k^2\) (treat \(v=\sigma_k^2\) as the variable):

$$\begin{aligned} \frac{\partial Q}{\partial v}&=\sum_i\gamma_{ik}\Big[-\frac1{2v}+\frac{(x_i-\mu_k)^2}{2v^2}\Big]=0\\ v\sum_i\gamma_{ik}&=\sum_i\gamma_{ik}(x_i-\mu_k)^2\\ \hat\sigma_k^2&=\frac{\sum_i\gamma_{ik}(x_i-\hat\mu_k)^2}{N_k} \end{aligned}$$

\(\pi_k\), general \(K\) (Lagrange, constraint \(\sum_k\pi_k=1\)):

$$\begin{aligned} \mathcal L&=\sum_kN_k\log\pi_k+\alpha\Big(1-\sum_k\pi_k\Big)\\ \frac{\partial\mathcal L}{\partial\pi_k}&=\frac{N_k}{\pi_k}-\alpha=0\\ \pi_k&=N_k/\alpha\\ 1=\sum_k\pi_k&=\frac{\sum_kN_k}{\alpha}=\frac n\alpha\\ \hat\pi_k&=N_k/n \end{aligned}$$

Mixture mean and variance · L16

Condition on \(Z\) (Adam's and Eve's laws). Write \(\bar\mu=\sum_k\pi_k\mu_k\).

$$\begin{aligned} \mathbb EX&=\mathbb E[\mathbb E(X\mid Z)]\\ &=\textstyle\sum_k\pi_k\mu_k=\bar\mu\\ \operatorname{Var}X&=\mathbb E[\operatorname{Var}(X\mid Z)]+\operatorname{Var}[\mathbb E(X\mid Z)]\\ &=\textstyle\sum_k\pi_k\sigma_k^2+\sum_k\pi_k(\mu_k-\bar\mu)^2\\ &=\textstyle\sum_k\pi_k\sigma_k^2+\pi_1\pi_2(\mu_1-\mu_2)^2\ \ (K=2) \end{aligned}$$

Poisson mixture: \(\operatorname{Var}X=\bar\lambda+\sum_k\pi_k(\lambda_k-\bar\lambda)^2>\mathbb EX\), so it is overdispersed. A mixture is not \(\pi_1X_1+\pi_2X_2\): pick a component, then sample.

For your A4 sheet A4

  1. \(\ell(\theta)=\sum_i\log\sum_k\pi_kf(x_i;\theta_k)\) vs complete \(\sum_i\sum_kI(Z_i=k)[\log\pi_k+\log f]\)
  2. \(Q=\sum_i\sum_k\gamma_{ik}[\log\pi_k+\log f(x_i;\theta_k)]\), with \(E[I(Z_i=k)\mid X,\theta^0]=\gamma_{ik}\)
  3. \(\gamma_{ik}=\pi_k^0f(x_i;\theta_k^0)\big/\sum_{k'}\pi_{k'}^0f(x_i;\theta_{k'}^0)\); classify by \(\arg\max_k\)
  4. Algorithm: init → E → M → stop when \(\Delta\ell<\varepsilon\); multiple starts, keep max \(\ell\)
  5. \(\hat\pi_k=N_k/n\) (Lagrange: \(N_k/\pi_k=\alpha\), \(\alpha=n\))
  6. \(\hat\mu_k,\hat\lambda_k^{\text{Pois}}=\sum\gamma x/N_k\); \(\hat\sigma_k^2=\sum\gamma(x-\hat\mu_k)^2/N_k\); \(\hat\lambda_k^{\text{Exp}}=N_k/\sum\gamma x\)
  7. Twists: known component with no \(Z\) → \(+\log f\), no \(\pi\); tied parameter → sum the derivative over \(k\)
  8. \(\operatorname{Var}X=\sum\pi_k\sigma_k^2+\sum\pi_k(\mu_k-\bar\mu)^2\)
