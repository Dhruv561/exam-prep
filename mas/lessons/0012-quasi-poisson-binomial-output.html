Lesson 12 · Topic 3: Overdispersion & quasi-likelihood

Reading quasi-Poisson and quasi-binomial R output: SEs, the F test, and which model to prefer

The goal: handed a Poisson printout, a Pearson \(\hat\phi\) line and the quasipoisson refit, you can give any SE "allowing for overdispersion", run (or explain) the F test for nested quasi models with its df, and say which model you'd keep and why. That's the same with quasibinomial.

Why this matters for 10 Nov: every paper from 2016 to 2022 has this inside the 7–22 mark GLM R-output question, as a run of 1–3 mark sub-parts. The marks go to the person who picks the right \(\hat\phi\), divides by \(s\), and gives the df.

You already know what overdispersion is and how to spot it (Lesson 10), and why the quasi-score gives the same \(\hat\beta\) with \(\operatorname{Var}\hat\beta\) scaled by \(\phi\) (Lesson 11). You've also met the F test with an estimated \(\phi\) for the gamma (Lesson 7), and \(\hat\ell\) from AIC plus the χ² LRT (Lesson 3). This lesson is pure printout reading.

1. Compare modelB (poisson) with modelD (quasipoisson, same formula). Which statement is correct?

Both print \(D = 1696.7\) on 139 df and SexM = 0.1616, but the SE goes from 0.04253 to 0.1543 (\(\times3.63 = \sqrt{13.17}\)). AIC does become NA, but that isn't the only change, so (d) is wrong. The scaled deviance is \(D/\phi\), but R prints the unscaled \(D\), so (b) is wrong too.

2 · SE allowing for overdispersion, both directions

$$\mathrm{SE}_{\text{quasi}}(\hat\beta_j) = \sqrt{\hat\phi}\;\mathrm{SE}_{\text{Pois}}(\hat\beta_j),\qquad \mathrm{SE}_{\text{Pois}} = \mathrm{SE}_{\text{quasi}}\big/\sqrt{\hat\phi},\qquad t_j = z_j\big/\sqrt{\hat\phi}.$$

The estimate itself is never rescaled. Use the \(\hat\phi\) of the model the coefficient belongs to.

Trout-egg demo (lecturer's notes, p. 10): 0.2461*sqrt(phihat) gives the quasibinomial SE 0.5682. That one line is the whole skill.

2. Using only summary(modelB) and the \(\hat\phi\) lines, give the SE of the SexM coefficient allowing for overdispersion (4 d.p.).

\(0.04253\times\sqrt{13.16684} = 0.04253\times3.6286 = \)0.1543, matching modelD's printout. It's modelB's \(\hat\phi\) (13.17), since SexM is in modelB. With modelA's 13.14 you'd be using the wrong model's dispersion. Here the difference is invisible, but in the challenge below it isn't.

3. Suppose you'd been given summary(modelD) only. What would the plain Poisson fit print as the SE of LrnSL (4 d.p.)? (Newer papers ask this way round.)

\(0.1888/\sqrt{13.16691} = 0.1888/3.6286 = \)0.0520 (modelB prints 0.05204, and the gap is just rounding of 0.1888). The estimate stays 0.3489. Likewise \(z = t\sqrt{\hat\phi} = 1.848\times3.6286 = 6.71\), matching 6.705.

Check the test column the same way: AgeF3 has \(z = 6.319\) under Poisson, so \(t = 6.319/3.6286 = 1.741\), as printed. A "highly significant" \(z\) turns into \(p = 0.084\). That's the slide-13 message: ignore overdispersion and you get spurious significance (slide 13).

3 · The F test for nested quasi models

$$F = \frac{(D_A - D_B)/s}{\hat\phi_B}\;\approx\;F_{s,\;n-p_B}\quad\text{under }H_0\text{: model A (smaller) is adequate},$$

\(s = \text{df}_A - \text{df}_B\) (extra parameters in B); \(\hat\phi_B = X^2_B/(n-p_B)\), the Pearson statistic of the bigger model over its residual df (slide 9; annotated). The second df is B's residual df.

Why F and not χ²? \(\phi\) is unknown, and the slide-12 point is that the scaled deviance \(D/\phi\) is no longer \(D\). Divide \(\Delta D\) by \(\hat\phi\) to get back to the χ² scale, and the noise in \(\hat\phi\) turns χ²/s into an F (same argument as for the gamma in Lesson 7). The lecturer's demo does it by hand: (913.56 - 64.5)/4/phihat (p. 13).

4. What does (phiB <- sum(residuals(modelB, type = "pearson")^2/modelB$df.residual)) compute? (It printed 13.16684.)

Pearson residuals are \((y_i-\hat\mu_i)/\sqrt{v(\hat\mu_i)}\), so the sum of squares is \(X^2\), and df.residual is \(n-p = 139\). So \(\hat\phi = X^2/(n-p)\) for modelB, the one the F test needs. (a) would be \(1696.7/139 = 12.21\), a different (deviance-based) estimate. (c) is phiA, which is 13.14 here.

5. Suppose the anova(modelC, modelD, test = "F") row were hidden. Compute F from the rest of the printout (3 d.p.). (Also note the df for yourself.)

\(F = \dfrac{(1711.1 - 1696.7)/1}{13.16684} = \dfrac{14.404}{13.16684} = \)1.094 on \((s,\ n-p_B) = (1,\ 146-7) = (1,\ 139)\) df. Since \(1.094 < F_{1,139}(0.95) = 3.91\), don't reject \(H_0\) (R: p = 0.297). If the row is shown and you're asked "what formula has been used", this line plus the df is the full-marks answer.

6. Allowing for overdispersion, which model do you prefer?

The χ² LRT compares \(\Delta D = 14.40\) with 3.84 as if \(\phi = 1\), but the variance is about 13 times that. Rescaled, the evidence for Sex is \(F = 1.09\), well below 3.91, so drop Sex: the simpler modelC. (c): a bigger model always has the lower deviance. (d): nested quasi models are compared with F, not AIC.
Traps
(1) Two \(\hat\phi\) lines are printed. The F test uses the bigger model's. A's \(\hat\phi\) is inflated by the lack of fit you're testing for. (2) Divide by \(s\) as well as \(\hat\phi\). With \(s = 1\) it's invisible, but for a factor with 4 levels \(s = 3\). (3) Second df \(= n - p_B\), not \(n - p_A\), and not \(n\). (4) Don't run a goodness-of-fit test on the quasi deviance: \(\phi\) is estimated from the same residuals (slide 12).
Explain why (2–3 sentences): χ² says keep Sex, F says drop it. Which do you believe?

Model answer. The χ² test assumes \(\operatorname{Var}Y_i = \mu_i\) (\(\phi = 1\)), but \(\hat\phi = 13.2\) shows the counts vary about 13 times more than that. So \(\Delta D = 14.4\) is mostly noise, and the χ² p-value (0.00015) is far too small. The F test divides \(\Delta D/s\) by \(\hat\phi\) and gives \(F = 1.09\) on (1, 139) df, p = 0.30. Allowing for overdispersion, Sex isn't needed, so prefer modelC.

4 · Wald CIs and predictions under quasi

Same recipe as Lesson 7: build on the \(\eta\) scale with the quasi SE, then exponentiate. Use \(z_{0.975} = 1.96\). (\(t_{n-p}\) is also acceptable since \(\phi\) is estimated, and here it's 1.98, which barely matters.) The point prediction \(e^{\hat\eta}\) is identical under both fits. Only its CI widens.

SexM: \(0.1616 \pm 1.96(0.1543) = (-0.141,\ 0.464)\), so the ratio of mean days absent (boys/girls) is \(e^{0.1616} = 1.18\) with CI \((0.87,\ 1.59)\). That contains 1, which agrees with the F test. Under Poisson it was \((1.08,\ 1.28)\), falsely precise.

8. Under f1, what is the expected number of falls in a year on a medical ward with 12 thousand bed-days and mean patient age 80 (2 d.p.)?

\(\hat\eta = \log 12 - 1.01866 + 0.41242 + 0.01197(80) = 2.48491 + 0.35136 = 2.83627\), so \(\hat\mu = e^{2.8363} = \)17.05 falls. Forget the \(\log 12\) and you get the rate per thousand bed-days, 1.42. \(\hat\phi = 4.32\) changes nothing here: it only matters for the CI.

5 · Still asked alongside: ℓ̂ and saturated ℓ from the Poisson AIC

The quasi fit prints AIC: NA, so likelihood questions always use the Poisson printout (Lesson 3):

$$\hat\ell = -\tfrac12(\text{AIC} - 2p) = p - \tfrac{\text{AIC}}{2},\qquad \ell_{\text{sat}} = \hat\ell + \tfrac{D}{2}\quad(\text{since } D = 2(\ell_{\text{sat}} - \hat\ell),\ \phi = 1).$$

\(p\) counts every coefficient row including the intercept (modelB: \(p = 146 - 139 = 7\)).

9. From summary(modelB), find the maximised log-likelihood of the saturated Poisson model (2 d.p.).

\(\hat\ell_B = 7 - 2299.2/2 = -1142.60\). Then \(\ell_{\text{sat}} = -1142.60 + 1696.7/2 = \)−294.25. Check with modelA: \(6 - 2311.6/2 = -1149.80\), \(+1711.1/2 = -294.25\) ✓. The saturated model doesn't depend on which model you fitted. The same holds for any "which Poisson model is better" part: AIC \(2299.2 < 2311.6\) and LRT p = 0.00015 both favour modelB, before allowing for overdispersion.

10. The anova(q1, q2, test = "F") row is hidden. Give F for the interaction (2 d.p.), then decide: keep it?

\(F = (39.686 - 33.278)/1 \,/\, 1.861832 = 6.4081/1.8618 = \)3.44 on \((1,\ 21-4) = (1,\ 17)\) df. \(3.44 < F_{1,17}(0.95) = 4.45\) (R: p = 0.081), so drop the interaction and prefer the additive model. χ² said keep it (\(6.41 > 3.84\), p = 0.011). Same twist, binomial version: here even a modest \(\hat\phi = 1.86\) flips the decision. Also: plate 1 (\(n = 39\), \(\hat p = 0.364\)) has binomial variance \(39(0.364)(0.636) = 9.03\), but the quasi-binomial variance is \(1.8618\times9.03 = 16.8\).

7 · The R lines you may be shown

  • anova(C, D, test = "F") on two quasi fits uses the bigger model's \(\hat\phi\) and \(F_{s,n-p_B}\): the formula in §3.
  • anova(A, B, dispersion = phiB, test = "F") on the Poisson/binomial fits gives the same F (1.094 here). R then treats the supplied \(\hat\phi\) as known, so the denominator df is \(\infty\) and p is 0.2956 rather than 0.2974. Same conclusion (trout-egg notes, p. 13).
  • drop1 and step "do not work" for quasi fits (slide 12): there's no AIC for step. Faraway (§7.4) does use drop1(modq, test = "F"). It runs, but it divides by the deviance-based \(D/(n-p)\), not Pearson's \(\hat\phi\): for Sex it prints \(F = 14.404/(1696.7/139) = 1.18\), not 1.094. In the exam, quote the anova/Pearson version.

11. anova(modelA, modelB, test = "F") on the two Poisson fits prints F = 14.404, p = 0.0001475, plus the warning using F test with a 'poisson' family is inappropriate. What happened?

A Poisson family's dispersion is fixed at 1, so \(F = 14.404/1/1 = \Delta D\). That's just the χ² test in disguise. To allow for overdispersion, either refit with quasipoisson or pass dispersion = phiB.

\(n = 53 + 1 = 54\); \(p_B = 54 - 50 = 4\). \(\hat\ell_B = 4 - 493.06/2 = \boxed{-242.53}\) [1]. \(\ell_{\text{sat}} = \hat\ell_B + D_B/2 = -242.53 + 210.39/2 = \boxed{-137.34}\) [1]. Check from modelA: \(3 - 507.09/2 + 226.43/2 = -137.33\) ✓ [1 for method/working].

Step 2: part (b) [2]

modelB. (i) AIC \(493.06 < 507.09\). (ii) LRT: \(\Delta D = 226.43 - 210.39 = 16.04\) on 1 df \(> 3.84\), p = 0.00006, so reject \(H_0\colon \beta_{\text{woolB}} = 0\). One mark each.

Step 3: part (c) [2]

(i) Residual deviance 210.39 on 50 df is far above \(\chi^2_{50}(0.95) = 67.50\). This goodness-of-fit test is trustworthy here because every fitted mean is at least 19.4 (well above 5), so modelB fits badly. With no obvious missing term, extra variance is the likely cause. (ii) Pearson \(\hat\phi_B = 4.26 \gg 1\): the variance is about 4 times the Poisson \(\operatorname{Var}Y = \mu\). Plausible cause: loom-to-loom differences (machine, operator, yarn batch) that aren't in the model (Lesson 10).

Step 4: part (d) [2]

modelB assumes \(\operatorname{Var}Y_i = \mu_i\) (\(\phi = 1\)). modelD only assumes \(E Y_i = \mu_i\), \(\operatorname{Var}Y_i = \phi\mu_i\) with \(\phi\) estimated by \(X^2/(n-p) = 4.26\), fitted by quasi-likelihood (no distribution, so no AIC). The coefficient estimates and deviances are identical, but modelD's SEs are \(\sqrt{4.26} = 2.06\) times larger and nested models are compared with an F test, not χ².

Step 5: part (e) [2]

\(\mathrm{SE} = 0.05157\times\sqrt{4.261522} = 0.05157\times2.0643 = \boxed{0.1065}\) (R prints 0.10646). Use modelB's \(\hat\phi\): woolB is a modelD coefficient and modelD has modelB's formula. Using 4.602 gives 0.1106, losing the mark. \(t = -3.994/2.0643 = \boxed{-1.93}\) on 50 df (R: p = 0.059), no longer significant at 5%.

Step 6: part (f) [4]
$$F = \frac{(D_C - D_D)/s}{\hat\phi_B} = \frac{(226.43 - 210.39)/1}{4.261522} = \frac{16.039}{4.2615} = \boxed{3.76}\;\sim F_{1,\;50}\text{ under }H_0.$$

[1 formula, 1 value.] df: \(s = 51 - 50 = 1\), and \(n - p_B = 54 - 4 = 50\) [1]. Since \(3.76 < F_{1,50}(0.95) = 4.03\), there's no significant evidence at 5% for a wool effect once overdispersion is allowed for (R: p = 0.058). Prefer modelC, the smaller model [1]. This reverses (b): the χ² test treated \(\phi = 1\) and overstated the evidence about 4.3-fold. \(\hat\phi\) comes from the bigger model (\(\hat\phi_B\), not 4.602) because it's valid whether or not \(H_0\) holds. (With \(\hat\phi_A\) you'd get 3.49: wrong, though the conclusion is the same.)

Step 7: part (g) [2]

Quasi SE \(= 0.06396\times2.0643 = 0.13204\). CI for \(\beta_{\text{H}}\): \(-0.51849 \pm 1.96(0.13204) = (-0.7773,\ -0.2597)\). Ratio: \(e^{-0.51849} = 0.60\) with CI \(\boxed{(0.46,\ 0.77)}\). For the same wool, high tension is estimated to cut mean breaks by about 40% compared with low tension. The CI excludes 1, so the tension effect survives allowing for overdispersion.

Step 8: part (h) [3]

Check: \(\hat\eta = 3.69196 - 0.20599 - 0.32132 = 3.16465\) ✓. \(\hat\mu = e^{3.164654} = \boxed{23.7}\) breaks [1]. The printed SE is Poisson: \(0.05397811\times2.0643 = 0.11143\) [1]. CI: \(e^{3.164654 \pm 1.96(0.11143)} = e^{(2.9463,\ 3.3831)} = \boxed{(19.0,\ 29.5)}\) [1]. Ignoring overdispersion would give \((21.3,\ 26.3)\), too narrow.

Homework answers

1(a). \(p = 4\): \(\hat\ell = 4 - 1467.2/2 = -729.6\); \(\ell_{\text{sat}} = -729.6 + 569.25/2 = -444.98\). (b) \(D = 569.25\) on 180 df (ratio 3.2), or \(\hat\phi = 3.31 \gg 1\). (c) \(\sqrt{3.308482} = 1.8189\): SE(limityes) \(= 0.0355784\times1.8189 = 0.0647\); SE(day) \(= 0.0005964\times1.8189 = 0.00108\). (d) \(F = (572.5323 - 569.25)/1/3.308482 = 3.2823/3.3085 = 0.99\) on (1, 180) \(< 3.89\), so drop year (R: 0.9925, p = 0.32). χ² agrees here: \(3.28 < 3.84\). 2. Quasi-binomial keeps the binomial mean model and only adds \(\phi\) to the variance. \(\phi\) cancels from the estimating equations, so \(\hat\beta\) (e.g. −0.7781) is unchanged. But \(\widehat{\operatorname{Var}}\hat\beta\) is scaled by \(\hat\phi = 1.8618\), so the interaction SE grows from 0.3064 to \(0.3064\sqrt{1.8618} = 0.4181\). Its \(|t| = 1.86\) (p = 0.08), and \(F = 3.44 < 4.45\), so the interaction is no longer significant.
