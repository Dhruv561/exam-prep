Lesson 5 · Topic 2: Exponential families & GLMs

Exponential families: canonical parameter, variance function and canonical link

The goal: handed any standard pmf or pdf, you can write it in exponential-family form, read off \(\theta\), \(\phi\), \(a(\phi)\), \(b(\theta)\) and \(c(y,\phi)\), get \(\mathbb E Y\) and \(\operatorname{Var} Y\) by differentiating \(b\), write the variance function \(v(\mu)\), and name the canonical link. All on paper, in about ten minutes.

Why this matters for 10 Nov: nearly every past paper has an 8–10 mark question that says "show that this distribution is an exponential family, obtain the canonical link, obtain the variance function". Gamma, Poisson, exponential and inverse Gaussian have all been used. The algebra is the same every time, so once you've drilled the recipe these are close to free marks. It's also the definition every later GLM lesson rests on: a GLM is an exponential-family response plus a link.

1 · The form

\(Y\) comes from an exponential family if its density or mass function can be written (Exponential families, slide 3)

$$f(y;\theta,\phi) = \exp\!\left[\frac{y\theta - b(\theta)}{a(\phi)} + c(y,\phi)\right].$$
  • \(\theta\) is the canonical parameter (location). It multiplies \(y\) itself: not \(y^2\), not \(\log y\).
  • \(\phi\) is the dispersion parameter (scale). For the Poisson and binomial, \(\phi = 1\).
  • \(b(\theta)\) depends on \(\theta\) only; \(c(y,\phi)\) can be any function of \(y\) and \(\phi\), but no \(\theta\). (That's the lecturer's handwritten note on the annotated slide 3.)
  • The course uses \(a(\phi) = \phi\) throughout (slides 4–5). Faraway allows known weights, \(a(\phi) = \phi/w\) (§8.1, p. 153). You won't need them for these questions.

The set of possible \(y\) values (the support) can't depend on \(\theta\). An indicator like \(I(0<y<\theta)\) can't be hidden inside \(c(y,\phi)\), because it involves \(\theta\).

2 · The recipe

  1. Take logs. Write \(\log f(y)\) and expand with log rules. Check the support doesn't involve the parameter.
  2. Find the \(y\cdot(\text{something})\) term. Every term with both \(y\) and the parameter must be \(y\) times a function of the parameter. That function is \(\theta\) (possibly after pulling out a scale factor, step 3). If the parameter multiplies \(y^2\), \(\log y\) or \(e^{y}\) instead, stop: it isn't an exponential family in this form.
  3. Pull out \(1/a(\phi)\). If a scale parameter divides the \(y\)-term (like \(\sigma^2\) or \(1/\nu\)), factor it out of both the \(y\)-term and the parameter-only term. That's \(a(\phi)\).
  4. Read off \(b\), then rewrite it in \(\theta\). The parameter-only term is \(-b/a(\phi)\). Invert \(\theta\)'s formula (e.g. \(\mu\) in terms of \(\theta\)) and substitute, so \(b\) is a function of \(\theta\) alone.
  5. Everything left is \(c(y,\phi)\). Then state all five pieces: \(\theta\), \(\phi\), \(a(\phi)\), \(b(\theta)\), \(c(y,\phi)\).

Worked example 1: Poisson (slide 5)

\(f(y) = e^{-\lambda}\lambda^y/y!\) for \(y = 0,1,2,\dots\) The support doesn't involve \(\lambda\).

$$\log f(y) = y\log\lambda - \lambda - \log y!$$

The \(y\)-term is \(y\cdot\log\lambda\), so \(\theta = \log\lambda\), and nothing divides it, so \(\phi = 1\), \(a(\phi) = \phi\). The parameter-only term is \(-\lambda\), so \(b = \lambda\); in terms of \(\theta\), \(\lambda = e^\theta\), so \(b(\theta) = e^\theta\). Finally \(c(y,\phi) = -\log y!\).

Worked example 2: gamma in mean–shape form

GLMs use the gamma with mean \(\mu\) and shape \(\nu\) (Faraway §9.1, p. 175):

$$f(y;\mu,\nu) = \frac{1}{\Gamma(\nu)}\left(\frac{\nu}{\mu}\right)^{\!\nu} y^{\nu-1} e^{-\nu y/\mu},\qquad y>0.$$

Take logs and group the \(\mu\) terms:

$$\begin{aligned} \log f &= \nu\log\nu - \nu\log\mu + (\nu-1)\log y - \frac{\nu y}{\mu} - \log\Gamma(\nu)\\ &= \frac{y\,(-1/\mu) - \log\mu}{1/\nu} + \nu\log\nu + (\nu-1)\log y - \log\Gamma(\nu). \end{aligned}$$

So \(\theta = -1/\mu\), \(\phi = 1/\nu\), \(a(\phi) = \phi\). The parameter-only term is \(-\log\mu\), so \(b = \log\mu\). Now rewrite it: \(\mu = -1/\theta\), so

$$b(\theta) = \log(-1/\theta) = -\log(-\theta),\qquad \theta<0,$$ $$c(y,\phi) = \frac1\phi\log\frac1\phi + \Big(\frac1\phi - 1\Big)\log y - \log\Gamma\!\Big(\frac1\phi\Big).$$

(I checked numerically that this reproduces the density.) The shape–rate parametrisation works the same way, with the rate in place of \(\nu/\mu\).

Trap: the four classic slips
(1) Leaving \(b\) in terms of \(\mu\), \(\lambda\) or \(p\). The lemma differentiates with respect to \(\theta\). For the Poisson, "\(b = \lambda\)" differentiated in \(\lambda\) gives 1, not the mean. Always substitute first: \(b(\theta) = e^\theta\), so \(b'(\theta) = e^\theta = \lambda\). ✓
(2) Ignoring the support. Uniform\((0,\theta)\) and a shifted exponential \(e^{-(y-\theta)}\), \(y\ge\theta\), are not exponential families: the range of \(y\) depends on \(\theta\). Write the support down in your answer; markers look for it.
(3) Mixing up \(v(\mu)\) and \(\operatorname{Var}Y\). \(\operatorname{Var} Y = a(\phi)\,v(\mu)\). For the gamma, \(v(\mu) = \mu^2\) but \(\operatorname{Var} Y = \mu^2/\nu\). They're equal only when \(\phi = 1\).
(4) Gamma's sign. \(\theta = -1/\mu\), not \(1/\mu\), and \(b(\theta) = -\log(-\theta)\) needs \(\theta<0\). R's Gamma() "inverse" link is \(1/\mu\), i.e. the canonical link with the sign dropped (section 4).

1. \(Y\) counts failures before the first success: \(f(y) = p(1-p)^y\) for \(y = 0,1,2,\dots\) (geometric). What is the canonical parameter \(\theta\)?

\(\log f = y\log(1-p) + \log p\). The term with \(y\) is \(y\cdot\log(1-p)\), so \(\theta = \log(1-p)\), \(\phi = 1\), \(c = 0\). Option (c) is the Bernoulli's \(\theta\), from a different \(y\)-term.

2. Same geometric. Which is \(b(\theta)\), written the way the recipe requires?

The parameter-only term is \(+\log p = -b\), so \(b = -\log p\). That's the right value, but (a) is still in \(p\). Since \(e^\theta = 1-p\), \(p = 1-e^\theta\), so \(b(\theta) = -\log(1-e^\theta)\). Option (b) loses the sign; (d) forgets the exponential.

3. Lesson 1's density was \(f(y;\theta) = \dfrac{y}{\theta}e^{-y^2/(2\theta)}\), \(y>0\). Is it an exponential family in the course's form, with \(Y\) as the response?

\(\log f = \log y - \log\theta - y^2/(2\theta)\). The only term linking \(y\) and \(\theta\) is \(y^2\cdot(-1/(2\theta))\), which isn't \(y\theta\). (It would be an exponential family for the response \(Y^2\), but that's a different variable.) The support \(y>0\) is fine, so (d) is wrong for a different reason.

4. Which one of these is not an exponential family in the course's sense?

\(f(y) = \theta^{-1} I(0<y<\theta)\): the support depends on \(\theta\), and there's no \(y\theta\) term at all. The normal with known \(\sigma^2 = 4\) is fine: \(\theta = \mu\), \(a(\phi) = 4\), \(b = \theta^2/2\).

Explain why (2–3 sentences). Why must \(b\) be written as a function of \(\theta\) alone before you use it?

Model answer

The mean and variance come from \(b'(\theta)\) and \(b''(\theta)\), derivatives with respect to the canonical parameter (section 3). If \(b\) is left in \(\mu\) or \(p\), differentiating it in that variable gives the wrong answer (Poisson: \(\frac{d}{d\lambda}\lambda = 1\neq\lambda\)). Also, the definition needs \(b\) to depend on the parameter only through \(\theta\), which you show by writing it that way.

3 · Mean and variance from \(b\)

Lemma (slide 8). If \(Y\) is from an exponential family,

$$\mathbb E Y = b'(\theta),\qquad \operatorname{Var}Y = b''(\theta)\,a(\phi).$$

The slide leaves the proof as an exercise. Here it is, filling in Faraway's lines (§8.1, pp. 152–153). It uses the two score identities from Lesson 1: \(\mathbb E\,\ell'(\theta) = 0\) and \(\mathbb E\,\ell''(\theta) = -\mathbb E[\ell'(\theta)^2]\). For one observation,

$$\ell(\theta) = \frac{y\theta - b(\theta)}{a(\phi)} + c(y,\phi),\qquad \ell'(\theta) = \frac{y - b'(\theta)}{a(\phi)},\qquad \ell''(\theta) = -\frac{b''(\theta)}{a(\phi)}.$$ $$\mathbb E\,\ell'(\theta) = \frac{\mathbb E Y - b'(\theta)}{a(\phi)} = 0 \;\Rightarrow\; \mathbb E Y = b'(\theta).$$ $$-\frac{b''(\theta)}{a(\phi)} = -\mathbb E\!\left[\frac{(Y-b'(\theta))^2}{a(\phi)^2}\right] = -\frac{\operatorname{Var}Y}{a(\phi)^2}\;\Rightarrow\;\operatorname{Var}Y = b''(\theta)\,a(\phi).$$

Variance function (slide 9). Write \(\mu = \mathbb E Y\). Since \(\mu = b'(\theta)\), \(\theta = (b')^{-1}(\mu)\), and

$$\operatorname{Var}Y = b''\big((b')^{-1}(\mu)\big)\,a(\phi) = v(\mu)\,a(\phi),\qquad v = b''\circ(b')^{-1}.$$

In practice: compute \(b''(\theta)\), then replace \(\theta\) by its formula in \(\mu\). The lecturer's note on the annotated slide 9: "the mean and variance are not always independent… \(v(\mu)\) is a function of \(\mu\)". It says how the spread changes with the mean.

Gamma, finished. \(b(\theta) = -\log(-\theta)\), so

$$b'(\theta) = -\frac1\theta = \mu\ \checkmark,\qquad b''(\theta) = \frac{1}{\theta^2} = \mu^2,$$

giving \(v(\mu) = \mu^2\) and \(\operatorname{Var}Y = \phi\mu^2 = \mu^2/\nu\). The check \(b'(\theta) = \mu\) is worth writing in an exam: it catches a wrong \(b\) immediately.

5. For the geometric of Q1–2 with \(p = 0.2\), use \(b(\theta)\) to find \(\operatorname{Var}Y\).

\(b'(\theta) = \dfrac{e^\theta}{1-e^\theta}\) and \(b''(\theta) = \dfrac{e^\theta}{(1-e^\theta)^2}\). With \(e^\theta = 1-p = 0.8\): \(\mathbb E Y = 0.8/0.2 = 4\) and \(\operatorname{Var}Y = 0.8/0.04 = \)20 (times \(a(\phi) = 1\)). These match the textbook \((1-p)/p\) and \((1-p)/p^2\).

6. Still the geometric. Write \(v(\mu)\) as a function of \(\mu\), then evaluate it at \(\mu = 2.5\).

From \(\mu = \dfrac{e^\theta}{1-e^\theta}\): \(\dfrac{1}{1-e^\theta} = 1+\mu\) and \(e^\theta = \dfrac{\mu}{1+\mu}\). So \(b'' = \dfrac{e^\theta}{1-e^\theta}\cdot\dfrac{1}{1-e^\theta} = \mu(1+\mu) = \mu+\mu^2\). At 2.5: \(2.5 + 6.25 = \)8.75. More variance than a Poisson with the same mean (which would give 2.5).

7. A gamma response has dispersion \(\phi = 0.2\) (shape \(\nu = 5\)) and mean \(\mu = 3\). What is \(\operatorname{Var}Y\)?

\(\operatorname{Var} Y = a(\phi)\,v(\mu) = 0.2\times 3^2 = \)1.8. If you typed 9, you gave \(v(\mu)\), not the variance: trap (3).

Explain why (2–3 sentences). What does \(v(\mu) = \mu^2\) say about gamma data, compared with normal (\(v = 1\)) and Poisson (\(v = \mu\)) data?

Model answer

For the gamma, \(\operatorname{Var}Y = \phi\mu^2\), so the standard deviation is \(\sqrt\phi\,\mu\): it grows in proportion to the mean, and the coefficient of variation \(\sqrt\phi\) is constant. The normal has the same spread at every mean, and the Poisson's SD grows only like \(\sqrt\mu\). So a gamma GLM suits positive, skewed data where bigger values are proportionally noisier (Faraway calls \(\phi\) the squared coefficient of variation, §9.3).

4 · The canonical link

A GLM says \(Y\) is from an exponential family and \(g(\mu) = x^T\beta\) for a monotone, differentiable link \(g\) (GLMs I, slide 3). The canonical link is the \(g\) that makes the linear predictor equal the canonical parameter, \(g(\mu) = x^T\beta = \theta\) (slide 4). Since \(\mu = b'(\theta)\),

$$g = (b')^{-1}.$$

The annotated slides show two ways to find it (annotated GLMs I, pp. 7–9): (1) solve \(\mu = b'(\theta)\) for \(\theta\); or (2) take your formula for \(\theta\) in terms of the mean and rename it \(g(\mu)\). Route (2) is faster when you already wrote \(\theta\) as a function of \(\mu\). Use (1) as a check. Gamma: \(\theta = -1/\mu\), so the canonical link is \(g(\mu) = -1/\mu\).

Sources: normal, Poisson and binomial rows from slides 4–9 and GLMs I slide 5 (binomial: week 4 tute Q1); gamma and inverse Gaussian from Faraway Table 8.1 and §9.1–9.2 (p. 181). I checked every \(b\), \(b'\) and \(b''\) numerically. Note the binomial: the lecture's \(Y\) is the count, so \(v(\mu) = \mu(1-\mu/m)\). Faraway and R use the proportion \(Y/m\), with \(V(\mu) = \mu(1-\mu)\). Use the course's version unless the question says otherwise.

Signs and constants in links
R and Faraway drop signs and constant factors from canonical links: Gamma() uses "inverse" \(1/\mu\), inverse.gaussian() uses \(1/\mu^2\). Multiplying \(\eta\) by a constant just rescales \(\beta\) (here, flips its sign), so it's the same model. In an exam, state the exact \(g = (b')^{-1}\) you derived (e.g. \(-1/\mu\)), then you may note that it's equivalent to \(1/\mu\). And "inverse" names the function \(1/\mu\). It doesn't mean \(g^{-1}\).

8. For a Bernoulli response (\(m = 1\)), the canonical link is the logit. If \(\mu = 0.2\), what is \(\theta = g(\mu)\) (3 d.p.)?

\(\theta = \log\dfrac{0.2}{0.8} = \log 0.25 = \)−1.386. Check route (1): \(b(\theta) = \log(1+e^\theta)\), so \(b'(\theta) = e^\theta/(1+e^\theta) = 0.25/1.25 = 0.2\) ✓.

9. For the gamma, \(\theta = -1/\mu\), but R's Gamma() family has link = "inverse", i.e. \(\eta = 1/\mu\). Which statement is right?

\(-1/\mu = x^T\beta\) and \(1/\mu = x^T(-\beta)\) give identical fitted values, so it's the canonical link up to a sign (Faraway §9.1: "we typically remove the minus"). The \(\theta\) itself is \(-1/\mu\): \(b(\theta) = -\log(-\theta)\) needs \(\theta<0\).

Why the canonical link matters

With independent \(y_i\) and the canonical link, \(\theta_i = x_i^T\beta\) (GLMs I, slide 7), so the log-likelihood is

$$\ell(\beta,\phi;y) = \sum_{i=1}^n\left[\frac{y_i x_i^T\beta - b(x_i^T\beta)}{a(\phi)} + c(y_i,\phi)\right] = \frac{\beta^TX^Ty - \sum_i b(x_i^T\beta)}{a(\phi)} + \sum_i c(y_i,\phi).$$

The data touch \(\beta\) only through \(X^Ty\), so \(X^Ty\) is sufficient for \(\beta\) (Faraway, p. 154). Differentiating, using \(b'(\theta_i) = \mu_i\): the score is \(X^T(y-\mu)/a(\phi)\), and the Hessian \(-\sum_i b''(\theta_i)x_ix_i^T/a(\phi)\) has no \(y\) in it. So observed and Fisher information coincide, and Newton–Raphson is Fisher scoring (slides 9 and 14). That's the convenience. Nothing forces you to use it, though: probit and cloglog are perfectly good binomial links (Lesson 2).

Reading R's family objects

> fam <- Gamma()
> fam$link
[1] "inverse"
> fam$linkfun(4)
[1] 0.25
> fam$variance(3)
[1] 9
> binomial()$variance(0.2)
[1] 0.16
> inverse.gaussian()$link
[1] "1/mu^2"

Each family stores its link \(g\) (linkfun) and its variance function (variance). fam$variance(3) is \(v(3) = 3^2 = 9\), not \(\operatorname{Var}Y\).

10. What does binomial()$variance(0.2), which prints 0.16, compute?

\(0.2\times0.8 = 0.16\). R works with the proportion \(Y/m\), so its variance function is \(\mu(1-\mu)\) as in Faraway's Table 8.1, and the \(m\) goes into the weights. The lecture's count version would be \(v(\mu) = \mu(1-\mu/m) = m\cdot0.16\) at \(p = 0.2\). The logit's derivative is \(1/0.16 = 6.25\).

Explain why (2–3 sentences). Why does the canonical link make \(X^Ty\) a sufficient statistic for \(\beta\)?

Model answer

Under the canonical link \(\theta_i = x_i^T\beta\), so the only term in the log-likelihood that involves both data and \(\beta\) is \(\sum_i y_ix_i^T\beta = \beta^TX^Ty\); the \(b(x_i^T\beta)\) terms have no data and \(c(y_i,\phi)\) has no \(\beta\). By the factorisation theorem, the likelihood depends on the data (as far as \(\beta\) is concerned) only through \(X^Ty\). With any other link, \(\theta_i\) is a non-linear function of \(x_i^T\beta\) and no such reduction happens.

5 · Exam-level challenge

About 15 minutes on paper, written answers. Then open the steps one at a time.

Let \(Y\) have the negative binomial distribution with mean \(\mu>0\) and known size \(r>0\):

$$P(Y=y) = \frac{\Gamma(y+r)}{\Gamma(r)\,y!}\left(\frac{r}{r+\mu}\right)^{\!r}\left(\frac{\mu}{r+\mu}\right)^{\!y},\qquad y = 0,1,2,\dots$$

(a) Show that \(Y\) is from an exponential family, identifying \(\theta\), \(\phi\), \(a(\phi)\), \(b(\theta)\) and \(c(y,\phi)\). [4]
(b) Use the exponential-family lemma to find \(\mathbb EY\) and \(\operatorname{Var}Y\). [2]
(c) Find the variance function. With \(r = 3\) and \(\mu = 6\), compute \(\operatorname{Var}Y\) and compare it with a Poisson of the same mean. [2]
(d) Obtain the canonical link. Why might a log link be preferred in practice? [2]
(e) For independent \(Y_1,\dots,Y_n\) with the canonical link \(\theta_i = x_i^T\beta\), show that the score for \(\beta\) is \(X^T(y-\mu)\). [2]
(f) Faraway (§8.1) says the negative binomial is not a member of the exponential family. Reconcile this with (a) in 2–3 sentences. [1]

Step 1: part (a)

The support \(\{0,1,2,\dots\}\) doesn't depend on \(\mu\). Take logs:

$$\log f(y) = y\log\frac{\mu}{\mu+r} + r\log\frac{r}{\mu+r} + \log\Gamma(y+r) - \log\Gamma(r) - \log y!$$

The \(y\)-term is \(y\log\frac{\mu}{\mu+r}\), so \(\theta = \log\dfrac{\mu}{\mu+r}\) (note \(\theta<0\)), \(\phi = 1\), \(a(\phi) = \phi\). Then \(e^\theta = \dfrac{\mu}{\mu+r}\), so \(1 - e^\theta = \dfrac{r}{\mu+r}\), and the parameter-only term is \(r\log(1-e^\theta) = -b(\theta)\):

$$b(\theta) = -r\log(1-e^\theta),\qquad c(y,\phi) = \log\Gamma(y+r) - \log\Gamma(r) - \log y!$$

(\(c\) contains \(r\), which is fine because \(r\) is a known constant.)

Step 2: part (b)
$$b'(\theta) = \frac{re^\theta}{1-e^\theta} = r\cdot\frac{\mu/(\mu+r)}{r/(\mu+r)} = \mu\ \checkmark$$ $$b''(\theta) = \frac{re^\theta}{(1-e^\theta)^2} = \frac{re^\theta}{1-e^\theta}\cdot\frac{1}{1-e^\theta} = \mu\cdot\frac{\mu+r}{r} = \mu + \frac{\mu^2}{r}.$$

So \(\mathbb EY = \mu\) and \(\operatorname{Var}Y = a(\phi)\,b''(\theta) = \mu + \mu^2/r\).

Step 3: part (c)

\(v(\mu) = \mu + \mu^2/r\). With \(r = 3\), \(\mu = 6\): \(\operatorname{Var}Y = 6 + 36/3 = \boxed{18}\), three times the Poisson's 6. The extra \(\mu^2/r\) is overdispersion relative to the Poisson. As \(r\to\infty\) it vanishes and you get the Poisson back.

Step 4: part (d)

\(g(\mu) = \theta = \log\dfrac{\mu}{\mu+r}\). Check with route (1): solving \(\mu = re^\theta/(1-e^\theta)\) gives \(e^\theta = \mu/(\mu+r)\) ✓. In practice: this \(g\) only takes negative values, so \(x^T\beta\) must stay below 0 for every \(x\), which the fitting can't guarantee. The log link maps \((0,\infty)\) onto all of \(\mathbb R\), so any \(\beta\) is valid and \(e^{\beta_j}\) is a multiplicative effect on the mean, as in a Poisson GLM. (This is the same kind of difficulty as the gamma's \(-1/\mu\), which also needs \(\eta\) of one sign.)

Step 5: part (e)

With \(\phi = 1\), \(\ell(\beta) = \sum_i\big[y_ix_i^T\beta - b(x_i^T\beta) + c(y_i)\big]\). Then

$$\frac{\partial\ell}{\partial\beta} = \sum_i\big[y_i - b'(x_i^T\beta)\big]x_i = \sum_i (y_i - \mu_i)\,x_i = X^T(y-\mu).$$
Step 6: part (f)

Faraway means the negative binomial with \(r\) unknown. Then \(r\) appears inside \(b\) (through \(-r\log(1-e^\theta)\)) and inside \(c\), and it can't be split off as a dispersion \(a(\phi)\) dividing \(y\theta - b(\theta)\), so the form fails. With \(r\) known, as here, it's a one-parameter exponential family with \(\phi = 1\).

Homework answers

1. \(\log f = y\log\frac{p}{1-p} + m\log(1-p) + \log\binom my\), so \(\theta = \log\frac{p}{1-p}\), \(\phi = 1\), \(b(\theta) = m\log(1+e^\theta)\), \(c = \log\binom my\). \(b'(\theta) = \frac{me^\theta}{1+e^\theta} = mp = \mu\); \(b''(\theta) = \frac{me^\theta}{(1+e^\theta)^2} = mp(1-p) = \mu(1-\mu/m)\). Canonical link \(g(\mu) = \log\frac{\mu}{m-\mu}\) (the logit of \(p = \mu/m\)).

2. \(\log P = y\log\lambda - \nu\log y! - \log Z(\lambda,\nu)\). So \(\theta = \log\lambda\), \(\phi = 1\), \(b(\theta) = \log Z(e^\theta,\nu) = \log\sum_{i\ge0} e^{i\theta}/(i!)^\nu\), \(c(y) = -\nu\log y!\). Then \(\mathbb EY = b'(\theta) = \sum_i i\lambda^i/(i!)^\nu \big/ Z\), which is the mean, as it should be. With \(\nu = 1\), \(Z = e^\lambda\) and \(b(\theta) = e^\theta\): the Poisson.

3. Uniform\((\alpha,\beta)\): no, because the support \([\alpha,\beta]\) depends on the parameters, and no special case with an unknown parameter fixes that. Gumbel with \(\beta\) known: \(\log f = -\log\beta + \frac{y-\alpha}{\beta} - e^{-\alpha/\beta}e^{y/\beta}\). The term \(y/\beta\) has no \(\alpha\) (it goes in \(c\)), but \(\alpha\) multiplies \(e^{y/\beta}\), not \(y\), so it isn't in the form for \(Y\). (It would be for the transformed response \(e^{Y/\beta}\).)
