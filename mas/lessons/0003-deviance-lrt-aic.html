Lesson 3 · Topic 1: Binomial regression & likelihood

Deviance, likelihood ratio tests and AIC: reading glm output

The goal: handed two R summary(glm(...)) printouts, you can recover both log-likelihoods, test one model against the other, check whether the model fits at all, and say which model you prefer with two numbers to back it up.

Why this matters for 10 Nov: every past paper has an R-output question worth 7–22 marks. The same sub-questions keep coming back: "what is the log-likelihood of the fitted model and of the saturated model?", "which model is better? Give two quantitative reasons", "what are the degrees of freedom?". This lesson is the binomial version. The overdispersion lesson later adds the quasi-Poisson twist on top of exactly these moves.

1 · Three models on one dataset

Take grouped binomial data: \(Y_i\sim\text{Bin}(m_i,p_i)\) for \(i=1,\dots,n\), with \(\operatorname{logit}p_i = x_i^T\beta\) as in Lesson 2. Three models matter:

  • Saturated model: one free \(p_i\) per observation, so \(n\) parameters. Its MLE is \(\tilde p_i = y_i/m_i\): it reproduces the data exactly, so no model on these data can have a higher log-likelihood \(\ell_{\text{sat}}\).
  • Your fitted model: \(p\) parameters (intercept included), with fitted values \(\hat\mu_i = m_i\hat p_i\) and log-likelihood \(\ell(\hat\beta)\).
  • Null model: intercept only, one parameter, so every \(p_i\) is the same pooled proportion.

The deviance measures how far your model falls short of the saturated one (Binomial Regression II, slide 9):

$$D = -2\big[\ell(\hat\beta) - \ell_{\text{sat}}\big] = 2\big[\ell_{\text{sat}} - \ell(\hat\beta)\big] \;\ge 0.$$

For the binomial, the constants cancel and it becomes a sum of one term per observation (slide 11):

$$D = 2\sum_{i=1}^n\left[\,y_i\log\frac{y_i}{\hat\mu_i} + (m_i-y_i)\log\frac{m_i-y_i}{m_i-\hat\mu_i}\right],$$

with the convention \(0\log 0 = 0\) when \(y_i = 0\) or \(y_i = m_i\). Small \(D\) means the fitted values are close to the data.

R prints two deviances. The residual deviance is \(D\) for your model, on \(n-p\) degrees of freedom. The null deviance is \(D\) for the null model, on \(n-1\) degrees of freedom. Neither changes with what you call the model, so you can read \(n\) and \(p\) straight off the df:

$$n = \text{null df} + 1, \qquad p = n - \text{residual df}.$$
Course convention
For the binomial and Poisson, the dispersion \(\phi = 1\), so the scaled deviance \(D/\phi\) and the deviance are the same number (GLMs II, slides 3 and 7). The lectures say "scaled deviance" a lot. For this lesson, read it as "deviance".

1. One group has \(m=20\) trials and \(y=12\) successes, and the model's fitted probability is \(\hat p = 0.5\). What is this group's contribution \(d_i\) to the deviance (3 d.p.)?

\(\hat\mu = 20\times0.5 = 10\). Then \(d = 2\big[12\log\tfrac{12}{10} + 8\log\tfrac{8}{10}\big] = 2\,[2.1879 - 1.7851] = \)0.805. The second term is negative, but the total is always \(\ge 0\). If you got a negative number, you probably flipped a fraction inside one of the logs.

2. A binomial glm summary ends with Null deviance: 88.4 on 41 degrees of freedom and Residual deviance: 39.0 on 35 degrees of freedom. How many parameters \(p\) does the model have, intercept included?

\(n = 41 + 1 = 42\), so \(p = 42 - 35 = \)7. (Equivalently, the model uses \(41 - 35 = 6\) parameters more than the null model, plus the intercept.) A factor with \(k\) levels counts as \(k-1\) parameters, so this could be, say, two numeric predictors plus a 5-level factor.

2 · Does the model fit? The deviance goodness-of-fit test

If the model is adequate and each \(m_i p_i\) and \(m_i(1-p_i)\) is at least about 5, then (slide 12)

$$D \;\overset{d}{\approx}\; \chi^2_{n-p}.$$

So compare \(D\) with the \(\chi^2_{n-p}\) 95% point. If \(D\) is bigger, the model is missing something (a predictor, an interaction, the right link, or extra variation between groups). A quick sense check: \(\mathbb E\,\chi^2_k = k\), so a residual deviance close to its df is reassuring, and one far above it is a warning.

Trap
With binary data (\(m_i = 1\): each row is one person who is either 0 or 1), \(m_ip_i\ge5\) fails for every row. Then \(D\) is not \(\chi^2_{n-p}\), so the goodness-of-fit test is meaningless (the saturated model gains a parameter for every new person, so the usual theory doesn't apply: slide 10). You can still compare nested models with differences of deviances, as in the next section.

No χ² tables on your calculator. The Casio FX-82 can't do χ² tail probabilities, so past papers print the critical values for you (an R line like qchisq(0.95, df=...)). Still, know the small ones by heart:

3. A logistic regression on 500 individual patients (each \(y_i\) is 0 or 1) has residual deviance 512 on 495 df. What can you conclude about fit from this?

Every \(m_i = 1\), so the "\(m_ip_i\ge5\)" condition fails and \(D\not\approx\chi^2_{495}\). Options (a) and (c) both treat \(D\) as \(\chi^2\). Option (d) is wrong too: with 0/1 data you can't even detect overdispersion this way. Deviance differences between nested models are still fine.

3 · Comparing nested models: the likelihood ratio test

Model A is nested in model B if you get A by constraining B's parameters (usually setting some to zero). Say B has \(s\) more parameters. Under \(H_0\): "the extra \(s\) parameters are all zero" (slides 5 and 8),

$$\text{LR} = -2\big[\ell(\hat\beta_A) - \ell(\hat\beta_B)\big] \;\overset{d}{\approx}\;\chi^2_s.$$

You never need \(\ell\) itself, because \(\ell_{\text{sat}}\) cancels when you subtract two deviances (slide 13):

$$\boxed{\;\text{LR} = D_A - D_B,\qquad \text{df} = s = \text{df}_A - \text{df}_B\;}$$

Reject \(H_0\) (keep the bigger model) if \(D_A - D_B\) exceeds the \(\chi^2_s\) 95% point. This works even for 0/1 data. R's anova(modelA, modelB, test="Chisq") prints exactly this: the change in residual deviance, its df, and Pr(>Chi). Null deviance minus residual deviance is the LRT of "all the predictors at once" against the null model.

Wald test vs LRT. For one coefficient, the Wald test uses \(z = \hat\beta_j/\text{se}(\hat\beta_j)\), which is the z value column in R. Since \(z^2\overset{d}{\approx}\chi^2_1\), the two tests are asymptotically equivalent and usually agree. When they differ, trust the LRT: the χ² approximation to the likelihood ratio is generally better than the normal approximation to the MLE (slide 6). Faraway names the failure mode: with sparse data the SE can be overestimated, so \(z\) is too small and a real effect can be missed (the Hauck–Donner effect; Faraway §2.3, p. 34).

Trap: factors
A factor with \(k\) levels gets \(k-1\) coefficients, each one a contrast with the baseline level. Their individual \(z\)-tests don't answer "does this factor matter?". Test the whole factor with one LRT on \(k-1\) df. You'll see below that a factor can matter even when none of its individual \(z\)-tests is significant.

4 · AIC, and recovering \(\ell\) from the printout

The Akaike Information Criterion is (slide 14)

$$\text{AIC} = 2p - 2\ell(\hat\beta).$$

Smaller is better. The \(2p\) is a penalty for each extra parameter. Unlike the LRT, AIC can compare models that aren't nested. If B has \(s\) more parameters than A,

$$\text{AIC}_B - \text{AIC}_A = 2s + D_B - D_A.$$

That makes the two classic exam lines one rearrangement each:

$$\ell(\hat\beta) = p - \frac{\text{AIC}}{2}, \qquad \ell_{\text{sat}} = \ell(\hat\beta) + \frac{D}{2}.$$

Get \(p\) from the df (section 1), \(\ell\) from the AIC, then \(\ell_{\text{sat}}\) from the residual deviance. The saturated log-likelihood is the same for every model on the same data, which makes a good check if you're given two summaries.

(R's \(\ell\) includes the \(\log\binom{m_i}{y_i}\) constants. They're in \(\ell_{\text{sat}}\) too, so everything stays consistent: just use the printed AIC as it is.)

Practice on this output

You'll also need one more fact: the model with mins alone (call it model C) has residual deviance 35.368 on 28 df.

4. What is the likelihood ratio statistic for testing whether school is needed, given mins (3 d.p.)?

Model C is nested in model B (set both school coefficients to zero). \(\text{LR} = D_C - D_B = 35.368 - 27.775 = \)7.593 on \(28 - 26 = 2\) df.

5. In model B, schoolcatholic has p = 0.46. Is school a useful predictor once mins is in the model?

A 3-level factor adds \(3-1 = 2\) parameters, so compare with \(\chi^2_2(0.95) = 5.99\). R gives p = 0.022. The catholic dummy only says "catholic ≈ public". The factor matters because independent schools differ. Option (d) counts the levels instead of the parameters, and (c) forgets the factor has two coefficients.

6. What is the maximised log-likelihood of model B (2 d.p.)?

\(p = 30 - 26 = 4\), so \(\ell = 4 - 143.42/2 = 4 - 71.71 = \)−67.71. The most common slip is using \(p = 3\) (forgetting the intercept) or \(p=26\) (using the df itself).

7. Using model B's printout only, what is the log-likelihood of the saturated model (2 d.p.)?

\(\ell_{\text{sat}} = \ell_B + D_B/2 = -67.71 + 27.775/2 = \)−53.82. It matches the value from model A, as it must: the saturated model doesn't depend on which predictors you chose.

8. Pretend the AIC lines were torn off. Using only the deviances, what is \(\text{AIC}_A - \text{AIC}_B\) (3 d.p.)?

A has \(s=1\) more parameter, so \(\text{AIC}_A - \text{AIC}_B = 2(1) + D_A - D_B = 2 - 1.054 = \)0.946. Check: \(144.37 - 143.42 = 0.95\) ✓. An extra parameter is only "worth it" on AIC if it cuts the deviance by more than 2.

9. Which model do you prefer, A or B, and why?

That's the "two quantitative reasons" answer exams want: the LRT doesn't reject \(\beta_{\text{size}}=0\) (1.054 on 1 df, p = 0.30), and \(\text{AIC}_B = 143.42 < 144.37 = \text{AIC}_A\). Option (a): the bigger model always has the lower deviance, so that alone proves nothing. Option (b) gets the AICs backwards. Option (d): the null deviance is the same for both.

10. Under model B, 30 more minutes a week multiplies the odds of passing by \(e^{30\hat\beta_{\text{mins}}} = 1.63\). What is the upper end of a 95% Wald CI for this multiplier (3 d.p.)?

Build the CI for \(\beta_{\text{mins}}\) first: \(0.016192 \pm 1.96(0.002632) = (0.01103,\ 0.02135)\). Multiply by 30 and exponentiate each end: \((1.392,\ \)1.897\()\). Don't exponentiate the SE. Transform the endpoints, exactly like the η-scale CI in Lesson 2.

Coming later: is φ really 1?

The line (Dispersion parameter for binomial family taken to be 1) is an assumption, not an estimate. The check uses the Pearson statistic \(X^2 = \sum_i \dfrac{(y_i-\hat\mu_i)^2}{m_i\hat p_i(1-\hat p_i)}\) (GLMs II, slide 12), and \(\hat\phi = X^2/(n-p)\). For model B, \(X^2 = 27.37\), so \(\hat\phi = 27.37/26 = 1.05\): fine. When \(\hat\phi\) is well above 1 (overdispersion), the binomial standard errors are too small, so p-values are too small and you'll keep predictors you shouldn't. The fix (quasi-likelihood, \(\text{SE}\times\sqrt{\hat\phi}\), and an F-test in place of the χ² LRT) has its own lesson. The challenge below gives you a first look.

11. A binomial model has residual deviance 61.3 on 24 df, all \(m_i\hat p_i\) and \(m_i(1-\hat p_i)\) are above 10, and \(X^2/24 = 2.4\). What's the best summary?

\(\chi^2_{24}(0.95) = 36.4\), so 61.3 is far too big, and the sample-size condition holds, so the test is valid. \(\hat\phi = 2.4\) says the variance is about 2.4 times what the binomial allows. Standard errors are then too small by a factor of about \(\sqrt{2.4}\approx1.55\). (Option (d) is a made-up rule.)

(a) For model1, what is the log-likelihood of the fitted model, and of the saturated model?
(b) Assuming binomial responses, which is better, model1 or model2? Give two quantitative reasons.
(c) Is model1 an adequate fit? State what you checked first. (The fitted \(\hat p_i\) range from 0.69 to 0.85.)
(d) Give a 95% CI for the factor by which the odds of hatching change when sand temperature rises by 1 °C, under model1.
(e) What does phi1 suggest, and which of your conclusions in (b) is most at risk because of it?

Step 1: part (a)

\(n = 35+1 = 36\) and \(p = 36 - 30 = 6\) (intercept, temp, three beach dummies, depth). So \(\ell_1 = 6 - 224.98/2 = \boxed{-106.49}\), and \(\ell_{\text{sat}} = -106.49 + 48.207/2 = \boxed{-82.39}\).

Check with model2: \(p = 3\), \(\ell_2 = 3 - 228.95/2 = -111.48\), and \(-111.48 + 58.173/2 = -82.39\) ✓.

Step 2: part (b), two quantitative reasons

LRT: model2 is nested in model1 (beach coefficients set to 0). \(\text{LR} = 58.173 - 48.207 = 9.966\) on \(33-30 = 3\) df, which is above \(\chi^2_3(0.95) = 7.81\) (p ≈ 0.019). Reject \(H_0\), so beach matters.
AIC: \(224.98 < 228.95\), so model1 has the lower AIC. Check: \(2(3) + 48.207 - 58.173 = -3.97\) ✓.
So under the binomial assumption, model1 is better. Notice that no single beach dummy is significant at 5% (p = 0.12, 0.10, 0.81), yet the factor as a whole is. That's the factor trap from section 3.

Step 3: part (c), goodness of fit

Check the condition first: \(m_i \ge 60\) and \(0.69\le\hat p_i\le0.85\), so the smallest \(m_i(1-\hat p_i)\) is about \(60\times0.15 = 9 \ge 5\). The χ² approximation is OK.

\(D = 48.207\) on 30 df, which is above \(\chi^2_{30}(0.95) = 43.77\) (p ≈ 0.019). Reject adequacy: model1 doesn't capture all the variation in hatching.

Step 4: part (d), odds multiplier

The CI for \(\beta_{\text{temp}}\) is \(-0.127696 \pm 1.96(0.029272) = (-0.1851,\ -0.0703)\). Exponentiate both ends: \(\boxed{(0.831,\ 0.932)}\), with point estimate \(e^{-0.1277} = 0.880\). Each extra degree cuts the odds of an egg hatching by about 12% (somewhere between 7% and 17%).

Step 5: part (e), the overdispersion warning

\(\hat\phi = 1.58 > 1\), and together with the failed goodness-of-fit test in (c) this points to overdispersion: nests vary more than a binomial with these predictors allows (e.g. unmeasured nest-to-nest differences). Under \(\phi=1\) the standard errors are too small, by a factor of about \(\sqrt{1.58} = 1.26\), and the χ² LRT in (b) is too generous.

The LRT for beach is most at risk. Sneak preview of the overdispersion lesson: the F-statistic is \(\dfrac{9.966/3}{1.584} = 2.10\) on (3, 30) df. The 5% point of \(F_{3,30}\) is 2.92, so once you allow for overdispersion, beach is no longer significant (p ≈ 0.12), and model2 would be preferred. Exams love this flip.

7 · Before you close this tab

Retrieval: write these from memory, then check

(1) \(D = 2(\ell_{\text{sat}} - \ell)\) on \(n-p\) df. (2) GOF: \(D\approx\chi^2_{n-p}\) only if \(m_ip_i,\ m_i(1-p_i)\gtrsim5\), and never for 0/1 data. (3) LRT for nested A ⊂ B: \(D_A - D_B\sim\chi^2_{s}\), and it works for 0/1 data too. (4) \(\text{AIC} = 2p - 2\ell\), smaller is better, and nesting isn't required. (5) \(\ell = p - \text{AIC}/2\) and \(\ell_{\text{sat}} = \ell + D/2\). (6) \(n = \text{null df}+1\) and \(p = n - \text{residual df}\). (7) Test a factor with one LRT on \(k-1\) df.

(c) At 29.9: \(\hat\eta = -61.3183 + 2.2110(29.9) = 4.79\), \(\hat p = 0.992\), expected females \(= 8(0.008) \approx 0.07\). At 27.2: \(\hat\eta = -1.18\), \(\hat p = 0.235\), expected males \(\approx 1.9\). Both are far below 5, so the data are sparse and the \(\chi^2\) fit test in (b) is unreliable. (f) \(\text{LR} = 24.942 - 20.256 = 4.69\) on 1 df, above 3.84 (\(p = 0.030\)): keep the quadratic. Wald \(z^2 = 2.328^2 = 5.42\), the same conclusion but not the same number; trust the LRT.
